## 一、持久约定（全书不变，永远生效）

| 约定 | 内容 |
|---|---|
| 底层空间 | 记作 E 或 V，**恒为有限维实内积空间**，配内积 ⟨·,·⟩ 与范数 ‖·‖ |
| 范数 | 是「配给」空间的，不是自带的。换范数 = 换问题性质（Ch10.9） |
| 对偶空间 | E* 与 E 是**同一批元素**，只有范数不同：E 上用 ‖·‖，E* 上用 ‖·‖\* |
| 对偶范数 | `‖y‖* = max{⟨y,x⟩ : ‖x‖ ≤ 1}` —— 等价于「单位球的支撑函数」 |
| 角色判断 | 位置/迭代点 → ‖·‖；梯度/测量工具 → ‖·‖\* |
| 球记号 | `B(c,r)` 开球，`B[c,r]` 闭球 |
| min/max | 全书只用 min/max，**不表示极值一定能取到**（书页 16 明示） |
| 欧氏自对偶 | 欧氏范数（‖·‖=√⟨·,·⟩）满足 ‖·‖ = ‖·‖\*，此时简记 E = E* |
| **水平集方向** | `Lev(f,α) = {x : f(x) ≤ α}` —— 是**下**水平集（≤），因为做的是最小化 |
| **lsc 直觉** | 下半连续 = **允许「向下凹陷」，不允许「向上凸起」**。向上凸起会在 epi 上戳出不闭合的缺口 |
| **lsc 定义方式** | 用**序列**刻画（xₙ→x 时 f(x) ≤ liminf f(xₙ)）。有限维下与拓扑刻画等价，够用 |
| **闭函数的定义域** | **不**一定闭。反例 f(x)=1/x (x>0)：dom=(0,∞) 开，但 epi 闭（缺口被 +∞ 补上） |

## 三、高频证明技巧库

遇到卡住的时候先来这里扫一遍——大部分「证不出来」其实是没认出套路。

### T1 · epigraph 技巧
把「函数性质」翻译成「集合性质」。
- f 闭 ⟺ epi(f) 闭
- f 凸 ⟺ epi(f) 凸
- **max 保闭保凸的证明就靠它**：`epi(max_i f_i) = ∩_i epi(f_i)`，闭集的交闭、凸集的交凸。对**任意**指标集成立。

### T2 · 序列 + liminf 技巧（证 lsc）
取 {(xₙ,yₙ)} ⊆ epi(f) 收敛到 (x\*,y\*)，由 f(xₙ) ≤ yₙ 和 lsc 得 f(x\*) ≤ liminf f(xₙ) ≤ liminf yₙ = y\*，故 (x\*,y\*) ∈ epi(f)。
**这是 Thm 2.6(i⇒ii) 的骨架，全书复用几十次。**

### T3 · 反证 + 取子列 + 致密性（证存在性）
Thm 2.12 的骨架：假设无下界 ⟹ 取列使 f(xₙ) → −∞ ⟹ Bolzano-Weierstrass 取收敛子列 ⟹ lsc 给出 f(x̄) ≤ liminf = −∞，矛盾。

### T4 · 截断到紧集（把「闭」升级成「紧」）
Thm 2.14 的骨架：强制性保证「最优解一定在某个球 B[0,M] 内」⟹ 问题等价于在 S ∩ B[0,M] 上求最小 ⟹ 后者紧 ⟹ 用 Weierstrass。
**模式**：强制性 → 有界化 → 紧化 → 存在性。

### T5 · ε-论证（处理 min/inf 取不到时）
Thm 2.18 的骨架：要证 g(λx₁+(1−λ)x₂) ≤ λg(x₁)+(1−λ)g(x₂)，先取 ε-近似最小点 y₁,y₂ 使 f(x₁,y₁) ≤ g(x₁)+ε，用凸性组合，最后令 ε→0。
**当 min 不一定取到时，这是标准武器。**

### T6 · 归一化技巧
取 x̃ = x/‖x‖（单位向量），用对偶范数定义得到界。引理 1.4 的证明，后面每个收敛率证明里都有它的影子。

### T7 · 「max of affine ⟹ convex」
要证一个函数凸，试试把它写成一族仿射函数的逐点上确界。
- σ_C 就是这样（⟹ 恒凸，不管 C 多烂）
- 例 2.17 的 ϕ_C 也是这样（⟹ 对任意 C 都凸）

### T8 · 分解 λx+(1−λ)y 为两个点的凸组合（斜率单调）
Thm 2.22 的骨架：把 c−t 写成 `(1−t/s)·c + (t/s)·(c−s)`，用凸性得 `g(t) ≤ g(s)`，即差商单调。

## 四、反例库

**反例的用途是标定假设的边界**——每个反例都在回答「去掉这个条件会怎样」。

| # | 反例 | 位置 | 说明 |
|---|---|---|---|
| R1 | f(x) = 1/x (x>0)，∞ else | Ch2 例 2.4 | **闭函数的定义域可以不闭**。dom=(0,∞) 开，但 epi 闭。lsc 口诀的反面印证：x→0⁺ 时 f→+∞，把"缺口"顶到无穷高补上 |
| R2 | f_α：f(0)=α, f(x)=x on (0,1] | Ch2 例 2.10 | **闭 ⊋ 连续**。闭 ⟺ α≤0；dom 上连续 ⟺ α=0。f_{−0.1} 即经典示例 |

## 五、计算表（逐章累积，做题时回查）

### 5.1 对偶范数（Ch1 例 1.5–1.7）

| 原范数 ‖·‖ | 对偶范数 ‖·‖\* |
|---|---|
| ℓ₁ | ℓ_∞ |
| ℓ₂ | ℓ₂（自对偶） |
| ℓ_p (p>1) | ℓ_q，1/p + 1/q = 1 |
| ℓ_∞ | ℓ₁ |
| Q-范数 √(xᵀQx) | Q⁻¹-范数 √(xᵀQ⁻¹x) |
| 积空间复合加权 ℓ₂：√(Σ ωᵢ‖uᵢ‖²) | √(Σ (1/ωᵢ)‖vᵢ‖²_{E*_i}) |

**规律**：加权结构在对偶下**权重取倒数**。可用于猜测未见过的对偶范数。

### 5.2 支撑函数（Ch2 §2.4 汇总表，书页 33）

| 集合 C | σ_C(y) | 条件 |
|---|---|---|
| {b₁,...,bₙ} | maxᵢ⟨bᵢ,y⟩ | bᵢ ∈ E |
| K（锥） | δ_{K°}(y) | K° = {y: ⟨y,x⟩≤0 ∀x∈K} |
| Rⁿ₊ | δ_{Rⁿ₋}(y) | E = Rⁿ |
| Δₙ（单纯形） | max{y₁,...,yₙ} | E = Rⁿ，因 Δₙ = conv{eᵢ} |
| {x: Ax ≤ 0} | δ_{\{Aᵀλ : λ∈R^m₊\}}(y) | 需 Farkas 引理 |
| {x: Bx = b} | ⟨y,x₀⟩ + δ_{Range(Bᵀ)}(y) | Bx₀ = b |
| **B_{‖·‖}[0,1]（单位球）** | **‖y\|\*（对偶范数）** | ⭐ Ch1↔Ch2 接缝 |
| B_{‖·‖_p}[0,1] | ‖y‖_q | 1/p+1/q=1 |
| B_{‖·‖_Q}[0,1] | ‖y‖_{Q⁻¹} | Q ∈ Sⁿ₊₊ |

### 5.3 支撑函数性质（Lemma 2.24）

- **正齐次**：σ_C(αy) = ασ_C(y)，α ≥ 0
- **次可加**：σ_C(y₁+y₂) ≤ σ_C(y₁) + σ_C(y₂)（⟹ σ_C 是次线性函数）
- σ_{αC}(y) = ασ_C(y)
- **σ_{A+B}(y) = σ_A(y) + σ_B(y)**（Minkowski 和）

## 六、分章核心（耐久结论）

### Ch1 向量空间 ✅ 已掌握（书页 1–12）

**一句话**：这一章定义的是全书的**计量单位**，不是知识。

必须会用的四个东西：
1. **对偶范数**：给 ‖·‖ 能写出 ‖·‖\*
2. **Q-范数对偶**：Q → Q⁻¹（Ch10.9 要用）
3. **伴随算子**：给 A 能求 Aᵀ（例 1.8 的 Tr 技巧）
4. **谱范数 vs Frobenius**：分得清哪个是 induced，记住 L = σ_max(A)²

关键定理：
- **引理 1.4（广义 Cauchy–Schwarz）**：`|⟨y,x⟩| ≤ ‖y‖* ‖x‖`。全书用了几百次。证明用归一化 x̃ = x/‖x‖（技巧 T6）。
- **§1.14**：算子范数 ‖A‖ = max{‖A(x)‖_V : ‖x‖_E ≤ 1}，它**就是** §1.8.2 的 induced norm。`‖A‖ = ‖Aᵀ‖` 的陷阱：左边 E→V，右边 E\*→V\*。

前向指针：Ch5 的 L-smooth 定义 `‖∇f(x)−∇f(y)‖* ≤ L‖x−y‖` —— **左边对偶范数，右边原范数**，L 本身就是一个算子范数。

### Ch2 扩展实值函数 🔄 进行中（书页 13–33）

**一句话**：这一章的战略目的是**把「约束」变成「函数」**。
`min{f(x) : x ∈ C}` ⟶ `min f(x) + δ_C(x)`
一旦这样写，所有算法只需处理无约束的复合目标 F = f + g —— **Ch10 的 prox-grad 就是这么来的**。

**为什么用「闭」而不用「连续」？**（书里没明说，但这是本章的核心动机）
优化真正需要的是「最小值能取到」。连续性太强——ℓ₀ 范数不连续，但它是闭的，所以 Weierstrass 仍然适用。**闭性（= lsc）是保证极值存在的最小条件。**

核心定理：
- **Thm 2.6**：闭 ⟺ 下半连续 ⟺ 所有水平集闭。**三种武器任选**——证 epi 闭（几何）/ 证 lsc（序列）/ 证水平集闭（集合论）。例 2.11 用第三种，因为 ℓ₀ 的 epi 闭性难直接证。
- **Thm 2.7 / 2.16**：保闭、保凸的运算完全平行——(a) 仿射复合 (b) 非负组合 (c) 逐点 max（**任意**指标集）。(c) 的证明靠 `epi(max f_i) = ∩ epi(f_i)`。
- **Thm 2.8**：连续（且 dom 闭） ⟹ 闭。证明唯一用到 dom 闭的点是：保证极限点仍在 dom 内，才能在它处用连续性。Cor 2.9：实值连续函数必闭——日常最常用。
- **Thm 2.12（Weierstrass）**：proper closed + C 紧 + C∩dom(f)≠∅ ⟹ 有下界且**取到**最小值。证明模式：取序列 → 紧集取收敛子列 → lsc 传递到极限点。
- **Def 2.13（强制性）**：$\|x\|\to\infty \Rightarrow f(x)\to+\infty$。它把低水平集困在有界区域内。
- **Thm 2.14**：proper + 闭 + 强制 + 非空闭约束集 + dom 相交 ⟹ 取到最小值。证明模式：取参照点 → 强制性把所有更优点困在大球 B[0,M] 内 → 闭集 ∩ 闭球 = 紧集 → Thm 2.12（技巧 T4 的完整展开）。
- **§2.3 Def 2.15**：凸函数 ⟺ epi(f) 凸。proper 凸函数 ⟺ dom 凸 + dom 上限制实值凸。
- **Jensen 不等式**：$f(\sum_i \lambda_i \mathbf{x}_i) \le \sum_i \lambda_i f(\mathbf{x}_i)$，$\lambda \in \Delta_k$。k=2 时退化为凸性定义 (2.5)。
- **Thm 2.16**：保凸运算——(a) 仿射复合 (b) 非负组合 (c) 任意 max。与 Thm 2.7 完全平行（一个保闭、一个保凸）。
- **Thm 2.18**：部分最小化保凸（ε-论证，技巧 T5）。
- **Thm 2.21**：凸函数在 int(dom) 上**局部 Lipschitz**。
- **Thm 2.22**：一元 proper closed convex 必在 dom 上连续（含端点）。**高维不成立**（反例 R4）。

**§2.4 支撑函数的三条要点**：
1. **σ_C 永远闭凸**（Lemma 2.23），不管 C 是否闭/凸 —— 因为它是仿射函数的逐点上确界（技巧 T7）。
2. **σ_{B[0,1]} = ‖y\|\***（例 2.31）—— Ch1 与 Ch2 的接缝，对偶范数换了个说法。
3. **σ 完全决定闭凸集**（Lemma 2.34：A=B ⟺ σ_A=σ_B），且 σ_A = σ_{cl(conv A)}（Lemma 2.35）。
   **含义**：从优化视角，**一个集合与它的闭凸包不可区分**——用线性泛函探测两者，得到的最大值相同。这是 Ch4 对偶理论的雏形。
