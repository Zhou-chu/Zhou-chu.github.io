## Feedforward Network（前向传播网络）
### Perception：最小的单个“神经元”——感知机
+ 一个感知机，它是MLP的最小单元，它其实就是这样一个表达式：$$\hat{y}=g(\theta_0+\sum_{i=1}^dx_i\theta_i)$$
即我们输入 $x$， 经 $\theta$ 参数的**线性组合(linear combination)**，再加上截距项$\theta_0$，得到的结果扔给**非线性**函数 $g$ （我们称之为**激活函数**）进行处理，从而得到预测值 $\hat{y}$。可以发现，这样的一个感知机理论上具有非线性的表达能力。
+ 由于感知机最早的启发灵感来自人脑的神经元，生物学告诉我们，神经元的信号处理是依靠高低电位实现的，出于对人类大脑的模仿，我们希望找到一个最像这种高低电位机制的函数，于是我们找到了 $sgn(x)$，表达式为：$$sgn(x)=\begin{cases}1\quad x>0\\ 0\quad others.\end{cases}$$尽管它由于导数性质极其糟糕，后来在实际的神经网络中完全没法使用，从而被彻底替代，但是作为引入，接下来的讨论中我们暂时使用它作为激活函数。
+ 我们认为，若干个这样的感知机，每层多个，布置多层，在结构合适的情况下，有能力**表达**任何的函数关系
+ PLA（最朴素的感知机学习方法）
	+ ### Inputs (输入)
		- 迭代次数：$T_0$
		- 训练集：$\{(x_t, y_t)\}_{t=1}^{m} \subset \mathbb{R}^d \times \{-1, +1\}$
		  - 其中 $m$ 为样本数量 (#samples)
		  - $d$ 为特征维度 (#dimension)
	+ ### Output (输出)
		- 参数 $\theta$
	+ ### Algorithm (算法流程)
		1. **初始化**：设置参数 $\theta = 0$
		2. **循环**：对于 $t = 1$ 到 $T_0$（共进行 $T_0$ 次迭代）
		   - **采样**：从训练集中取出一个样本 $(x_t, y_t)$
		   - **预测**：计算预测值 $\hat{y} = \text{sgn}(x_t \cdot \theta)$
		   - **更新**：
		     - 如果预测错误（$\hat{y} \neq y_t$），则更新参数：$\theta = \theta + y_t x_t$
		     - 如果预测正确，则保持 $\theta$ 不变
	+ 这显然是一种基本的学习办法，即扔给模型一个输入，得到一个预测，根据预测和实际值的差距来更新参数，那么预期上我们的模型也许会变得更好。但是我们关心的是这个学习办法是否真正有效，换句话说，我们希望在严格的数学框架下证明它**收敛**
+ Convergence Rate（收敛速率定理）
	- **$\gamma$：最优间隔（best-case margin）**
	  - 假设存在一个向量 $v \in \mathbb{R}^d$，使得对于所有 $i \in \{1...n\}$，满足 $\gamma \le \frac{y_i(v \cdot x_i)}{\|v\|}$（点到超平面的距离公式）
	  - 直觉理解是**最大间隔**，我们希望这个最小的间隔尽可能大
	- **$R$：最长向量的长度（the length of the longest vector）**，越大说明数据越分散
	- **定理（Convergence）**
	  - PLA 在不超过 $(\frac{R}{\gamma})^2$ 次误分类后收敛
	  - 前提条件是类别是**线性可分**的
	    - 这是一个“非常不现实的假设”
	  - 否则，它根本不会收敛
	  - 证明：挖坑待填
+ 我们现在来评估感知机的**表达**能力
	+ 显而易见的，AND、OR、NOT都是可以**表达**的，XOR由于是前面三者的组合，因此可用多层的感知机进行**表达**（expressivity）。即，多层感知机可以表示任意布尔函数

#### 激活函数的研究
+ 之前，我们使用的激活函数是阶跃函数sgn，但是它的导数性质非常差，因此我们要换一个好的。考虑到sgn是最简单的一个激活函数，而且高低电位性质和大脑神经元高度相似。因此，我们需要一个**很像sgn，但是又具有优秀导数性质**的激活函数，由此我们得到了**sigmoid函数**：$$g(z)=\sigma(z)=\dfrac{1}{1+e^{-z}}$$![](/obsidian-assets/d0f169f112b425bf.png)![](/obsidian-assets/c96b257d2fe0bb5e.png)
+ 他现在可导了，我们能用梯度的方式来做，因此我们可以求导（有需要的参考**链式法则**）、利用**梯度下降法**进行**反向传播**，从而能够学习
+ **梯度消失**问题：注意到上图小于-4和大于4的广大区域，sigmoid函数近似一条水平线，梯度很小，在计算机中极易**下溢**从而为0，称为**梯度消失**，这种不合适的梯度大小对训练极为不利。不是我们想要的，这会创造一些几乎完全无法反馈梯度的**死神经元**
+ 解决：我们提出了**ReLU函数**，这在几年前都是激活函数的绝对主流：$g(z)=\max(0,z)$
+ 注意到ReLU有一半的区域没有梯度消失，这个范围差不多够用了，而且他也满足**激活函数需要计算简单**的要求
+ 还有一种需要介绍的是tanh激活函数：$$g(z)=\dfrac{e^z-e^{-z}}{e^z+e^{-z}}$$尽管它并没有让梯度变好，但是它是**对称**的，适用于很多的二值神经网络
+ 后来，ReLU在小于0没有梯度信号的缺点，人们提出了
	+ GeLU（Gaussion Error Linear Unit）（目前主流，用在大多数transformer中）：$$GeLU(z)=zP(Z\leq z)=z\Phi(z)=z\cdot \dfrac{1}{2}[1+erf(\dfrac{z}{\sqrt{2}})]$$
	+ Swish: $g(z)=\dfrac{x}{1+^{-\beta z}}$
+ 激活函数中Softmax在分类问题也很常用，也多用于输出层：$$g(z)_i=\dfrac{e^{z_i}}{\sum_{j=1}^ke^{z_j}}$$
	+ 考虑我们在分类问题的决策比如猫狗识别，我们人会对这张图片打一个分，像猫和像狗的分数得出后，我们对其取max，可惜max函数的导数性质非常不好。而这个Softmax把所有**分数**全都转化为**概率**，然后我们取最大的概率即可
	+ 但是它这个数学函数也很容易数值溢出，因此在具体实践的时候，我们对其进行稳定性操作：$$g(z)_i=\dfrac{z_j-z_u}{\sum_{j=1}^ke^{z_j-z_u}},u=\arg \max(z_j)$$
#### Cost Function
![](/obsidian-assets/f61722edf67c0b29.png)
+ 现在，我们来定义损失函数，
+ 对于多分类问题，如果不想追求更高的性能，一个无脑操作是定义**交叉熵损失**：$J(q,p)=-\sum_{j=1}^kq_j\log p_j$（其中q、p是两个概率分布），则Loss Function $$J(y,\hat{y})=-\sum_{j=1}^ky_j\log\hat{y}_j$$
+ Cost Function为损失函数之和：$$\min_\theta J(\theta)=-\dfrac{1}{m}\sum_{i=1}^m[\sum_{j=1}^k 1{y^{(i)=j}}]\log\dfrac{\exp(z_j^{(n_i)})}{\sum_{j'=1}^k\exp(z_{j'}^{(n_i)})}$$
+ 还有几种函数了解：![](/obsidian-assets/37f67b7f94fa825f.png)
	+ 熵函数：$H(q)=-\sum_{j=1^k}q_j\log q_j$，度量信息量，即描述这个信息（uncertainty）的**比特数**
### Softmax Regression
+ 我们考虑以多分类问题举例，对多分类问题，我们实际上是在描述每个类别的可能性，然后选择**最大**的可能性的哪个类别作为分类结果。
+ 考虑取 $\max$ 这个函数的可导性质显然非常的不好，因此我们考虑某个函数，可以把每个类别的可能性全部**归一化**为总和为1的概率，而且尽可能的，我们要放大最有可能的那个选项对应的权重，这显然可以用指数函数来解决，于是我们利用了Softmax Function：$$p(y=j\mid x;W)=\dfrac{\exp(w_j^Tx)}{\sum_{j'=1}^k \exp(w_{j'}^T x)}$$
+ 举个例子，考虑掷骰子(骰子的点数总共为1~k)的实验，我们规定 $q$ 是每次掷骰子的概率密度函数，我们有：$$P(y=j\mid q)=q_j,\sum_{j=1}^kq_j=1$$
	+ 那么我们现在有 $m$ 个骰子，我们规定 $q_{ij}$ 表示第 $i$ 个骰子的结果是点数为 $j$ 的概率
	+ 那么，对于这 $m$ 个骰子，我们掷骰子得到的结果是：$\{y_1,y_2,\dots,y_m\}$ 的概率为：$$\prod_{i=1}^m\prod_{j=1}^kP(y_i=j\mid q_{ij})^{1\{y_i=j\}}$$
	+ 我们这是在学习，因此这个式子，只要是知道 $q_{ij}$ ，我们就知道了具体的结果。但是这个 $q_{ij}$ 是怎么来的呢？Softmax Regression认为，他是我们的输入 $x_i$ 经过参数 $W$ 的某种处理得来的：$$q_{ij}=P(y_i=j\mid x_i;W)$$
	+ 考虑我们的所有样本 $D=\{(x_i,y_i)\}_{i=1}^m$。那么我们利用统计知识，反过来估计 $W$ 的似然函数：$$L(W;D)=\prod_{i=1}^m\prod_{j=1}^kP(y_i=j\mid x_i;W)^{1\{y_i=j\}}$$
	+ 之后进行**最大似然估计**（Maximum likelihood estimation）：$$L(W;D)=\max_{w_1,\dots,w_k}\prod_{i=1}^m\prod_{j=1}^kP(y_i=j\mid x_i;W)^{1\{y_i=j\}}$$
	+ 考虑对数似然（minimum negative log-likelihood estimation）：$$LL(W;D)=\min_{w_1,\dots,w_k}-\dfrac{1}{m}\sum_{i=1}^m\sum_{j=1}^k\{1\{y_i=j\}\cdot \log P(y_i=j\mid x_i;W)\}=\min_{w_1,\dots,w_k}-\dfrac{1}{m} \sum_{i=1}^m\sum_{j=1}^k\{1\{y_i=j\}\cdot \log \dfrac{\exp(w_{j}^T x_i+b_j)}{w_{j'}^Tx_i+b_{j'}}\}$$
	+ 我们注意到，这样推导出来的式子和之前是一模一样

## Backpropagation（反向传播）
![](/obsidian-assets/43abde44b5a9a6c1.png)
+ 符号表示：$z^{(i)}_j$ 表示第 i 层的第 j 个神经元，$a_i^{(l)}$ 是第 $l$ 层第 $i$ 个神经元前向跑出来的结果（激活过了），除了输入层是直接为输入。他在输出层恰好是输出
+ ![](/obsidian-assets/d8ffdb15c7e6ed65.png)
+ 考虑梯度下降的基本框架
+ 前两步是反向传播算法，第三步是最优化问题（已知梯度优化参数），它不一定是只能用梯度下降
+ ![](/obsidian-assets/761b6e0362a8c802.png)
+ 现在是方向传播过程
	1. 按照前面讲的方法，用目前的参数，把输入扔进去得到输出
	2. 利用链式法则反向传播
		+ ![](/obsidian-assets/56c830dc2bc34e58.png)
		+ 多维情况下的梯度链式法则需要**雅可比矩阵**（坑）
		+ 注意，我们要优化 $\theta_2$ ，那我们要求**目标函数对 $\theta_2$ 的梯度**，在本图中：$$\dfrac{\partial J(\theta)}{\partial \theta_2}=\dfrac{\partial J(\theta)}{\partial \hat{y}}\cdot \dfrac{\partial \hat{y}}{\partial \theta_2}$$在这之后我们对于 $\theta_2$ 在梯度方向上移动一个**步长**就行了（步长多大合适那是后面讨论的事情）
		+ 同理，我们要优化 $\theta_1$ 也需要 $\dfrac{\partial J(\theta)}{\partial \hat{y}}$ 然后 $\dfrac{\partial \hat{y}}{\partial z_1}$ ，这些“主干道”的梯度我们随着反向回推没有必要重算，存在显存里就行了（**动态规划**了解一下），这是一种空间换时间
		+ 我们定义**残差**的概念：$$\delta_i^{(l)} === \dfrac{\partial}{\partial z_i^{(l)}}J(\theta,b;x,y)$$它代表了第 $l$ 层的第 $i$ 个神经元对最后的误差所负的责任
		+ 我们发现了残差之间的递推表达式：
			+ 最后一层：$$\delta_i^{(n_l)}=\dfrac{\partial}{\partial z_i^{(n_l)}}J(\theta,b;x,y)=\dfrac{\partial}{\partial \hat{y}_i}J(\theta,b;x,y)g'(z_i^{(n_l)})$$
			+ 在隐藏层，考虑某个 $z_j^{(l)}$ 会对所有的 $l+1$ 层神经元有贡献，因此：$$\dfrac{\partial J(\theta,b;x,y)}{\partial z_i^{(l)}}=\sum_{j=1}^{s_{l+1}}\dfrac{\partial J(\theta,b;x,y)}{\partial z_j^{(l+1)}}\dfrac{\partial z_{j}^{(l+1)}}{\partial z_i^{(l)}}$$也即：$$\delta_{i}^{(l)}=\sum_{j=1}^{s_{l+1}}\delta_j^{(l+1)}\theta_{ji}^{(l)}g'(z_i^{(l)})$$
			+  其中$\theta_{ji}^{(l)}$ 表示第 $l$ 层，上家节点 $i$ 对下家节点 $j$ 的线性参数
			+ 由此我们得到了反向传播的递推式了
			+ ![](/obsidian-assets/65d4b010678ed30c.png)
