## 一、电力电子的定义与任务
**定义**：电力电子（Power Electronics）研究**开关模式（switching-mode）电子器件**在**电能的控制与变换**中的应用。
**任务**：通过提供形式**最适合用户负载**的电压和电流，来控制并变换电能的流动。
拆词理解：
- **Power**：处理的是功率，不是信号。
- **Electronics**：靠半导体器件实现。
- **核心限定词是 switching-mode（开关模式）**——这是整门课的立足点，也是它区别于线性电子学的唯一分界线。
---
## 二、为什么必须"开关模式"：线性区 vs 开关区
以功率晶体管（GTR / BJT）为例，其输出特性（iC ~ vCE 平面）上存在两条完全不同的工作路径：

| 对比项   | 线性（放大）模式                   | 开关模式                           |
| ----- | -------------------------- | ------------------------------ |
| 工作点位置 | 落在放大区内部，iC 与 vCE **同时不为零** | 只停在两个端点：ON / OFF               |
| 器件角色  | 串联晶体管当作**可调电阻**            | 晶体管当作**开关**，ON → "1"，OFF → "0" |
| 器件损耗  | 大                          | 小（理想时为零）                       |
| 结果    | 效率低、笨重、体积大                 | 效率高、重量轻、紧凑                     |
> **考点**：为什么开关电源效率高？
> 答：器件只工作在 ON / OFF 两个状态——ON 时通态压降趋近于零，OFF 时电流趋近于零。两种状态下瞬时功率 v·i 都接近 0，因此器件自身损耗极小。而线性模式下电压与电流同时存在，v·i 直接变成热耗散。

**理想开关的伏安特性**（画在 iC–vCE 平面上）：
- **ON 态**：沿纵轴（vCE = 0）的一条垂线——零压降，可流过任意电流；
- **OFF 态**：沿横轴（iC = 0）的一条水平线——零电流，可承受任意电压。
**线性电源 vs 开关电源**（课件原对比）：

| 线性电源        | 开关电源     |
| ----------- | -------- |
| 串联晶体管作为可调电阻 | 晶体管作为开关  |
| 效率低         | 效率高      |
| 笨重、体积大      | 重量轻、结构紧凑 |

## 三、效率：为什么它是核心指标

```
η = Pout / Pin

Ploss = Pin − Pout = Pout · (1/η − 1)
```

课件给出 η 随 Ploss/Pout 变化的曲线：损耗占比稍一增大，效率就快速下降（例如 Ploss/Pout = 1 时 η 仅 0.5；Ploss/Pout = 1.5 时 η 降到约 0.4）。
在电力电子领域，即使做的很差，其效率一般也是90%以上，而且我们非常关心效率，比如99%和98%的效率差距实际上我们非常在意
**必须背下来的逻辑链**：
> 高效率 → 变换器内部损耗低 → 发热少、散热压力小 → **体积小** 与 **可靠运行** 才成为可能。

因此结论是：**效率是衡量变换器性能的一个好指标。**
**器件层面的配套要求**：功率处理器中要**避免使用有损耗的元件**（比如电阻、Linear mode的管子）；无源元件（C、L、变压器T）工作于**高频**，因此必须采用**低损耗材料**。

## 四、一个电力电子系统的构成

```
    Power input                        Power output
 vi ──────→ ┌────────────────┐ ──────→ ──●──────→ ( Load )
  ii        │ Power          │    io      │   vo
            │ processor      │            │
            └───────┬────────┘      Measurements
                    │ Control signals    │
            ┌───────┴────────┐ ←─────────┘
            │   Controller   │ ←── Reference
            └────────────────┘
```

- **功率处理器（Power processor）**：由**功率半导体器件**构成，器件**作为开关**工作。
- **控制器（Controller）**：由**低电平电子电路**构成，为功率处理器中的功率器件**产生控制信号**。
- 控制回路：采样输出 → 与基准（Reference）比较 → 生成控制信号，构成闭环。

> 课件中 **power processing ⇔ power conversion** 视为同义，即"功率处理"就是"功率变换"。

## 五、四种功率变换（必背，含英文名）

| #   | 变换                   | 英文名                                 | 电路名称                                                   | 典型器件     |
| --- | -------------------- | ----------------------------------- | ------------------------------------------------------ | -------- |
| 1   | **AC → DC**（整流）      | Rectification                       | **Rectifier**（整流器）                                     | 二极管、晶闸管  |
| 2   | **DC → DC**（直流变换）    | DC conversion                       | **DC chopper**（直流斩波器）                                  | 全控器件     |
| 3   | **DC → AC**（逆变）      | Inversion                           | **Inverter**（逆变器）                                      | 全控器件     |
| 4   | **AC → AC**（本课不强制要求） | Cycloconversion → Matrix Conversion | **Cycloconverter**（周波变换器）→ **Matrix converter**（矩阵变换器） | 晶闸管、全控器件 |

**记忆锚点**：整流 / 斩波 / 逆变 / 周波（矩阵）——英文词根分别对应 rect- / chop- / invert- / cyclo-。第 4 类的命名从 cycloconverter 演变为 matrix converter，注意两个名字都要认得。

## 六、开关模式 DC-DC 的基本关系（后续章节的原型）
![](/obsidian-assets/4a825a03e054ac4c.png)
课件给出的降压型开关变换器结构：**开关管 + 续流二极管 + 电感 L + 电容 C + 负载 R**；控制器采样输出电压 vo 与基准 vo,ref 比较，据此控制开关通断。
$$
Vo = \dfrac{1}{T_s} ∫_0^{t_on} v_o {\rm d}t = \dfrac{t_{on}}{T_s} · V_d = f_s \cdot t_{on} \cdot V_d = D \cdot V_d$$
符号含义：

| 符号               | 含义                              |
| ---------------- | ------------------------------- |
| Ts               | 开关周期（switching period）          |
| ton              | 导通时间；toff 为关断时间，Ts = ton + toff |
| fs = 1/Ts        | 开关频率                            |
| Vd               | 输入直流电压                          |
| **D = ton / Ts** | **占空比（duty ratio）**             |
**结论**：输出电压 = 输入电压 × 占空比，即 **Vo = D·Vd**。通过调节占空比 D 调节输出。由于 0 ≤ D ≤ 1，Vo ≤ Vd，故为降压。这条关系式是后面所有 DC-DC 变换器分析的起点。

## 七、理想功率器件
**理想功率器件 = 理想可控开关**，须同时满足三条：
1. **可控**（controllable）；
2. 开关过程**无时间限制**（无开通时间 / 关断时间约束）；
3. 电流与电压的**处理能力无限**。
课件给出的理想器件符号特性共 **4 条**（逐条记牢）：
4. 导通时电流**只能沿箭头方向流动**（单向导电）；
5. **通态压降为零**；
6. **电压、电流处理能力无限**；
7. **状态之间瞬时切换**。

## 八、商用功率器件对照表（重点考点）

| #   | 器件                             | 控制特性                 | 额定值（up to）                    | 开关频率（up to） |
| --- | ------------------------------ | -------------------- | ----------------------------- | ----------- |
| 1   | **二极管** Diode                  | **不可控** Uncontrolled | 9000 V / 8400 A（开关时间 ~100 μs） | —           |
| 1b  | **快恢复二极管** Fast Recovery Diode | 不可控，**反恢复时间 < 1 μs** | > 4500 V / 690 A              | —           |
| 2   | **晶闸管** Thyristor              | **可控开通、不可控关断**       | 9500 V / 5000 A（开关时间 ~200 μs） | —           |
| 3   | **GTO**                        | 可控开通与关断              | 4500 V / 3000 A               | 10 kHz      |
| 4   | **功率晶体管** Power transistor     | 可控开通与关断              | 1200 V / 400 A                | 10 kHz      |
| 5   | **功率 MOSFET**                  | 可控开通与关断              | 1200 V / 300 A                | 100 kHz     |
| 6   | **IGBT**（绝缘栅双极型晶体管）            | 可控开通与关断              | 6500 V / 3600 A               | 20 kHz      |
| 7   | **SiC MOSFET**                 | 可控开通与关断              | 10 kV / 225 A                 | 100 kHz     |
| 8   | **GaN**                        | 可控开通与关断              | 900 V / 50 A                  | **1 MHz**   |
### 从表里必须读出的三条规律
1. **按可控性分三档**（考试高频）：
   - **不可控**：二极管 —— 通断完全由主电路电压电流决定；
   - **半控 / 可控开通、不可控关断**：晶闸管 —— 给触发信号能开通，但关断要等主电路电流过零；
   - **全控**：GTO、功率晶体管、功率 MOSFET、IGBT、SiC MOSFET、GaN。
1. **耐压电流能力与开关频率成反比**：晶闸管耐压最高（9500 V）但开关最慢（~200 μs）；GaN 耐压最低（900 V）但开关最快（1 MHz）。物理原因：高耐压需要厚漂移区，导通电阻与开关损耗随之增大，频率因此受限。
2. **宽禁带器件（SiC、GaN）**：在同等耐压等级下能跑到更高的开关频率，是当前技术发展方向。GaN 已进入 MHz 量级。

## 九、应用场合
**课件列出的 5 个方向**：
1. **IT** —— 开关电源（SMPS）、不间断电源（UPS）
2. **节能** —— 电机驱动、照明
3. **交通** —— 电动汽车、地铁、高速列车
4. **新能源利用** —— 风电、光伏、燃料电池
5. **电力系统** —— 智能电网、柔性直流（Flexible DC）
**两个需要能展开讲的例子**：
- **变速驱动（Adjustable speed drives）**：
  - (a) 传统方式：靠**节流阀**调节流量，多余能量白白损耗在阀门上；
  - (b) 电力电子方式：用**变频器（frequency converter）**高效调节电机-泵的转速，直接给出所需流量。
  - → 这是"电力电子节能"最经典的论据，务必能对比着说。
- **柔性 AC-DC-AC 互联**：美国 Tres Amigas Superstation 的柔性交直流互联工程。
**交通运输领域的细分**（课件补充列表）：电动汽车牵引控制、电动汽车充电机、电力机车、有轨电车与无轨电车、地铁、含发动机控制的汽车电子、电梯。

## 十、功率等级（记住量级对应关系）

| 功率等级          | 典型场合             |
| ------------- | ---------------- |
| **< 1 W**     | 电池供电的便携设备        |
| **数十 ~ 数千 W** | 计算机 / 办公设备电源     |
| **kW ~ MW**   | 变速电机驱动           |
| **1000 MW**   | 电力系统直流输电用整流器与逆变器 |
