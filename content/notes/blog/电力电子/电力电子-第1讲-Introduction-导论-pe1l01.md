## 一、电力电子的定义与任务

**定义**：电力电子（Power Electronics）研究**开关模式（switching-mode）电子器件**在**电能的控制与变换**中的应用。
**任务**：通过提供形式**最适合用户负载**的电压和电流，来控制并变换电能的流动。
拆词理解：
- **Power**：处理的是功率，不是信号。
- **Electronics**：靠半导体器件实现。
- **核心限定词是 switching-mode（开关模式）**——这是整门课的立足点，也是它与线性电源（Linear power supply）的根本区别。

## 二、为什么必须"开关模式"：线性区 vs 开关区

课件分别以功率晶体管（GTR / BJT，iC–vCE 平面）和功率 MOSFET（iD–vDS 平面）为例，说明同一个器件可以有两种完全不同的用法：

| 对比项   | 线性（放大）模式                   | 开关模式                           |
| ----- | -------------------------- | ------------------------------ |
| 工作点位置 | 落在放大区内部，iC 与 vCE **同时不为零** | 只停在两个端点：ON / OFF               |
| 器件角色  | 串联晶体管当作**可调电阻**            | 晶体管当作**开关**，ON → "1"，OFF → "0" |
| 器件损耗  | 大                          | 小（理想时为零）                       |
| 结果    | 效率低、笨重、体积大                 | 效率高、重量轻、紧凑                     |

> **考点**：为什么开关电源效率高？
> 答：器件只工作在 ON / OFF 两个状态——ON 时通态压降趋近于零，OFF 时电流趋近于零。两种状态下瞬时功率 v·i 都接近 0，因此器件自身损耗极小。而线性模式下电压与电流同时存在，v·i 直接变成热耗散。

**理想开关的伏安特性**（画在 iC–vCE 平面上）：
- **ON 态**：沿纵轴（vCE = 0）的一条垂线——零压降，可流过任意电流；
- **OFF 态**：沿横轴（iC = 0）的一条水平线——零电流，可承受任意电压。
**线性电源 vs 开关电源**（课件原对比）：

| 线性电源        | 开关电源     |
| ----------- | -------- |
| 串联晶体管作为可调电阻 | 晶体管作为开关  |
| 效率低         | 效率高      |
| 笨重、体积大      | 重量轻、结构紧凑 |

## 三、效率：为什么它是核心指标

$$
\eta=\frac{P_{out}}{P_{in}},\qquad
P_{loss}=P_{in}-P_{out}=P_{out}\left(\frac{1}{\eta}-1\right)
$$

课件给出 η 随 $P_{loss}/P_{out}$ 变化的曲线，即 $\eta = 1/(1+P_{loss}/P_{out})$：$P_{loss}/P_{out}=1$ 时 η = 0.5，$=1.5$ 时 η = 0.4。

反过来看更有感觉：电力电子变换器的效率通常在 90% 以上，此时**效率每提高 1 个百分点，损耗就大幅下降**。按上式，η = 98% 时 $P_{loss}/P_{out}\approx 2.04\%$，η = 99% 时约 1.01%——效率只差 1 个点，发热却差了一倍，散热器体积也随之减半。这就是工程上为什么会认真计较 98% 和 99%。

**必须背下来的逻辑链**：
> 高效率 → 变换器内部损耗低 → 发热少、散热压力小 → **体积小** 与 **可靠运行** 才成为可能。

因此结论是：**效率是衡量变换器性能的一个好指标。**
**器件层面的配套要求**：功率处理器中要**避免使用有损耗的元件**（例如电阻、工作在线性区的晶体管）；无源元件（C、L、变压器 T）工作于**高频**，因此必须采用**低损耗材料**。

## 四、一个电力电子系统的构成

```
    Power input                        Power output
 vi ──────→ ┌────────────────┐ ──────→ ──●──────→ ( Load )
  ii        │ Power          │    io      │   vo
            │ processor      │            │
            └───────┬────────┘      Measurements
                    │ Control signals    │
            ┌───────┴────────┐ ←─────────┘
            │   Controller   │ ←── Reference
            └────────────────┘
```

- **功率处理器（Power processor）**：由**功率半导体器件**构成，器件**作为开关**工作。
- **控制器（Controller）**：由**低电平电子电路**构成，为功率处理器中的功率器件**产生控制信号**。
- 控制回路：采样输出 → 与基准（Reference）比较 → 生成控制信号，构成闭环。

> 课件中 **power processing ⇔ power conversion** 视为同义，即"功率处理"就是"功率变换"。

## 五、四种功率变换（必背，含英文名）

| #   | 变换                   | 英文名                                 | 电路名称                                                   | 典型器件     |
| --- | -------------------- | ----------------------------------- | ------------------------------------------------------ | -------- |
| 1   | **AC → DC**（整流）      | Rectification                       | **Rectifier**（整流器）                                     | 二极管、晶闸管  |
| 2   | **DC → DC**（直流变换）    | DC conversion                       | **DC chopper**（直流斩波器）                                  | 全控器件     |
| 3   | **DC → AC**（逆变）      | Inversion                           | **Inverter**（逆变器）                                      | 全控器件     |
| 4   | **AC → AC**（交交变换）   | Cycloconversion → Matrix Conversion | **Cycloconverter**（周波变换器）→ **Matrix converter**（矩阵变换器） | 晶闸管、全控器件 |

> 本学期课程大纲里，AC-DC（二极管整流、晶闸管整流）、DC-DC、DC-AC 各有独立模块；AC-AC 没有单独成章，导论中只要求认得名字。

**记忆锚点**：整流 / 斩波 / 逆变 / 周波（矩阵）——英文词根分别对应 rect- / chop- / invert- / cyclo-。第 4 类的命名从 cycloconverter 演变为 matrix converter，注意两个名字都要认得。

## 六、开关模式 DC-DC 的基本关系（后续章节的原型）

![](/obsidian-assets/4a825a03e054ac4c.png)
课件给出的降压型开关变换器结构：**开关管 + 续流二极管 + 电感 L + 电容 C + 负载 R**；控制器采样输出电压 $v_o$ 与基准 $V_{o,ref}$ 比较，据此控制开关通断。右侧波形中的 $v_o$ 指 LC 滤波之前、二极管两端的方波电压：开关导通时等于 $V_d$，关断时为 0。

$$
V_o=\frac{1}{T_s}\int_0^{t_{on}} v_o\,dt=\frac{t_{on}}{T_s}V_d=f_s\,t_{on}\,V_d=D\,V_d
$$

符号含义：


| 符号               | 含义                              |
| ---------------- | ------------------------------- |
| Ts               | 开关周期（switching period）          |
| ton              | 导通时间；toff 为关断时间，Ts = ton + toff |
| fs = 1/Ts        | 开关频率                            |
| Vd               | 输入直流电压                          |
| **D = ton / Ts** | **占空比（duty ratio）**             |

**结论**：输出电压平均值 = 输入电压 × 占空比，即 **Vo = D·Vd**。LC 低通滤波器滤掉开关频率分量，只留下这个平均值；调节 D 就能调节输出。由于 0 ≤ D ≤ 1，Vo ≤ Vd，故为降压。第 5 讲的 Buck 电路会用"电感伏秒平衡"再推一次这个结果。

**一个应用旁注**：1977 年 Apple II 采用开关电源（Rod Holt 设计），整机因此比同时代电脑轻巧得多——开关模式带来的"高效率 → 小体积"在消费电子上的早期体现。

## 七、理想功率器件

**理想功率器件 ≈ 理想可控开关**：可控，并且在开通/关断时间、电流/电压处理能力两方面都没有限制。

课件给出的理想器件符号特性共 **4 条**（逐条记牢）：

- 导通时电流**只能沿箭头方向流动**（单向导电）；
- **通态压降为零**；
- **电压、电流处理能力无限**；
- **状态之间瞬时切换**。

> 第 2 讲会把它扩展成 7 条（再加上"触发功率为零""漏电流为零""成本低"等），并用来给各种真实器件打分。

## 八、商用功率器件对照表（重点考点）

| #   | 器件                             | 控制特性                 | 额定值（up to）                    | 开关频率（up to） |
| --- | ------------------------------ | -------------------- | ----------------------------- | ----------- |
| 1   | **二极管** Diode                  | **不可控** Uncontrolled | 9000 V / 8400 A（开关时间 ~100 μs） | —           |
| 1b  | **快恢复二极管** Fast Recovery Diode | 不可控，**反恢复时间 < 1 μs** | > 4500 V / 690 A              | —           |
| 2   | **晶闸管** Thyristor              | **可控开通、不可控关断**       | 9500 V / 5000 A（开关时间 ~200 μs） | —           |
| 3   | **GTO**                        | 可控开通与关断              | 4500 V / 3000 A               | 10 kHz      |
| 4   | **功率晶体管** Power transistor     | 可控开通与关断              | 1200 V / 400 A                | 10 kHz      |
| 5   | **功率 MOSFET**                  | 可控开通与关断              | 1200 V / 300 A                | 100 kHz     |
| 6   | **IGBT**（绝缘栅双极型晶体管）            | 可控开通与关断              | 6500 V / 3600 A               | 20 kHz      |
| 7   | **SiC MOSFET**                 | 可控开通与关断              | 10 kV / 225 A                 | 100 kHz     |
| 8   | **GaN**                        | 可控开通与关断              | 900 V / 50 A                  | **1 MHz**   |

> 数据口径提醒：快恢复二极管电流在本讲课件写 690 A、第 2 讲写 1000 A；功率晶体管电压本讲写 1200 V、第 2 讲写 1400 V。两份课件不一致，记数量级即可，考试以老师最新口径为准。

### 从表里必须读出的三条规律

1. **按可控性分三档**（考试高频）：
   - **不可控**：二极管 —— 通断完全由主电路电压电流决定；
   - **半控 / 可控开通、不可控关断**：晶闸管 —— 给触发信号能开通，但关断要等主电路电流过零；
   - **全控**：GTO、功率晶体管、功率 MOSFET、IGBT、SiC MOSFET、GaN。
2. **硅器件里，功率等级与开关速度此消彼长**：晶闸管定额最高（9500 V / 5000 A）但开关最慢（~200 μs）；MOSFET 能到 100 kHz，定额却只有 1200 V / 300 A；IGBT 居中。这是趋势而不是严格的反比——高耐压需要更厚、更低掺杂的漂移区，双极器件靠存储大量载流子来降低压降，存储电荷越多关断越慢。
3. **宽禁带器件（SiC、GaN）打破了这个取舍**：SiC MOSFET 做到 10 kV 仍能工作在 100 kHz，GaN 做到 1 MHz。它们是当前的技术发展方向（第 2 讲末尾和宽禁带综述一文会展开）。

## 九、应用场合

**课件列出的 5 个方向**：
1. **IT** —— 开关电源（SMPS）、不间断电源（UPS）
2. **节能** —— 电机驱动、照明
3. **交通** —— 电动汽车、地铁、高速列车
4. **新能源利用** —— 风电、光伏、燃料电池
5. **电力系统** —— 智能电网、柔性直流（Flexible DC）
**两个需要能展开讲的例子**：
- **变速驱动（Adjustable speed drives）**：
  - (a) 传统方式：靠**节流阀**调节流量，多余能量白白损耗在阀门上；
  - (b) 电力电子方式：用**变频器（frequency converter）**高效调节电机-泵的转速，直接给出所需流量。
  - → 这是"电力电子节能"最经典的论据，务必能对比着说。
- **柔性 AC-DC-AC 互联**：美国 Tres Amigas Superstation 的柔性交直流互联工程。
**交通运输领域的细分**（课件补充列表）：电动汽车牵引控制、电动汽车充电机、电力机车、有轨电车与无轨电车、地铁、含发动机控制的汽车电子、电梯。
