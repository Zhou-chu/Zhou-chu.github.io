> （每节标题后括号内为对应原课件页码，配图见 `AC-DC学习笔记.assets/` 文件夹）

## 0. 学习重点与分析框架（P2）

分析各类整流器（Rectifier）的核心方法是**关键波形分析**，对每一种电路都要看三组波形：

| 观察对象                | 波形                                  |
| ------------------- | ----------------------------------- |
| **直流输出（DC output）** | 输出电压 $v_d$、输出电流 $i_d$               |
| **交流输入（AC input）**  | 电源电压 $v_s$、电源电流 $i_s$               |
| **器件（Devices）**     | 二极管电压 $v_{diode}$、二极管电流 $i_{diode}$ |

**理想化假设**：

1. 二极管导通时压降忽略不计；
2. 开通与关断时间为零（瞬时切换）。

**核心关键点：换流（Commutation）** —— 电流从一对器件转移到另一对器件的过程。

> 补充说明：本讲为**工频不控整流器**（line-frequency uncontrolled rectifier）。  
> 直流输出电压 = 直流平均值 + 交流纹波；交流侧电流为**非正弦**。

## 1. 单相桥式二极管整流器（Single-phase Bridge）

### 1.1 纯电阻负载（Pure Resistance, R）（P3）

![单相桥·纯电阻负载](/obsidian-assets/51bfacaf8c0d0c88.png)

电路结构：4 只二极管 D₁~D₄ 组成 H 桥，D₁D₂ 与 D₃D₄ 交替导通：

- 电源正半周：**D₁、D₂ 导通**；
- 电源负半周：**D₃、D₄ 导通**。

输出电压 $v_d$ 为全波整流波形（|sin| 形），每个工频周期两个脉波。

记号约定：小写（$v_d$、$i_s$）表示瞬时值，大写（$V_d$、$I_d$）表示平均值、有效值等常量。

**直流平均量：**

$$
V_d=\frac{1}{\pi}\int_0^{\pi}V_{smax}\sin\theta\,d\theta=\frac{2V_{smax}}{\pi}\approx0.9V_s,\qquad I_d=\frac{V_d}{R}
$$

其中 $V_{smax}$ 为电源电压峰值，$V_s$ 为有效值。

波形要点（对应原图右侧三组波形）：

- $v_d$、$i_d$：脉动的 |sin| 波，$i_d$ 与 $v_d$ 同形（阻性负载）；
- $i_s$：正半周 $i_s=i_d$，负半周 $i_s=-i_d$，所以 $i_s = v_s/R$，是**与 $v_s$ 同相的正弦波**（PF = 1）；
- $i_{diode1,2}$：只在正半周导通，波形是**正弦半波**（不是方波）；
- $v_{diode1,2}$：导通段≈0，关断段承受反压（峰值达 $V_{smax}$）。

### 1.2 感性负载（理想化 R-L / 大电感）（P4）

![单相桥·感性负载](/obsidian-assets/0c27dc1512dedc96.png)

负载为**理想化电感**（电流被完全平直，$i_d = I_d$ 恒流源近似）：

- 导通逻辑与阻性时相同：正半周 D₁D₂、负半周 D₃D₄ 交替，**在电压过零点处自然换流**；
- $v_d$ 波形仍为 |sin| 全波整流（有过零点），平均值不变；
- $i_d$ 平直为 $I_d$；
- $i_s$ 变为 **±I_d 的方波**（与 $v_s$ 同相）→ 非正弦；
- $i_{diode1,2}$：幅值 $I_d$ 的 180° 方波；
- $v_{diode1,2}$：导通段 0，关断段 $-v_d$（峰值 $V_{smax}$）。

$V_d = \frac{2V_{smax}}{\pi}, \qquad I_d = \frac{V_d}{R}$

两种负载的 $V_d$ 相同（理想电感上直流压降为零），区别全在电流：阻性负载时 $i_s$ 是正弦，大电感负载时 $i_s$ 变成方波——这才引出下一节的谐波与功率因数问题。

## 2. 补充 2-1：谐波分析与功率因数（Supplement 2-1）

### 2.1 谐波分析（Harmonic Analysis）（P5）

任何周期波形都可用**傅里叶级数**表达：

$f = f_{mean} + \sum_n a_n \sin n\omega t + \sum_n b_n \cos n\omega t$

各系数（对周期 $2\pi$ 积分）：

$f_{mean} = \frac{1}{2\pi}\int_0^{2\pi} f \, d(\omega t)$

$a_n = \frac{1}{\pi}\int_0^{2\pi} f \sin n\omega t \, d(\omega t), \qquad b_n = \frac{1}{\pi}\int_0^{2\pi} f \cos n\omega t \, d(\omega t)$

有效值（rms）关系：

- 第 n 次谐波有效值：  
  $f_{n(rms)} = \frac{1}{\sqrt{2}}\sqrt{a_n^2 + b_n^2}$
- 总有效值（含直流分量）：  
  $f_{rms} = \sqrt{f_{mean}^2 + \sum_n f_{n(rms)}^2}$
- 纯交流分量有效值（去掉直流）：  
  $f_{R(rms)} = \sqrt{\sum_n f_{n(rms)}^2}$

两个质量指标：

| 指标           | 定义                                 | 适用对象                  |
| ------------ | ---------------------------------- | --------------------- |
| **纹波系数** γ_f | $\gamma_f = f_{R(rms)} / f_{mean}$ | 直流电压（衡量纹波大小），我们希望越小越好 |
| **畸变因数** ξ_f | $\xi_f = f_{1(rms)} / f_{rms}$     | 交流电流（衡量波形偏离基波程度）      |

### 2.2 功率因数（Power Factor）（P6）

$\lambda = \frac{P}{S}$

- 有功功率（mean power）：  
  $P = U_0 I_0 + \sum_n U_{n(rms)} I_{n(rms)} \cos\varphi_n$
- 视在功率（apparent power）：  
  $S = U_{rms} I_{rms}$

当**电网相电压为正弦**时（只有基波电压做功）：

$P = U_{1(rms)} I_{1(rms)} \cos\varphi_1, \qquad S = U_{1(rms)} \, I_{rms}$

$\boxed{\lambda = \xi_i \cos\varphi_1}$

- $\xi_i$ —— 输入电流畸变因数（distortion factor）；
- $\cos\varphi_1$ —— 输入位移因数（displacement factor，基波电压与基波电流的相位差余弦）。

> 结论：即使电压正弦、基波电流与电压同相（$\cos\varphi_1=1$），只要电流含谐波（$\xi_i<1$），功率因数就 < 1。谐波电流只占视在功率、不传递有功。

### 2.3 单相桥的输入电流谐波（P7）

![单相桥输入电流](/obsidian-assets/017d366e622f8519.png)

感性负载下 $i_s$ 为 ±I_d 方波。它的有效值 $I_s = I_d$；对方波做傅里叶分解，基波幅值为 $\frac{4}{\pi}I_d$，故基波有效值：

$$
I_{s1}=\frac{4}{\pi}\cdot\frac{I_d}{\sqrt2}=\frac{2\sqrt2}{\pi}I_d\approx0.9I_d
$$

谐波只有奇次，第 n 次幅值为基波的 1/n（3、5、7…次分别为 1/3、1/5、1/7）。

- 畸变因数：$\xi = I_{s1}/I_s = 0.9$
- 功率因数：$PF = \xi \cos\varphi_1 = 0.9\cos\varphi_1$（位移角为 0 时 PF ≈ 0.9）

## 3. 单相桥：考虑交流侧电感的换流分析（P8–P9）

### 3.1 换流物理过程（P8）

![换流过程](/obsidian-assets/0cb7f813d620afd5.png)

电源侧串有电感 $L_s$（线路电感），考察电流从 D₃D₄ 换到 D₁D₂ 的过程：

由于 $L_s$ 中的电流不能突变，换流需要一段时间——**换流期（重叠期）内 D₁~D₄ 四管同时导通**，$v_d = 0$（A、B 两点被短接，电源电压全部降在 $L_s$ 上）。

换流期间各电流走向（换流回路电流 $i_u$）：

| 电流               | 变化          |
| ---------------- | ----------- |
| $i_u$            | 0 → I_d     |
| $i_{D3}, i_{D4}$ | I_d → 0（减小） |
| $i_{D1}, i_{D2}$ | 0 → I_d（增大） |
| $i_s$            | −I_d → I_d  |

（课件分两步图示：$i_u$ 先从 0 升到 I_d/2，再从 I_d/2 升到 I_d；每一步都是 i_D1、i_D2 增大，i_D3、i_D4 减小。）

### 3.2 换流重叠角 u 的定量计算（P9）

![重叠角计算](/obsidian-assets/a3ba7deec3179479.png)

换流期间回路方程（以过零点为 t = 0，此时 $i_s = -I_d$）：

$v_s = V_{smax}\sin\omega t = L_s \frac{di_s}{dt}$

积分得：

$i_s = \frac{V_{smax}}{\omega L_s}(1 - \cos\omega t) - I_d$

当 $\omega t = u$（**重叠角 overlap angle**）时换流完成，$i_s = I_d$：

$I_d = \frac{V_{smax}}{\omega L_s}(1 - \cos u) - I_d$

$\boxed{\cos u = 1 - \frac{2\omega L_s I_d}{V_{smax}}}$

换流期间 $v_d = 0$，损失了部分输出面积，直流平均电压降为：

$\boxed{V_d = \frac{2V_{smax}}{\pi} \cdot \frac{1 + \cos u}{2}}$

把 $\cos u$ 代进去，可以得到一个更直观的等价形式：

$$
V_d=\frac{2V_{smax}}{\pi}-\frac{2\omega L_s}{\pi}I_d
$$

即 $L_s$ 相当于在直流侧串了一个"等效电阻" $2\omega L_s/\pi$——它不消耗功率，只是让输出电压随负载电流增大而下降。物理来源：每次换流，电源要在 $L_s$ 上"花掉"一块伏秒面积 $A_u=\int_0^u V_{smax}\sin\theta\,d\theta=2\omega L_sI_d$ 才能把电流从 $-I_d$ 扳到 $+I_d$，每半个周期损失一块，平均到 $\pi$ 上就是 $2\omega L_sI_d/\pi$。

波形特征：$v_d$ 出现换流凹口（notch），$i_s$ 由理想方波变为带斜坡的梯形波。电流的过零被推迟了约 $u/2$，基波电流也就滞后电压约 $u/2$，所以有 $L_s$ 时功率因数会略低于 0.9。

## 4. 实际单相桥：带滤波电容的整流器（P10–P11）

### 4.1 实用电路与等效电路（P10）

![实际带滤波电容整流器](/obsidian-assets/f24d4d8b3ffa17db.png)

实际中最常见的电路：**二极管桥 + 直流侧滤波电容 C_d**（交流侧仍有 L_s、R_s）。

**半周期等效电路**：整流桥输出近似为 |v_s| 电压源串 L_s、R_s，后接 C_d 与 R_load 并联。仅当 |v_s| > v_d 时二极管才导通、向电容充电。

课件算例参数：

$V_s = 120\,\text{V}\ (60\,\text{Hz}),\quad L_s = 1\,\text{mH},\quad R_s = 1\,\text{m}\Omega,\quad C_d = 100\,\mu\text{F},\quad R_{load} = 20\,\Omega$

波形特征（原图下方波形）：

- $v_d$：在 |v_s| 峰值附近充电、随后经 R_load 放电的**锯齿状纹波**，平均值接近峰值 $V_{smax}$，明显高于无电容时的 $2V_{smax}/\pi$；
- $i_s$：只有 $|v_s| > v_d$ 时二极管才导通，所以电流只在峰值附近的窄区间流动 → **很窄的尖峰脉冲电流**（基波 $i_{s1}$ 与 $v_s$ 的相位差见图中 φ₁）。

### 4.2 网侧电压畸变（Line-Voltage Distortion）（P11）

![网侧电压畸变](/obsidian-assets/de22aa5c6b9f697a.png)

窄脉冲电流流经电源内阻抗（L_s 等），在阻抗上产生压降，使**电网电压波形本身发生畸变**——这就是整流器作为"电力公害"影响其他用户的原因，也是滤波电容整流器需要功率因数校正（PFC）的动因。

## 5. 三相桥式二极管整流器（Three-phase Bridge）（P12–P14）

### 5.1 电路结构与输出电压（P12）

![三相桥电路与波形](/obsidian-assets/c4e716c87367c29d.png)

结构：6 只二极管，共阳极组（D₄D₆D₂）+ 共阴极组（D₁D₃D₅），任意时刻**共阴极组中接最高相电位的一管、共阳极组中接最低相电位的一管同时导通**。

输出电压 = 线电压包络（每周期 6 个脉波，6-pulse）：

$\boxed{V_d = \frac{3\sqrt{3}\,V_{ph(max)}}{\pi} = \frac{3\,V_{line(max)}}{\pi}}$

其中 $V_{ph(max)}$ 为相电压峰值，$V_{line(max)}=\sqrt{3}V_{ph(max)}$ 为线电压峰值。

波形要点（原图右侧）：

- 负载上端相对中性点 N 的电压 = 三相相电压的上包络；
- 负载下端 = 三相相电压的下包络；
- $v_d$ = 上、下包络之差（6 脉波纹波）；
- $i_d$：大电感下平直为 I_d；
- 各二极管电流 $i_1$~$i_6$：幅值 I_d、宽 120° 的方波；
- 网侧电流：$i_a = i_1 - i_4$，$i_b = i_3 - i_6$，$i_c = i_5 - i_2$（每相接一个共阴极管和一个共阳极管），为 ±I_d、正负各导通 120°、中间各有 60° 为零的**准方波**；
- 二极管电压 $v_{D1}$ = 相电压减去上包络，承受反压。

### 5.2 输入电流谐波与功率因数（P13）

![三相桥输入电流](/obsidian-assets/6859a04ab4eec6d4.png)

准方波电流（每半周导通 120°）的有效值与基波有效值：

$$
I_s=\sqrt{\tfrac23}\,I_d\approx0.816I_d,\qquad
I_{s1}=\frac{\sqrt6}{\pi}I_d\approx0.78I_d
$$

谐波只剩 $6k\pm1$ 次（5、7、11、13…），3 的倍数次谐波被 120° 导通宽度自然消掉了。

- 畸变因数：$\xi = I_{s1}/I_s = 3/\pi \approx 0.955$
- 功率因数：$PF = \xi\cos\varphi_1 = 0.955$（位移角为 0 时）

> 对比记忆：单相桥 ξ = 0.9，三相桥 ξ = 0.955 —— 相数越多，电流波形越接近正弦，功率因数越高。

### 5.3 三相桥的换流分析（P14）

![三相桥换流](/obsidian-assets/80537ce67e488ac2.png)

考虑交流侧电感 $L_s$，考察 a 相换流（i_a 从 0 升到 I_d，c 相电流 I_d 降到 0）：

换流期间 D₁、D₅ 同时导通，a、c 两相经两只 $L_s$ 短接，换流回路由线电压驱动：

$v_a - v_c = V_{line(max)}\sin\omega t = 2L_s\frac{di_u}{dt}$

> 课件此式写作 $\sqrt3\,V_{line(max)}\sin\omega t$，应为笔误：线电压幅值就是 $\sqrt3V_{ph(max)} = V_{line(max)}$，下一行积分结果的系数 $V_{line(max)}/(2\omega L_s)$ 也印证了这一点。

以换流起点 t = 0、$i_u = 0$ 积分：

$i_a = i_u = \frac{V_{line(max)}}{2\omega L_s}(1 - \cos\omega t)$

当 $\omega t = u$ 时 $i_a = I_d$（记 $X = \omega L_s$）：

$\boxed{\cos u = 1 - \frac{2X I_d}{V_{line(max)}}}$

换流期间 $v_d$ 出现凹口，输出平均电压降为：

$\boxed{V_d = \frac{3V_{line(max)}}{\pi} \cdot \frac{1 + \cos u}{2}}$

等价形式：

$$
V_d=\frac{3V_{line(max)}}{\pi}-\frac{3\omega L_s}{\pi}I_d
$$

（每 60° 换流一次，每次损失伏秒面积 $A_u=\omega L_sI_d$，一个周期 6 次，$6\omega L_sI_d/2\pi$。）

> 与单相结论形式一致：都是"无重叠角的 V_d × (1+cos u)/2"。重叠角 u 随 $L_s I_d$ 增大而增大，使 V_d 下降。

## 6. 工程应用：SS1 型电力机车（P15）

![SS1 电力机车](/obsidian-assets/627c0ad8c8658f07.png)

- **SS1 型电力机车（1968 年，中国第一代干线电力机车）**：受电弓 → 主断路器 → 牵引变压器 → **整流柜（二极管整流）** → 平波电抗器 → 直流牵引电机。即"AC 电源 + 带分接头变压器 → 二极管整流 → DC 电机"架构，电压调节靠变压器分接头。
- 后续演进为**晶闸管（Thyristor）相控整流 AC/DC**：用 T₁~T₆ 可控器件直接调节输出电压，省去分接头调压。这是下一章（相控整流）的引子。

## 7. 本章总结（P16）

**二极管整流器 = 不控型 AC-DC 变换。**

核心方法：**按关键波形分析功能**（单相、三相整流器均要求掌握）：

1. **关键波形**：
   - 直流输出 $v_d$、$i_d$；
   - 交流输入 $v_s$、$i_s$；
   - 器件电压电流 $v_{diode}$、$i_{diode}$。
2. **按波形进行计算**：
   - 直流输出：$V_d$、$I_d$；
   - 交流输入：基波 $I_{s1}$、畸变因数 ξ、功率因数 PF。
3. **考虑负载与线路参数的影响**：
   - 交流侧电感 → 换流重叠角 u → V_d 下降、波形出现换流凹口。

### 关键公式速查

| 电路 | V_d | ξ | PF |
| --- | --- | --- | --- |
| 单相桥（无 L_s） | $2V_{smax}/\pi \approx 0.9V_s$ | 0.9 | 0.9 |
