# 电力电子 · 第 2 讲 Power Devices 学习笔记

> **来源课件**：`2.Devices_4360231.pdf`（Chapter 1 Power Devices）
> **配图**：均为原课件截图，存于 `assets/2-Devices/`，每张图下方标注对应页码（Pxx）。
> **已剔除**：章节末尾文献列表与作者署名（Bimal Bose 2014、Millán 2014、Jones 2016、Raju 2014）、"The End" 等纯版式页。
> **保留并展开**：全部器件特性、损耗模型、结构图、特性曲线、开关波形、额定与结论、对比表。

**本讲定位（课堂讲法）**：上一讲 Introduction 立好"为什么必须用开关"的世界观；本讲接上"**用什么开关**"。课堂主线非常清楚：

1. 先立"理想开关"这个靶子（理想特性）；
2. 再讲真实器件为什么会偏离理想（三种状态 + 两类损耗）；
3. 把课程要研究的器件分三类；
4. 再**逐个**解剖：二极管 → 晶闸管 → 功率晶体管 → MOSFET → IGBT（每个都按"结构/符号 → 特性 → 开关过程 → 额定 → 结论"讲）；
5. 用 SOA 和六维对比表收口；
6. 最后点出宽禁带（SiC/GaN）作为演进方向。

## 一、先立靶子：理想功率器件的七条特性（P2）

![理想功率器件特性与符号](/obsidian-assets/b1d9e29195901584.png)

课堂先问一句："如果有一个**完美开关**，它应该长什么样？"课件给出 7 条：

1. 可控开通和/或关断（Controlled turn-on or/and -off）
2. 触发功率要求为零（Zero gate firing power requirement）
3. 导通时电流只能沿给定方向流动（When on, current flows only in given direction）
4. 通态与阻断损耗为零（V_on-state = 0，i_leakage = 0）
5. 电流、电压额定值无限（Unlimited current and voltage ratings）
6. 开通与关断时间瞬时（Instant turn-on and -off times）
7. 成本低（Low cost）

课件右下角画了**理想器件符号**：一个受控开关，标注端电压 vT 与端电流 iT。

> **关键框（图中蓝框）**：`Idealized Characteristics — for analyzing the circuit topology`。
> 这句话点明了**为什么要先讲理想特性**：后面第 3、4 章的整流电路分析，全部建立在"理想器件"假设上（压降为零、开关瞬时）。而工程选型时再回到"真实特性"。所以"理想"与"真实"是**两个不同层次的问题**，课堂上明确区分，别混淆。

## 二、再看真实：三种开关状态与两类损耗（P3、P4）

![真实器件：开关状态](/obsidian-assets/3f375ea77af8e82e.png)

**真实特性（Real Characteristics — for the actual circuit design）**。课堂按"器件在三种状态下、工程上要关心什么参数"来讲：

| 状态 | 关心的参数 | 工程含义 |
|---|---|---|
| on state（静态导通） | 电流定额（平均值 / RMS / 峰值）、通态压降或通态电阻 | 决定导通损耗与发热 |
| off state（静态阻断） | 电压定额（正向 / 反向峰值） | 决定耐压等级 |
| commutation（开关瞬态） | dv/dt、di/dt 定额、开通时间、关断时间 | 决定开关损耗与能否高频 |

![真实开关能量损耗](/obsidian-assets/0e5d3d3426d5c98c.png)

课堂接着把损耗**拆成两块**——这是本页的灵魂：

```
Wstatic = Won + Woff
        = ∫on-time ion(t)·von-state(t) dt + ∫off-time ileakage(t)·voff(t) dt
Wdynamic = ∫turn-on i(t)·v(t) dt + ∫turn-off i(t)·v(t) dt
Paverage = (Wstatic + Wswitch) / T
```

图中 (a) 开通、(b) 关断把 i(t)、v(t)、p=vi 三条曲线叠在一起，阴影 "Area = power × time" 即**一次开关过程的能量 = i·v 曲线下的面积**。

> **课堂结论句（务必记住）**：
> - **Pstatic —— major loss at lower-frequency operation**（低频时的主要损耗）；
> - **Pswitch —— significant at high-frequency operation**（高频时变得显著）。
>
> 由此引出整门课一条暗线：**要提高开关频率（从而缩小无源元件体积），就必须压低开关损耗——这就逼着器件往"快"的方向演进**（BJT → MOSFET → IGBT → 宽禁带）。

## 三、研究重点与器件三分类（P5）

课堂在这里明确"本课程关注什么、不关注什么"：

- **关注终端特性（terminal characteristics），而非内部物理（internal physics）**——即从外部看它的能力。
- 具体看三个能力：**current、voltage、switching speed capabilities**。
- 器件分三类：

| 类别 | 器件 | 说明 |
|---|---|---|
| 不可控 uncontrolled | 功率二极管 power diode | 通断由主电路决定 |
| 半控 semi-controlled | SCR（晶闸管） | 可触发开通，关断靠电流过零 |
| 全控 controllable | BJT、MOSFET、IGBT | 开通/关断均可控 |

## 四、逐个解剖五类器件

### 4-1 功率二极管（P6–P11）

**① 结构、符号与输出特性（P6）**

![功率二极管结构与特性](/obsidian-assets/9a81f8e39797f386.png)

- 左侧：PN 结构与电路符号（箭头方向 = 正向电流方向）。
- 左下：**理想特性**——正偏时沿 iD 轴一条垂线，反偏时沿 vD 轴一条水平线。
- 右侧：**真实输出特性**——正向导通有一段 "Forward volt-drop"（通态压降），反偏有微小 "Leakage current"（漏电流），继续加反压到 "Reverse breakdown"（反向击穿）。
- 结论：**V_on-state ~ 1–3 V，I_leakage ~ negligible**。

**② 为什么做成 PiN 结构：电导调制（P7）**

![PiN 二极管结构与载流子注入](/obsidian-assets/4fe1c7a5d9927a14.png)

课堂在这里回答一个矛盾："**又要高耐压，又要低压降，怎么办？**"

- 高耐压需要厚而低掺杂的 **n⁻ 漂移区**（图中 250 μm 厚；掺杂 Na~10¹⁹、n⁻~10¹⁴）。
- 但厚低掺杂区电阻很大 → 通态压降会很高。
- 解法是**电导调制（conductivity modulation）**：正偏时从 p⁺、n⁺ 两端向 n⁻ 区**注入大量过剩载流子**（右图 np(x)、pn(x) 分布曲线），使 n⁻ 区电阻**大幅下降**。
- 代价：器件变成**双极型（bipolar）**——电子与空穴同时参与导电；这也埋下隐患：关断时**必须先把存储的少数载流子抽走**（引出下页的 tr、Qr）。

**③ 开关波形：反向恢复（P8）**

![典型二极管开关波形](/obsidian-assets/786fa5f44f20ca3d.png)

一页图讲清二极管的两个瞬态。上半 v(t)、下半 i(t)，分 (1)~(6) 六个阶段：

- **开通**：电压先过冲（overshoot）再回落。
- **关断**：电流从 If 下降、**过零反向**，冲到 **反向恢复电流 Ir**，再沿 di/dt 回到零；这段电流围出的阴影面积即 **反向恢复电荷 −Qr**，对应时间即**反向恢复时间 tr**。

> **考点**：二极管关断时电流为何先"反向"？
> 答：要先把导通期间存储在 n⁻ 区的**少数载流子抽走**；抽走前结仍正向偏置，故电流反向流动。储荷越多，tr 越长、Qr 越大，开关损耗越大——这正是"快恢复二极管"要解决的问题。

**④ 开通瞬态（P9）与关断瞬态（P10）**

![二极管开通瞬态](/obsidian-assets/32265f4baf7b547c.png)

![二极管关断瞬态](/obsidian-assets/ade5770481c94cca.png)

两页把上面的波形对应到**器件内部载流子的动作**：

- **开通**：反偏（宽耗尽区、高耐压）→ 正偏，向 n⁻ 注入少数载流子以降低通态电阻 → 正向导通（存储电荷 q、低压降）。
- **关断**：正向导通 → 先移走存储电荷 q → 再建立耗尽区（承受反压）。
- 注意关断第 (4) 阶段器件**仍正偏**（正在抽存荷），第 (5) 阶段才真正反偏。

**⑤ 额定与结论（P11）**

![功率二极管结论](/obsidian-assets/4e3d7ca69ce5f4cb.png)

| 类型 | 额定（up to） | 开关时间 |
|---|---|---|
| 工频二极管 Line-frequency Diodes | 9000 V / 8400 A | ~100 μs |
| 快恢复二极管 Fast Recovery Diodes | 4500 V / 1000 A | 反向恢复时间 < 1 μs |

**结论**：无源器件；只导通正向电流；电流试图反向时自动关断；可阻断反向电压；正向压降低、功率定额高；**但开关损耗大、开关频率受限**。

### 4-2 晶闸管 / SCR（P12–P15）

**① 结构与正反馈机理（P12）**

![晶闸管结构与等效电路](/obsidian-assets/0e5a08417cad0ad3.png)

- 结构：P-N-P-N 四层三结，门极从中间 p 层引出。
- 等效电路：可拆成 PNP + NPN 两晶体管**互相耦合**。
- 课堂核心：**正反馈闩锁**——`Ig↑ → Ib1↑ → Ia,Ic↑ → Ib2↑ …`（图中回路），门极一个脉冲即可触发，之后**自我维持**，即使撤掉 Ig 也继续导通。

**② 特性曲线（P13）**

![晶闸管特性](/obsidian-assets/34bdd7d0947271f6.png)

- 真实特性：反偏 → Reverse blocking；正偏未触发 → Forward leakage current；加门极电流 Ig 后，转折电压随 Ig 增大而下降（图中一簇曲线）；越过 **latching current（擎住电流）** 后进入低压大电流导通态；电流降到 **holding current（维持电流）** 以下才关断。
- 要点：Von ~ 1–3 V；漏电可忽略；**正向击穿电压 ≈ 反向击穿电压**；**2× 维持电流 ≈ 擎住电流**。
- 理想特性：正反向都能阻断，正向一触发就导通。

**③ 简单电路中的开/关断条件（P14）**

![晶闸管简单电路与波形](/obsidian-assets/e5ff5e21c48c25b9.png)

- 电路 + 波形（vs 正弦，只有正半周导通；下方 iG 脉冲）。
- **成功开通**：门极脉冲电流需**上升快、宽度足够**，使阳极电流冲过擎住值。
- **成功关断**：需施加**反向电压**且持续时间**大于关断间隔**，让阻断结恢复阻断能力。→ 这正是"半控、靠自然换相关断"的根源。

**④ 额定与结论（P15）**

- 工频晶闸管额定 up to **9500 V / 5000 A**，开关时间 ~200 μs。
- 结论：半控；正偏下由门极脉冲闩锁；电流反向才关断；**双向可阻断电压**；低压降、高定额；开关损耗大、频率受限。

### 4-3 功率晶体管（GTR / BJT）（P16–P18）

![功率晶体管结构、符号与特性](/obsidian-assets/1badbab835d06f99.png)

- NPN / PNP 的结构与符号；右图为 NPN 输出特性（一族 Ib 曲线）。
- 特性：饱和电压（V_on-state）~ 1–2 V；反向击穿电压较小。
- 理想开关特性：画成 On / Off 两态。

![功率晶体管基极电流控制](/obsidian-assets/d430c43a4f98e55d.png)

课堂在这里强调**基极电流要"刚刚好"**（本页是全讲的点睛处）：

- **太小** → 退出饱和进入放大区，VCE 升高 → **二次击穿（second breakdown）！**
- **太大** → 深饱和，存储电荷多 → **关断太慢！**
- 三条工程准则：
  a) 开通时基极电流足够大以快速开通；
  b) 集电极电流变化要有对应基极电流匹配；
  c) 关断时基极加**负偏置**以加速载流子扫出。

结论（P18）：基极控制复杂、开关损耗高；过去常用，现多用于特定场合，**已被 MOSFET/IGBT 取代**。额定 up to 1400 V / 400 A，频率 up to 10 kHz。

### 4-4 功率 MOSFET（P19–P22）

![MOSFET 符号与剖面结构](/obsidian-assets/2d7b6295a787cf09.png)

- 符号 + 简化剖面：**只有电子导电 → 单极型（unipolar）**。
- 图中标出沟道电流与体二极管（Diode current）两股电流通道。

![MOSFET 体二极管](/obsidian-assets/882772186c636783.png)

**体二极管（body diode）四条性质（考点）**：
- p-n 结形成与沟道并联的有效二极管；
- 负的漏源电压会使体二极管正偏导通；
- 它能流过 MOSFET 的额定全电流；
- **但其开关速度未优化——慢、Qr 大**（故高频场合常外并快恢复二极管）。

![MOSFET 电路、输出特性与理想开关特性](/obsidian-assets/b5dbf0acfba10f0e.png)

- 输出特性：一族 VGS 曲线，低 VDS 段呈 **constant resistance（恒电阻）**。
- 理想开关特性：On / Off 两态。
- 四条理想化特性：
  - **极快开关**：电压控制、无存储电荷；
  - **导通损耗高**：恒定导通电阻；
  - **功率定额低**：难以同时高电压高电流；
  - **电阻正温度系数** → 易于直接并联。

结论（P22）：栅压控制（易驱动）；可正向导通/阻断，也能反向导通（体二极管）；单极型、速度快；**导通电阻随额定电压上升而急剧增大**。额定 up to 1200 V / 300 A，频率 up to 100 kHz。

### 4-5 IGBT（P23–P24）

![IGBT 剖面、等效电路与符号](/obsidian-assets/b3c26ecfb4591f7b.png)

课堂一句话概括 IGBT 的定位：**"输出特性像功率晶体管（双极、低压降），控制特性像 MOSFET（电压控、易驱动）"**；需外接二极管（an external diode）。理想特性画法同 MOSFET。

结论（P24）：当今**低/中功率应用最广泛**；正向压降低（2–4 V 典型）；驱动容易；**比 MOSFET 慢、比 BJT 快**。额定 up to 6500 V / 3600 A，频率 up to 20 kHz。

## 五、安全工作区 SOA（P25）

![安全工作区](/obsidian-assets/cb61d5707f1c94da.png)

在 IC–VCE 平面上，由三条边界围成：

- **Current limit**（水平段，电流极限）；
- **Power limit**（斜段，功率极限）；
- **Voltage limit**（垂直段，电压极限）。

器件必须工作在 SOA 内。

## 六、器件六维对比表（P26–P27）

课堂基于"理想特性"的 6 条，给各器件按 高/中/低 打分（考试常考，务必背下）：

| 指标 | 高 (high) | 中 (medium) | 低 (low) |
|---|---|---|---|
| 1. 可控开通/关断 | MOSFET、IGBT（电压控） | SCR、BJT（电流控） | — |
| 2. 触发功率要求为零 | MOSFET、IGBT | SCR、BJT | — |
| 3. 导通损耗为零 | SCR | BJT、IGBT | MOSFET |
| 4. 电压/电流额定无限 | SCR | IGBT、BJT | MOSFET |
| 5. 瞬时开通/关断 | MOSFET | IGBT、BJT | SCR |
| 6. 成本低 | SCR | BJT、IGBT | MOSFET |

> **读法**：SCR 综合是"高定额、低成本，但慢且半控"；MOSFET 是"快、易驱动，但损耗高、定额低、且贵"；IGBT 多项取"中"，是折中王，故成为中高功率主力。

## 七、发展方向与宽禁带（P28–P29）

- 研发主线：不断逼近理想电子开关——**功率越来越大、开关越来越快、控制越来越容易**。
- 现状：中高功率最重要器件是 **IGBT**；ABB 1997 年推出 **IGCT**，曾与高压 IGBT 竞争，但逐渐掉队。
- 方向：**SiC、GaN**。已商用 SiC SBD（1200 V/50 A）、SiC MOSFET（1200 V/100 A 半桥）、JBS（600 V/20 A）；未来有 10 kV p-i-n、15 kV IGBT。
