# 电力电子 · 第 4 讲 Thyristor AC-DC Converters 学习笔记

> **来源课件**：`4.AC-DC_49580402.pdf`（Chapter 3 Thyristor AC-DC Converters）
> **配图**：均为原课件截图，存于 `assets/4-Thyristor-AC-DC/`，图注标注页码（Pxx）。
> **已剔除**：章节末尾 "The End"、纯版式页。
> **保留并展开**：晶闸管特性与触发、单相/三相桥的可控 Vd 推导、谐波与功率因数、交流侧电感换相、逆变模式与灭弧角、电压缺口、实际负载、HVDC 应用。

**本讲定位（课堂讲法）**：承接第 3 讲——上讲的二极管整流器**不可控**；本讲把二极管换成**晶闸管**，于是同一套电路变成**可控**：靠调节**触发延迟角 α** 得到想要的直流电压。更进一步，当 α 足够大时，同一电路还能**把直流变回交流**（逆变），所以晶闸管变换器是**两象限变换器**（整流 + 逆变）。分析套路与上一讲完全一致：**按波形分析**。

---

## 一、晶闸管特性与符号（P2）

![晶闸管结构、符号与特性](/obsidian-assets/2d006fbd210f7cc6.png)

- 结构：P-N-P-N 四层，门极引出；符号如上。
- 真实特性（右上）：正偏未触发时只有 Forward leakage current；加 Ig 后转折电压下降；导通后是低压大电流。
- 理想特性（右下）：正、反方向均可阻断电压，正向触发后导通（Off-to-on）。

> 课堂提示：晶闸管与二极管的最大区别是**"何时开始导通"可控（由 α 决定）**，但"何时关断"仍不可控（靠主电路电流过零）——半控器件的本质。

---

## 二、简单电路：α 控制的原理（P3）

![简单电路与 P3 波形](/obsidian-assets/ecfd7df676b6c50f.png)

最简单的可控整流电路：交流源 vs + 一个晶闸管 + 电阻 R。

- **触发延迟角 α**：从**供电电压过零点**算起、延迟 α 再给门极脉冲（图中下方 iG 脉冲位于 α 处）。
- 波形：vd 只在 α~π 区间随 vs 导通（其余时间截止）；门极脉冲每周期一次。

**输出电压平均值（半波可控整流）**：

```
Vd = (1/2π) ∫_α^π Vs(max)·sinθ dθ = (1/2π)·Vs(max)·(1 + cosα)
```

> **课堂要点**：α 就是"**从电压过零到触发之间的延时**"，它直接决定了导通区间的起点，从而决定 Vd。

---

## 三、晶闸管触发电路（P4）

![锯齿波移相触发电路](/obsidian-assets/2fee96ccce62567a.png)

课堂补充"α 在工程上怎么产生"：

- 交流电压同步（vsynchronization）→ **锯齿波发生器（Saw-tooth Generator）**产生 vs t。
- 与**控制电压 vcontrol** 送**比较器与逻辑（Comparator and Logic）**，交点即触发时刻。
- 改变 vcontrol 的幅值，就改变交点位置 → 改变 α → 改变 Vd。

> 结论：**触发电路 = 移相电路**，用直流控制电压连续调节 α。课件注明有现成 IC（ICs available）。

## 四、单相桥式晶闸管变换器（P5、P6、P7）

### 4-1 电路与课堂三问（P5）

![单相桥电路与波形、课堂三问](/obsidian-assets/595db9eacaca0530.png)

- 电路与相控（T1、T2 与 T3、T4 分正负半周）；左下是触发电路（脉冲变压器给 T1、T2 门极）。
- 右侧波形：vd 的导通区间从 α 开始；is、iT、vT 波形；下方 ig1,2、ig3,4 触发脉冲。
- **课堂三问**（务必能答）：
  - Q1：触发信号的时间序列是什么？
  - Q2：一个线频周期内有多少个开关动作？
  - Q3：换相发生在何时？

### 4-2 平均直流输出电压（P6）

![单相桥平均直流电压与 Vd/Vdo–α 曲线](/obsidian-assets/50a64e3d287ca93a.png)

```
Vd = (1/π) ∫_α^{π+α} Vs(max)·sinθ dθ = (2/π)·Vs(max)·cosα
```

右下曲线给出 **Vd/Vdo ~ α** 关系（Vdo 为 α=0 时的最大输出）：

- **α < 90°：Vd > 0**，工作在 **Rectifier mode（整流）**；
- **α = 90°：Vd = 0**；
- **α > 90°：Vd < 0**，进入 **Inverter mode（逆变）**。

> 课堂提示：说明"**线换相变换器（line-commutated converter）** + **可控直流电压**"，并追问"电压与电流方向？"→ **两象限（Two-quadrant）**。

### 4-3 输入电流谐波与功率因数（P7）

![单相桥输入电流谐波与功率](/obsidian-assets/1ed869ac3edd02ee.png)

- is 仍是**准方波**，但基波相对 vs **滞后 φ1 = α**（图中 φ1 = α）。
- 谐波谱：奇次谐波 3、5、7、9 …（幅值 1/3、1/5、1/7 …）。
- 右下：有功 P、无功 Q1、视在 S 随 α 的变化曲线（α 增大 → P 下降、Q1 上升）。

```
Is1 = 0.9·Id
PF  = 0.9·cosα
```

> **考点**：与不控单相桥（PF=0.9）相比，多了一个 **cosα** —— α 越大，位移因数越低，PF 越差。这是相控整流"**用相位换电压、代价是功率因数下降**"的体现。

## 五、交流侧电感引起的换相（P8、P9）

### 5-1 换相过程（P8）

![单相桥换相电流路径](/obsidian-assets/c7f0f52d12041293.png)

与第 3 讲完全同类：换相期间两组晶闸管**同时导通**，Ls 限制电流变化速率：

```
iT1、iT2 从 0 增大到 Id
iT3、iT4 从 Id 减小到 0
```

图中三张子图用红箭头标出换相各阶段的电流路径。

### 5-2 换相定量推导（P9）

![单相桥换相推导与波形](/obsidian-assets/c4ca1085d4983424.png)

```
vs = Vs(max)·sin(ωt + α) = Ls · dis/dt
[ωt = 0,  is = −Id]
[ωt = u（overlap angle）, is = Id]   ……（换相结束）
```

- 波形 (a)：is 与基波 is1 的关系，φ1 = α + u/2。
- 波形 (b)：vd 出现缺口（阴影 Au），平均 Vd 被折减。

> **注意相位**：换相把电流基波的滞后角从 α 又推后了约 u/2 → **φ1 ≈ α + u/2**，进一步降低位移因数。

## 六、逆变模式（P10、P11）

### 6-1 单相桥逆变模式（α > 90°）（P10）

![单相桥逆变模式与灭弧角](/obsidian-assets/dbd6aea5b2d0e958.png)

```
extinction angle  γ = 180° − α − u
要求：γmin > 5°
```

- 波形：当 α > 90°，vd 的均值变负 → 直流侧"倒送"能量，进入逆变。
- **灭弧角 γ（extinction angle）**：晶闸管在电流过零后到承受正压之前、用于恢复阻断能力的时间折算角。换相重叠角 u 会**吃掉**一部分余量，故要求 γmin > 5°。
- 模式范围：
  - 整流模式：**α < 90°**
  - 逆变模式：**α : 90° ~ 180° − δmin**

### 6-2 两象限变换器（P11）

![晶闸管变换器 Vd–Id 平面](/obsidian-assets/c4030ada78383df5.png)

- 晶闸管变换器的功能：**线频交流 → 可控直流**。
- Vd–Id 平面（右）：第一象限标 "Rectification"、第三象限标 "Inversion"，**只能在这两个象限工作 → 两象限**。
- 边界说明：电压受"电路结构与输入电压"限制；电流受"器件电流定额"限制。

> **一句话总结**：α 在 0~90° 整流、90°~180° 逆变；由于电流方向不变、电压可正可负，故为**两象限**（不能四象限，因为电流不可反向）。

## 八、实际负载与实用变换器（P16）

![带实际负载的实用晶闸管变换器](/obsidian-assets/54a27aa99d02c29d.png)

- 实际直流负载建模为 **rd + Ld + Ed**（电阻 + 电感 + 反电势，如直流电机）。
- 由于有 Ed 与 Ld，vd 的脉动被平滑、ia 接近方波，且 Ed 参与决定电流大小。

## 十、电压缺口（Voltage Notching）（P18）

![电压缺口](/obsidian-assets/886094c9f3bc5e23.png)

- 电路：交流侧 Ls1、Ls2，PCC 处接**其它设备（Equipment）**与并联电容 Cs。
- 换相瞬间多个晶闸管同时导通，会在线电压 vLL 上产生**瞬间的电压缺口（notching）**（波形 (c) 中的锯齿）。
- 定量：缺口深度 ≈ √2·VLL·sinα，缺口面积 A = ωLs·Id（图中给出）。

> **要点**：电压缺口是晶闸管（相控）变换器**特有的电能质量问题**，会干扰同一母线上的其它设备；工程上要靠进线电抗、滤波、Snubber（图中有 Snubber）等缓解。

## 十一、工程应用：HVDC 换流站（P19）

![HVDC 换流站](/obsidian-assets/19eedcc090ea85d8.png)

- 结构：AC Source 1 → 变压器 → **整流器** → 直流线路（含平波电抗）→ **逆变器** → 变压器 → AC Source 2。
- 传送"Real Power（有功）"，两端交换"Reactive Power（无功）"。
- 实际工程：HVDC 换流站里大量**晶闸管阀塔**串联堆叠（左下照片 → 阀塔特写 → 单个 thyristor 器件），是晶闸管最大的应用场景之一。

---

## 十二、本讲总结（P20）

- 晶闸管 AC-DC = **可控直流、两象限**。
- 分析方法：**按关键波形**。单相与三相都要掌握：
  - DC 输出 vd、id；AC 输入 vs、is；器件 vT、iT；**触发延迟角 α**。
- 定量计算：DC 输出 Vd、Id；AC 输入 Is1、ξ、PF。
- 额外因素：**交流侧电感、灭弧角 γ、电压缺口（notching）**。
- 工作模式：**整流模式 & 逆变模式**。
