## 本讲提纲：本讲回答 7 个核心问题
1. **How to generate electricity?** — 电能是怎么生产出来的？
2. **How to transmit electricity?** — 电能是怎么输送的？
3. **Why choosing power as variables in power systems?** — 电力系统分析为什么用功率而不是电流作变量？
4. **How to introduce power and complex power in AC?** — 交流系统中的功率、复功率如何定义？
5. **What are load and load curves?** — 什么是负荷与负荷曲线？
6. **What are typical load curves? Their application?** — 典型负荷曲线长什么样？有什么用？
7. **Which load curves are preferred by power systems?** — 什么样的负荷曲线对电网更“友好”？
> 第 1、2 问对应发电厂与电网，是电力系统的“硬件”；第 3–7 问对应功率、负荷，是后续潮流、短路、稳定分析的“语言基础”。

## §2 发电厂：电能生产 Power Plants: Power Generation
### 2.1 火电厂 Thermal Power Plants
**能量转换链：** 化学能（燃料）→ 热能 → 机械能 → 电能
**主要组成：**

| 系统             | 英文                 | 功能             |
| -------------- | ------------------ | -------------- |
| 燃烧系统           | Combustion System  | 燃料 → 灰，空气 → 烟气 |
| 汽水系统           | Steam-water System | 水 ↔ 蒸汽循环       |
| 电力系统           | Power System       | 发电机、变压器、输电线路   |
| 燃料供给 / 引风 / 除灰 | Fuel/Draft/Ash     | 辅助燃烧与环保        |
**火电厂流程图**

![Thermal Power Generation Process](/obsidian-assets/a4eda73c3bc1374e.png)

> 流程：燃料在锅炉燃烧 → 产生高压高温蒸汽 → 汽轮机 → 发电机 → 升压变压器并网。冷凝器由冷却塔/空冷岛提供冷却。

**在中国的情况：**
- 长期占据装机容量主体，发电量占比曾达 60% 以上（近年随新能源增长而下降）。
- 典型机组：燃煤、燃气、燃油；大型机组多为 600 MW、1000 MW 级。
- 问题：煤矿安全、运输压力、酸雨/温室气体/颗粒物、效率、不可再生。
- 发展方向：**热电联产 CHP**、超超临界、灵活性改造。

---

### 2.2 水电厂 Hydro Power Plants

**能量转换链：** 势能（水位）→ 动能（水流）→ 机械能（水轮机）→ 电能

**水电厂流程图**

![Hydro Power Generation Process](/obsidian-assets/7ed59d8b30dba311.png)

> 关键要素：水库（Reservoir）形成水头 → 进水口/控制闸门（Intake/Control Gate）→ 压力钢管（Penstock）→ 水轮机（Turbine）→ 发电机 → 变压器 → 输电线。

**优点：**

| 优点   | 说明            |
| ---- | ------------- |
| 清洁   | 几乎不直接排放 CO₂   |
| 廉价   | 无燃料成本         |
| 可再生  | 靠水文循环         |
| 综合利用 | 防洪、灌溉、航运、养殖   |
| 快速启停 | 冷启动可达分钟级，适合调峰 |
| 抽水蓄能 | 可双向运行，削峰填谷    |

**问题：**
- 建设：投资大、周期长、移民、文物保护、国防安全。
- 运行：来水受气候、水文、防洪、灌溉约束，出力波动大。

**典型案例：** 三峡（32×700 MW + 2×50 MW，年发电量约 100 TWh）、向家坝、千岛湖新安江、天荒坪/丰宁抽水蓄能。

### 2.3 核电厂 Nuclear Power Plants（自学）

**能量转换链：** 核能（核裂变）→ 热能 → 机械能 → 电能

**核电厂流程图**

![Nuclear Power Generation Process](/obsidian-assets/124d2b0b0c8cc67a.png)

> 一回路：反应堆 → 蒸汽发生器；二回路：蒸汽发生器 → 汽轮机 → 发电机 → 冷凝器。核电站与火电厂本质区别只在“热源”，后续汽轮发电部分类似。

**优缺点：**
- 省煤省油：500 MW 机组年耗煤约 150 万吨 vs 铀约 20 吨。
- 选址灵活：可建在水源受限或地下/水下/高原。
- 投资高、运行成本低；>500 MW 时经济性优于火电。
- 最大风险：放射性污染与安全处置。

## §3 电力网络：输配电 Power Network: Transmission and Distribution

### 3.1 主要组成 Main Components

电力网络可狭义理解为**不含发电机和负荷**的输配电网络，配电系统也可视为负荷侧。

**主要元件：**

| 元件     | 英文                       | 作用           |
| ------ | ------------------------ | ------------ |
| 输电线路   | Transmission Line        | 远距离、大功率送电    |
| 变电站    | Substation               | 电压变换、潮流汇集与分配 |
| 变压器    | Transformer              | 升压 / 降压      |
| 断路器    | Breaker                  | 故障隔离、开合电路    |
| 母线     | Bus                      | 多回线路的电气连接点   |
| 输电电缆   | Cable                    | 城市地下、跨海      |
| 气体绝缘线路 | GIL (Gas-Insulated Line) | 大容量、占地小      |

**带断路器的连接示意图**

![Connection Diagram with Breakers](/obsidian-assets/5e4a506b72b64cab.png)

> 发电机 → 变压器 → 母线（Bus）→ 断路器 → 输电线路 → 母线 → 变压器 → 负荷。断路器实现故障隔离和运行方式切换。

### 3.3 高压输电：为什么要高电压？

**长距离、大容量输电的约束：**

| 物理量  | 公式              |
| ---- | --------------- |
| 输送容量 | $S = UI$        |
| 电压降落 | $\Delta V = IZ$ |
| 有功损耗 | $P_L = I^2 R$   |

- 在输送功率 $S$ 一定时，提高电压 $U$ 可减小电流 $I$，从而**降低线损**和**电压降落**。
- 高电压还能提高系统**稳定性**。
- 发电机机端电压通常 10–30 kV，经变压器升压至 110–1000 kV 后远距离输送。

**电压等级与输送容量、距离的关系**

| 网络      | 电压等级      | 输送容量          | 输送距离           |
| ------- | --------- | ------------- | -------------- |
| 输电网     | 1000 kV   | 3500–5000 MVA | >1000 km       |
|         | 750 kV    | 2000–2500 MVA | >500 km（跨区）    |
|         | 500 kV    | 1000–1500 MVA | 150–850 km（跨省） |
|         | 220 kV    | 100–500 MVA   | 100–300 km（地区） |
| 高/中压配电网 | 110 kV    | 10–50 MVA     | 50–100 km（跨市）  |
|         | 35 kV     | 2–10 MVA      | 20–50 km（市内）   |
|         | 10 kV     | 0.2–2 MVA     | 6–20 km（市中心）   |
| 低压配电网   | 380/220 V | 建筑物、农村用户      | 极短距离           |

> 电压等级越高，绝缘、设备制造与运行难度越大，因此需要在技术与经济之间权衡。

---

### 3.4 额定电压的确定 Rated Voltage

**基本原则（±5%）**

- 线路 / 用电设备额定电压 = $U_N$
- 发电机额定电压 = $1.05 U_N$（补偿机端线路压降）
- 升压变压器：
  - 一次侧 = 线路电压（若直接连发电机则为 $1.05 U_N$）
  - 二次侧 = $1.1 U_N$（补偿线路压降）
- 降压变压器：
  - 一次侧 = 线路电压 $U_N$
  - 二次侧 = $1.05 U_N$ 或 $1.1 U_N$（视配电距离与负荷而定）

**额定电压沿线路的分布示意**

![Determine Rated Voltage](/obsidian-assets/fe7edfceaca35cd8.png)

> 图中可以看到：发电机出口 1.05$U_N$，升压变二次侧 1.1$U_N$，线路末端约 $U_N$，配电线路末端允许降到 0.95$U_N$。

### 3.5 高压直流输电 HVDC（自学）

**HVDC 基本结构**

![HVDC](/obsidian-assets/6681164b9c859b27.png)

> 送端：三相 AC → 变压器 → 整流器（Rectifier）→ DC 线路 → 受端逆变器（Inverter）→ 变压器 → 三相 AC。

**优点：**
- 可连接两个**非同步**交流系统，无频率约束，不存在功角稳定问题。
- 相同成本下，直流线路输送容量约为交流的 3:2；电缆优势更明显。
- 线路损耗小。
- 控制快速灵活。

**缺点：**
- 换流站投资高，等价距离约 500 km（架空线）或 50 km（电缆）。
- 产生谐波，需要滤波。
- 无自然过零点，直流断路器制造困难。

**中国典型工程：** 葛洲坝—南桥（早期 HVDC）、向家坝—上海 ±800 kV 特高压直流等。

## §4 交流电力系统的功率与复功率 Power and Complex Power
### 4.1 为什么用功率作变量？
- 电力系统是**能量系统**，分析方法以能量/功率为基础。
- 电力系统分析给定边界条件，求解内部状态；最终关心的是发电机输出功率和负荷功率。
- 发电、用电、计费都以**功率/电能**为单位，用功率作变量最自然。
### 4.2 单相瞬时功率 Single-phase Instantaneous Power
设单端口网络电压、电流为
$$
u(t)=\sqrt{2}U\cos\omega t, \quad i(t)=\sqrt{2}I\cos(\omega t-\varphi)
$$
则瞬时功率
$$
p(t)=u(t)i(t)
$$
利用三角恒等式，可分解为
$$
p(t)=\underbrace{UI\cos\varphi\,[1+\cos 2\omega t]}_{p_R(t)} + \underbrace{UI\sin\varphi\,\sin 2\omega t}_{p_X(t)}
$$
### 4.3 有功功率与无功功率
**有功功率 P（Active Power）**
$$
P = UI\cos\varphi
$$
- 物理意义：等效电阻消耗能量的速率，是瞬时功率的平均值（做功部分）。
- 单位：W、kW、MW。
**无功功率 Q（Reactive Power）**
$$
Q = UI\sin\varphi
$$
- 物理意义：等效电抗与外部电源之间能量交换的幅值，平均值为 0。
- 描述电感、电容储存和释放磁场/电场能量的现象。
- 单位：var、kvar、Mvar。
**关键特征：**
- $p_R(t)$ 周期为 $2\omega t$，平均值 $UI\cos\varphi$，恒 $\ge 0$。
- $p_X(t)$ 周期为 $2\omega t$，平均值为 0，幅值 $UI\sin\varphi$。
### 4.4 无功功率真的“无用”吗？
**不是。** 无功功率用于在交流系统中**建立和维持电场/磁场**，是电压支撑和正常运行的必要条件。
- 感性网络：$Q>0$，吸收感性无功，是**无功负荷**。
- 容性网络：$Q<0$，发出感性无功，是**无功电源**。
- 吸收感性无功 = 发出容性无功，反之亦然。
### 4.5 视在功率与复功率
**视在功率 S**
$$
S = UI, \qquad S^2 = P^2 + Q^2
$$
**复功率 $\tilde{S}$**
![Complex Power and Power Triangle](/obsidian-assets/f22c36048ce88e1d.png)
$$
\tilde{S} = \dot{U}\,\dot{I}^* = UI\angle(\delta_u - \delta_i) = UI\angle\varphi = UI\cos\varphi + jUI\sin\varphi = P + jQ
$$

| 部分  | 含义              |
| --- | --------------- |
| 实部  | 有功功率 $P$        |
| 虚部  | 无功功率 $Q$        |
| 模   | 视在功率 $S$        |
| 辐角  | 功率因数角 $\varphi$ |
**复功率的优点：**
- 把功率三角关系用复数统一表达。
- 在电路计算中，满足基尔霍夫定律的复功率**可以相加**；视在功率 $S$ 不能直接相加。
### 4.6 三相功率 Three-phase Power
**对称三相系统（以相电压、相电流表示）**
$$
P = 3U_p I_p \cos\varphi, \quad Q=3Q_p = 3U_p I_p \sin\varphi, \quad S = 3U_p I_p
$$
**用线电压、线电流表示（Y 或 Δ 接法）**
$$
P = \sqrt{3}U_L I_L \cos\varphi
$$
$$
Q = \sqrt{3}U_L I_L \sin\varphi
$$

$$
S = \sqrt{3}U_L I_L
$$

![Three-phase Power](/obsidian-assets/b63c87caf67f5154.png)

**复功率**

$$
\tilde{S} = \sqrt{3}\,\dot{U}_L\,\dot{I}_L^*\,e^{-j30°} = \sqrt{3}U_L I_L\angle\varphi = P + jQ
$$

> 其中 $\varphi$ 为每相负载的功率因数角。注意线电压与相电压之间有 $30°$ 相位差，用复功率计算时需通过 $e^{-j30°}$ 修正，或直接用相量按 $P+jQ$ 合成。

## §5 电力系统负荷：电能消费 Power System Load

### 5.1 什么是电力系统负荷？

- **电力系统负荷（Power System Load）**：所有用电设备的综合负荷，又称系统综合负荷。
- 包括工业、农业、交通、生活等各类用电设备。
- 主要设备：异步电动机、同步电动机、电炉、电热、照明、整流装置等，其中**异步电动机占主要部分**。
- 本课程研究的负荷通常指高压输电系统侧看到的负荷（一个城镇、大型工厂或配电网的总负荷）。

### 5.2 负荷关系 Power System Load Relationship

![Power System Load Relationship](/obsidian-assets/2ce49de791d51f17.png)

**从电源到用户的功率传递层次：**

| 层级     | 定义                     | 关系                   |
| ------ | ---------------------- | -------------------- |
| 用户负荷   | Customer Load          | 终端用电设备消耗的功率          |
| 综合系统负荷 | Integrated System Load | 用户负荷 + 网损            |
| 供电负荷   | Power Supply Load      | 综合系统负荷，即电网向用户输送的功率   |
| 发电负荷   | Generator Load         | 供电负荷 + 厂用电 = 发电机输出功率 |

**厂用电与网损比例（参考值）**

| 电厂类型 | 厂用电比例 |
|---|---|
| 火电厂 | 5%–8% |
| 水电厂 | 0.1%–1% |
| 核电厂 | 4%–5% |

- 网损：输配电损耗，约占 5%–10%。

### 5.3 负荷曲线 Load Curve

**定义：** 描述负荷随时间变化的曲线，是负荷预测、调度、规划的基础。

**分类：**

| 分类维度 | 类别 |
|---|---|
| 功率类型 | 有功负荷曲线、无功负荷曲线 |
| 时间尺度 | 日、周、月、年负荷曲线 |
| 对象 | 发电厂、变电站、线路、用户 |

#### 日负荷曲线 Daily Load Curves

![Typical Daily Load Curves](/obsidian-assets/fa281ea66ecdc7b3.png)

- 反映一天 24 小时内负荷变化。
- 应用：编制日调度计划、计算日电量 $A = \int_0^{24} P \,dt$（kWh）。
- 特征量：日最大负荷 $P_{\max}$、日最小负荷 $P_{\min}$、日平均负荷 $P_a$、峰谷差。
- 负荷分层：基荷（valley，谷）、腰荷（waist）、峰荷（peak）。

#### 年最大负荷曲线 Maximum Annual Load Curves

![Typical Maximum Annual Load Curves](/obsidian-assets/a277c0b0e15a7ef9.png)

- 描述一年中每月（或每日）最大负荷的变化。
- 应用：安排机组检修、扩建或新建电厂、确定备用容量。
- 图中：装机容量 > 最大负荷，差额为 $R_t$ **备用容量**；A 区为检修窗口；B 区为新增容量。

#### 年负荷持续时间曲线 Annual Load Duration Curves

![Typical Annual Load Duration Curves](/obsidian-assets/5d56d1033cc70f8d.png)

- 将全年负荷按从大到小排序，横轴为累计小时数（0–8760 h）。
- 曲线下的面积 = 全年用电量 $A = \int_0^{8760} P(t)\,dt$。
- **年最大负荷利用小时数：**

$$
T_{\max} = \frac{A}{P_{\max}}
$$

- 中国 $T_{\max}$ 约 5000 h，且呈下降趋势（说明负荷率降低、峰谷差变大）。

### 5.4 负荷预测 Load Forecast

- **目的：** 预测未来负荷变化，指导发电计划与资源配置。
- **重要性：** 电能难以大规模储存，必须“以需定发”。
- **难点：** 受工业/农业生产、地理位置、气候气象、节假日、居民生活习惯等多因素影响。
- 被认为是“尚未完全解决的问题”，是电力系统运行与规划的核心课题。

## 关键公式汇总

| 名称        | 公式                                                                          |
| --------- | --------------------------------------------------------------------------- |
| 单相瞬时功率    | $p(t)=\nu(t)i(t)=UI\cos\varphi[1+\cos2\omega t]+UI\sin\varphi\sin2\omega t$ |
| 单相有功功率    | $P=UI\cos\varphi$                                                           |
| 单相无功功率    | $Q=UI\sin\varphi$                                                           |
| 视在功率      | $S=UI=\sqrt{P^2+Q^2}$                                                       |
| 复功率       | $\tilde{S}=\dot{U}\dot{I}^*=P+jQ$                                           |
| 三相有功功率    | $P=\sqrt{3}U_L I_L\cos\varphi$                                              |
| 三相无功功率    | $Q=\sqrt{3}U_L I_L\sin\varphi$                                              |
| 三相视在功率    | $S=\sqrt{3}U_L I_L$                                                         |
| 输送容量      | $S=UI$                                                                      |
| 电压降落      | $\Delta V=IZ$                                                               |
| 线路损耗      | $P_L=I^2R$                                                                  |
| 年最大负荷利用小时 | $T_{\max}=A/P_{\max}$                                                       |
