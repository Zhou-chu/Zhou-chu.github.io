## 0. 本讲位置

课件开篇给出的稳态建模链条：

```
观察元件稳态现象  →  元件模型（等值电路）  →  系统模型（全网等值电路 + 网络方程）  →  各种求解方法
```

本讲只解决第一环：**把一条实际输电线路抽象成 r、x、g、b 四个参数，再化成能参与网络方程的等值电路。**

全讲逻辑线：**物理结构 → 电磁现象（定性）→ 参数计算（定量）→ 等值电路（工程可用）**。

## 1. 线路结构（P4–P13）

### 1.1 架空线

组成部件：**导线**（载流输送电能）、**避雷线/地线**（屏蔽雷直击导线）、**杆塔**、**绝缘子串**（把导线与接地杆塔隔离）、**金具**。

导线类型与型号：

| 类型 | 说明 | 型号 |
| --- | --- | --- |
| 单股线 Single Strand | 单根实心铜/铝线，机械强度差，**很少使用** | — |
| 多股绞线（同材料） | 多股绞合，柔韧性好 | TJ（铜绞）、LJ（铝绞）、GJ（钢绞） |
| 多股绞线（两种材料） | 钢芯铝绞线 ACSR：钢芯承力、铝线载流 | LGJ（普通）/ LGJQ（轻型）/ LGJJ（加强型） |

**型号命名规则**：字母 + 数字，数字为**主要载流部分的额定截面积**（mm²）。
例：`LGJ-150` = 额定载流截面 150 mm² 的钢芯铝绞线。

### 1.2 电缆

结构：**缆芯（导体）+ 绝缘层 + 保护层（护套/铠装）**，敷设于地下或水下。

相对架空线的特点：不受气象影响、占地少、美观；但**电容大、电抗小、投资高、不易检修**，多用于城市配电网与跨海输电。

### 1.3 特殊问题一：三相排列不对称 → 循环换位（P8）

三相导线在杆塔上的空间位置**不对称** → 各相的电感、电容**不相等**。

解决办法：**循环换位**——把线路全长分成三等份（各 l/3），每段把三相位置轮换一次，使**每一相在三个位置上的长度相等**，全线路平均后参数恢复对称。

![三相循环换位原理：三段 l/3 依次轮换 A、B、C 位置|418](/obsidian-assets/5d668c826bf94686.png)

### 1.4 特殊问题二：分裂导线（P11）

目的：**减小电抗 x 和电晕损耗**——分裂等效于增大导线半径（即增大等值半径 D′ₛ / D_S）。

电压等级越高，分裂数越多（课件示例 500 kV / 750 kV / 1000 kV）。

## 2. 电磁现象 → 四个参数（P15–P17）

| 起因     | 物理现象                          | 参数       | 接入方式 |
| ------ | ----------------------------- | -------- | ---- |
| **电流** | 电流流过导线发热，消耗有功功率               | 电阻 **R** | 串联   |
| **电流** | 交流电流 → 交变磁场 → 感应反电动势阻碍交流电流    | 电抗 **X** | 串联   |
| **电压** | 绝缘子泄漏、电晕放电，损耗有功               | 电导 **G** | 并联   |
| **电压** | 电压建立电场 → 线间及线—地电容 → 电容上流过交变电流 | 电纳 **B** | 并联   |

参数是**分布**的：沿线路均匀分布的单位长度参数 r、x（Ω/km，串联支路）与 g、b（S/km，并联支路）。

![单位长度分布参数等值电路：串联 r + jx，并联 g + jb|440](/obsidian-assets/f64eace5daff78b9.png)

> 架空线的 r、x、g、b 受**气象与地理环境**影响而改变；标准电缆受外界影响小，参数基本不变。

## 3. 架空线参数计算

### 3.1 电阻 r（P18）

$$ r = \frac{\rho}{nS} \quad (\Omega/\text{km}) $$

| 符号 | 含义 |
| --- | --- |
| ρ | 电阻率（Ω·mm²/km），20 ℃ 时**铜 18.8、铝 31.5**；受温度影响 |
| S | 载流部分额定截面积（mm²） |
| n | 单相导线的子导线根数（分裂数） |

**ρ 取值略大于直流电阻率**，三个原因：① 集肤效应；② 多股绞线使每股实际长度略大于线路长度；③ S 取额定截面，而实际截面略小。

### 3.2 电抗 x（P19–P26）
#### 推导骨架
1. 用**安培环路定律**分析长直导线周围的磁场分布：I → H；
2. 求穿过导线回路的磁链：B = μH（μ 为磁导率）→ Φ = A·B → ψ = W·Φ；磁链 = **自磁链 + 互磁链**；
3. L = ψ/I，X = ωL。
三个易错点：
- 区分**励磁（excite）与去磁（demagnetize）**——本导体电流产生自感磁链，其他导体电流产生去磁的互感磁链；
- 导体内部磁链所交链的匝数是**分数匝（fraction turns）**；
- **自感与互感都要计入**。
#### 单相线路电感（两条平行长直导线构成的回路）
$$ L_1 = L_2 = 2\times10^{-7}\,\ln\frac{D_{12}}{r'} \quad(\text{H/m}) $$
- $D_{12}$：两导线间距离（m）；
- $r' = e^{-1/4}r_0 = 0.779\,r_0$：**等效半径**。导线内部有磁链、交链分数匝，把实心导线等效成半径为 r′ 的"无内部磁链"细线；$r' < r_0$，等效于半径变小、电感变大。
- L 随 $D_{12}$ 减小而减小，随 r′ 增大而减小。
#### 三相线路电感
**对称排列：**
$$ L_A = L_B = L_C = 2\times10^{-7}\,\ln\frac{D_{eq}}{r'} \quad(\text{H/m}) $$
**不对称排列经循环换位后公式相同**，其中
$$ D_{eq} = \sqrt[3]{D_{12}D_{23}D_{31}} \quad(\text{三相导线间的几何平均距离 GMD}) $$

![三相导线间的几何平均距离 D_eq 示意|229](/obsidian-assets/b514dea713682af8.png)
#### 三相分裂导线（换位后）
对于不对称，由于我们之前说过1导线的换相，所以我们在三相的距离取几何平均值
公式形式不变，只把 r′ 换成**几何平均等效半径** $D_s'$：
$$ L_A = L_B = L_C = 2\times10^{-7}\,\ln\frac{D_{eq}}{D_s'} \quad(\text{H/m}), \qquad D_s' = \sqrt[n]{nR^{\,n-1}r'} $$
- n：分裂数；R：分裂圆半径（一相中子导线所在圆的半径）；
- **n = 1 时公式同样适用**（$D_s' = r'$）。

![四分裂导线的子导线布置与分裂圆半径 R|472](/obsidian-assets/f39cfbad9667c958.png)
#### 单相 → 三相的类比
$$ L = 2\times10^{-7}\ln\frac{D_{12}}{r'} \quad\Longrightarrow\quad L_A = L_B = L_C = 2\times10^{-7}\ln\frac{D_{eq}}{D_s'} $$
即 **$D_{12} \to D_{eq}$，$r' \to D_s'$**——形式完全一致，只是把几何量换成对应的"平均值"。

![单相回路到三相线路的电感类比|488](/obsidian-assets/b1be6d654b0b0303.png)
第一次等效：把不对称的等效为对称的：$D_{eq}$，对应挪动到2'与3'
第二次等效：反正只要距离不变，对磁效应没有什么影响，所以我们可以按照等边三角形的方法等效到 2''
热知识：500kV线路常用6分裂（n=6）
#### 结论：单位长度电抗
$$ \boxed{\;x = 0.1445\,\lg\frac{D_{eq}}{D_s'} \quad(\Omega/\text{km})\;} \qquad \text{三相、分裂、换位后通用} $$

由 $x = \omega L\times1000 = 2\times10^{-7}\times2\pi\times50\times1000\times\ln = 0.0628\ln = 0.1445\lg$ 换算而来。
**使用要点**
- $D_{eq}$、$D_s'$、$r'$ 单位必须一致（m）；
- r′ 取值：单股导线 $r'=0.779r_0$；多股绞线 $r' < 0.779r_0$；**钢绞线 $r' > 0.779r_0$**（磁性材料，内部磁链大）；
- 经验数据：非分裂导线 110/220 kV 线路 **x ≈ 0.4 Ω/km**；
- L **客观存在**，由几何尺寸（$D_{eq}$、$D_s'$、$r'$）决定，是"等效电感"，**与电流 i 的大小无关**；前提是三相电流平衡 $i_a+i_b+i_c=0$。**三相不平衡时 L 会改变**（出现零序等不同序参数）；
- **如何减小 x**：增大 $D_s'$（分裂、加大子导线半径）、减小 $D_{eq}$（紧凑化杆塔）。
- 零序电抗问题：考虑某个同步发电机，它的电枢绕组接电网，突然在电网对这个电机测到一个三相相位差为0的电压，此时我们阻抗表测到的电抗和同步机的电枢绕组电抗值经验上大概是什么关系：结论是0.15~0.5倍，这和同步电机内相见助磁和去磁的关系有关
### 3.3 电导 g（P27）
$$ g = \frac{\Delta P_g}{U^2}\times10^{-3} \quad(\text{S/km}) $$
- U：线电压（kV）；
- $\Delta P_g$：三相电晕损耗有功功率（kW/km）；
- 来源是**电晕（corona）**（及绝缘泄漏）；电晕机理复杂，**无法建模计算，只能实测**；
- $U_{cr}$：**电晕临界电压**，低于它不发生电晕；受天气、导线材料、导线半径、分裂方式、空气密度影响，电晕通常发生在下雨天 （ $U_{cr}$ 小 ）；
- 晴天通常不发生电晕 → **工程上忽略 g，取 g = 0**。
### 3.4 电纳 b（P28–P33）
#### 推导骨架（与电感对偶）
高斯环路定律 $q\to D$；
电场强度 $E = D/\varepsilon$；
E → 线间电压 $U_{12}$；
电容 $C = q/U_{12}$；
电纳 $B = \omega C$。
#### 单相线路电容（两条平行长直导线）
**线间电容（Line/Line）：**
$$ C_{12} = \frac{0.012\times10^{-6}}{\lg (D_{12}/r_0)} \quad(\text{F/km}) $$
**相对地（中性点）电容（Line/Ground）：**

$$ C_{1n} = C_{2n} = 2C_{12} = \frac{0.0241\times10^{-6}}{\lg (D_{12}/r_0)} \quad(\text{F/km}) $$

![单相线路的线间电容与对地电容示意|86](/obsidian-assets/3b49d9b7b5abdf7e.png)

> **关键：为什么电容用 r₀，而电感用 r′？**
> 电场与磁场不同——电荷全部分布在导线**表面**，导线是等位体，**内部没有电场**，无需内部修正，所以用**实际半径 r₀**；而磁场有内部磁链，必须用 $r' = 0.779r_0$ 修正。

#### 三相线路电容（相对地）

**对称排列：**

$$ C_A = C_B = C_C = \frac{0.0241\times10^{-6}}{\lg (D_{eq}/r_0)} \quad(\text{F/km}) $$

**分裂导线（换位后）：**

$$ C_A = C_B = C_C = \frac{0.0241\times10^{-6}}{\lg (D_{eq}/D_S)} \quad(\text{F/km}), \qquad D_S = \sqrt[n]{nR^{\,n-1}r_0} $$

- 注意 $D_S$ 里用**实际半径 $r_0$**（不是 r′）；
- n = 1 时同样适用。

#### 单相 → 三相的类比

$$ C_{1n}=2C_{12}=\frac{0.0241\times10^{-6}}{\lg(D_{12}/r_0)} \quad\Longrightarrow\quad C_A=C_B=C_C=\frac{0.0241\times10^{-6}}{\lg(D_{eq}/D_S)} $$

![单相回路到三相线路的电容类比|632](/obsidian-assets/640d538d11c540b0.png)

#### 结论：单位长度电纳

$$ \boxed{\;b = \omega C = 314\,C = \frac{7.58\times10^{-6}}{\lg (D_{eq}/D_S)} \quad(\text{S/km})\;} \qquad \text{三相、分裂、换位后通用} $$

**使用要点**

- $D_{eq}$、$D_S$、$r_0$ 单位一致（m）；**$D_S$ 与计算 L 的 $D_s'$ 不同**（前者用 $r_0$，后者用 $r'$）；
- 经验数据：非分裂线路 **b ≈ (2.6~2.85)×10⁻⁶ S/km**；
- C **客观存在**，由几何尺寸决定，是"等效电容"，**与电压 u 的大小无关**；前提是三相电压平衡 $u_a+u_b+u_c=0$（等价于 $q_a+q_b+q_c=0$）。**不平衡时 C 会改变**。

## 4. 电力线路等值电路（P34–P38）

### 4.1 为什么需要等值电路

全长分布参数汇总：

| 参数  | 公式                       | 单位   |
| --- | ------------------------ | ---- |
| r   | ρ/(nS)                   | Ω/km |
| x   | 0.1445 lg(D_eq/D′ₛ)      | Ω/km |
| g   | 0（通常忽略）                  | S/km |
| b   | 7.58×10⁻⁶ / lg(D_eq/D_S) | S/km |

**分布参数电路无法直接参与全网的节点方程**；而工程真正关心的是线路**两端**的电压、电流关系。因此要把分布参数线路转化为**全长集中参数**的等值电路。

### 4.2 推导：把线路视为二端口网络

![线路二端口示意：端口 1 的 U̇₁、İ₁ 与端口 2 的 U̇₂、İ₂|707](/obsidian-assets/ddfb87560c4ff67e.png)

1. 分布参数线路的 Port 1 与 Port 2 构成一个**二端口网络**；
2. 列写分布参数下的**微分方程**：每一小段 dl 上：
	$$\begin{cases}{\rm d}\dot U = \dot I z\,{\rm d}l\\ {\rm d}\dot I = \dot U y\,{\rm d}l\end{cases}$$
3. 在给定边界条件下（已知 $\dot U_2,\dot I_2$）求出 $\dot U_1,\dot I_1$ → 用集中参数表示二端口等值电路。

![分布参数线路的微元电路与微分方程|550](/obsidian-assets/94d74f04dac8d702.png)

**二端口网络方程（精确解）**

$$ \begin{bmatrix}\dot U_1\\ \dot I_1\end{bmatrix} = \begin{bmatrix} \cosh\sqrt{ZY} & \sqrt{Z/Y}\,\sinh\sqrt{ZY} \\[4pt] \sqrt{Y/Z}\,\sinh\sqrt{ZY} & \cosh\sqrt{ZY} \end{bmatrix}\begin{bmatrix}\dot U_2\\ \dot I_2\end{bmatrix} $$

- Z = zL：单相全长串联总阻抗；Y = yL：单相全长并联总导纳；L 为线路长度；
- $\sqrt{Z/Y}$ 即波阻抗 $Z_c$，$\sqrt{ZY}$ 即传播系数 γl。

> ⚠️ **勘误**：课件 P36 矩阵的 (1,2) 元素写作 $\sqrt{ZY}\sinh\sqrt{ZY}$，与同页 (2,1) 元素 $\sqrt{Y/Z}\sinh\sqrt{ZY}$ 不自洽，且量纲上该位置应为阻抗。正确形式是 $\sqrt{Z/Y}\sinh\sqrt{ZY}$。

### 4.3 π 型等值电路

![π 型等值电路：串联 Z′，两端各挂 Y′/2|327](/obsidian-assets/b0379bdcc0156309.png)

$$ \begin{cases}Z' = Z\cdot\dfrac{\sinh\sqrt{ZY}}{\sqrt{ZY}}\\ \dfrac{Y'}{2} = \dfrac{Y}{2}\cdot\dfrac{\tanh\!\left(\sqrt{ZY}/2\right)}{\sqrt{ZY}/2} \end{cases}$$
 Z' 比实际的 Z 要大，Y' 比实际的 Y 要小（为什么？）
- 即把分布参数线路等效为 **π 型电路**：中间串联 Z′，两端各挂 Y′/2；
- sinh、tanh 项是**修正系数（Correction Factor）**，计及分布参数效应。

**L > 750 km：必须用上式计算。**

### 4.4 近似计算（Taylor 级数截断）

| 适用范围                       | 处理                          | 等值参数                                                                                           |
| -------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------- |
| **300 km ≤ L ≤ 750 km**    | 保留 Taylor 级数前 2 项           | $Z' = Z\left(1+\dfrac{ZY}{6}\right)$，$\dfrac{Y'}{2}=\dfrac{Y}{2}\left(1-\dfrac{ZY}{12}\right)$ |
| **L ≤ 300 km**             | 保留第 1 项，不计分布参数影响（**工程最常用**） | $Z' = Z$，$\dfrac{Y'}{2}=\dfrac{Y}{2}$                                                          |
| **L ≤ 100 km 且 U ≤ 35 kV** | 进一步**忽略并联导纳**               | $Z' = Z$，$\dfrac{Y'}{2}=0$                                                                     |

> **为什么 L ≤ 300 km 可以不修正？** 此时 $\sqrt{ZY}$ 很小，双曲函数展开的高次项贡献极小，修正系数趋近于 1，分布参数效应可忽略——等值电路简单且误差在工程允许范围内。

## 7. 勘误与说明

1. **P36 二端口矩阵 (1,2) 元素**：课件写作 $\sqrt{ZY}\sinh\sqrt{ZY}$，应为 $\sqrt{Z/Y}\sinh\sqrt{ZY}$（与同页 (2,1) 元素 $\sqrt{Y/Z}\sinh\sqrt{ZY}$ 对应，且该位置量纲为阻抗）。
2. **P25 等效半径**：课件写作 $r' = 0.799r_0$，系笔误，应为 **0.779**（$e^{-1/4}=0.7788$，与 P21、P26 一致）。
3. **P26 "GJ (钢芯绞线)"**：GJ 是**钢绞线**（纯钢线，磁性材料），故 $r' > 0.779r_0$；钢芯铝绞线 LGJ 的载流部分为铝，按铝绞线取值。P6 的"GJ（钢绞）"写法正确。
4. **未收录内容**：P4、P5、P9、P10、P11、P12、P13 为线路实物照片（杆塔、换位塔、分裂导线、电缆敷设），P7 为导线参数速查表（LGJ 系列 R₁、X₁ 等工程数据），均未转录；P3 为纯文字流程页，已用文字概括于 §0。
5. **本讲范围**：仅线路模型。变压器、发电机、负荷模型及系统等值电路在后续讲次展开。
