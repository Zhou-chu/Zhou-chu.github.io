## 第 1 章 绪论（INTRODUCTION）

### §1.1 基本术语（Basic Concepts）

这一组定义是后续全部内容的地基，务必逐条弄清"谁被控制、谁来测、谁来调"。

#### 系统（System）

> A combination of components that act together and perform a certain objective.

为完成某一目标而协同动作的部件的组合。**系统不限于物理对象**，这一概念同样可应用于抽象对象。

#### 控制系统（Control System）

> An interconnection of components for forming a system configuration that will provide a desired response.

为产生**期望响应**而按一定结构互连起来的部件集合。关键词是"互连"——控制系统的本质是结构，而非单个元件。

#### 被控对象（Plant）

> A plant may be a piece of equipment, perhaps just a set of machine parts functioning together, the purpose of which is to perform a particular operation. Generally speaking, we call any physical object to be controlled a plant.

被控对象可以是一台设备，也可以只是共同完成某一操作的一组机械部件。**概括地说，任何被控制的物理对象都称为被控对象。**

#### 过程（Process）

> A process is a natural progressively continuing operation or development marked by a series of gradual changes that succeed one another in a relatively fixed way and lead toward a particular result or end.

过程是自然持续进行的运行或发展，其标志是一系列按相对固定的方式相继发生的渐变，并导向某一特定结果或终点。**概括地说，任何被控制的运行都称为过程。**

> 辨析：plant 偏"物"（被控的物理对象），process 偏"事"（被控的运行/操作）。

#### 被控变量（Controlled Variable）

系统中我们希望**调节或维持在期望值**的关键量，代表控制系统的核心性能目标。

- 通常就是被控系统的**输出**；
- 其数值一般用**传感器**测量，并与**设定值**（setpoint，即期望值）比较。

#### 操纵变量（Manipulated Variable）

**由控制器改变**、用以影响被控变量的量或条件。控制器通过调节操纵变量，使被控变量保持在目标值上。

| 场景                         | 被控变量  | 操纵变量                  |
| -------------------------- | ----- | --------------------- |
| 汽车转向控制（steering control）   | 行驶方向  | 前轮方向（方向盘的转角指令）        |
| 汽车怠速控制（idle-speed control） | 发动机转速 | 节气门开度（throttle angle） |

#### 控制工程（Control Engineering）

> To find a technically feasible way to act on a given system (or process) so that the system (or process) adheres as closely as possible to some desired behavior.

为给定系统（或过程）寻找**技术可行**的作用途径，使其尽可能贴近某种期望行为。控制工程关心的是理解并改造自然界的物质与力，以造福人类。

#### 改善控制带来的收益（Benefits of Improved Control）

- 提高产品质量（improved product quality）
- 降低能耗（reduced energy consumption）
- 减少废料（minimization of waste material）
- 提高安全性（increased safety levels）
- 减少污染（reduction of pollution）

### §1.2 本课程研究对象的限定

**限定一：只研究线性系统（Linear systems）。**

**限定二：假定系统各元件满足因果（cause-effect）关系。** 由此，过程可用**函数方块**（function blocks）表示，即输入—方块—输出的形式：

```
Input  ──▶ [ System ] ──▶  Output
```

#### 因果系统（Causal System）

> A system is causal if its output at any given time depends only on the values of its input at the present and past times. It cannot depend on future values of the input.

系统是因果的，当且仅当它在任意时刻的输出**只依赖于当前及过去时刻的输入值**，不能依赖于未来的输入值。常概括为："**输出不能先于输入发生**"（the output cannot occur before the input）。

> 思考题（课件留问）：世界上是否存在非因果系统？

### §1.3 两种基本控制机理（Key Control Mechanisms）

控制有**两种**基本机理：开环（前馈）与闭环（反馈）。

#### 1.3.1 开环控制（Open-loop / Feed-forward）

> Utilizes an actuating device to control the system (process) directly **without using feedback (output)**.

用执行装置**直接**控制系统（过程），**不使用反馈**（不使用输出信息）。

**功能方块图：**

```
Desired output response ──▶ [ Controller ] ──▶ [ Actuator ] ──▶ [ Process ] ──▶ Output
```

![开环控制系统功能方块图](/obsidian-assets/a1dd589541a266aa.png)

**元件定义：**

- **执行器（Actuator）**：作用于系统、使过程从当前状态移动到期望状态的部件。
- **控制器（Controller）**：在开环系统中，按一定函数关系把参考信号转换成某种量或条件、用以驱动执行器的部件。

**例：转台转速的开环控制**

电路部分：电池 + 变阻器（设定转速）→ DC 放大器 → DC 电机 → 转台。

![转台转速开环控制：电路原理与功能方块图](/obsidian-assets/ed85d760b200acef.png)

对应的功能方块对应关系：

| 功能方块 | 实际元件 | 信号 |
| --- | --- | --- |
| 期望输入 | 变阻器（转速设定） | 期望转速（电压） |
| 控制装置（Control device） | 放大器（Amplifier） | — |
| 执行器（Actuator） | DC 电机 | — |
| 被控对象（Plant） | 转台（Turntable） | 实际转速 |

#### 1.3.2 闭环控制（Closed-loop / Feedback）

> Uses a measurement of the output and feedback of this signal to compare it with the desired input (reference or command).

**测量**输出，并将该信号**反馈**回来，与期望输入（参考信号或指令）**比较**。

**功能方块图：**

```
Desired output response ──▶( Σ )──▶ [ Amplifier ] ──▶ [ Actuator ] ──▶ [ Process ] ──▶ Output
                            ▲  −                                                          │
                            └──────────── [ Sensor ] ◀────────────────────────────────────┘
```

![闭环控制系统功能方块图](/obsidian-assets/8ba68354edb5df9e.png)

**元件定义（比喻说法值得记住）：**

- **传感器（Sensor）**：Sensors are **the eyes** of control，使人得以"看到"正在发生什么。
- **控制器（Controller）**：A controller is **the brain** of control engineering，即协调传感器与执行器的**算法**。

**三种改进方向：**

| 改进方向 | 作用 |
| --- | --- |
| Better Control | Provides more **finesse**（更精细）——以更聪明的方式组合传感器与执行器 |
| Better Actuators | Provide more **Muscle**（更强壮） |
| Better Sensors | Provide better **Vision**（更好的视力） |

**例：转台转速的闭环控制**

在开环电路基础上增加**测速发电机（tachometer）**作为传感器，构成反馈回路。

![转台转速闭环控制：电路原理](/obsidian-assets/de40f334db80f868.png)

![转台转速闭环控制：功能方块图](/obsidian-assets/03352c00ecb2bb22.png)

对应的功能方块：期望转速（电压）→ 比较（Σ，+ / −）→ [控制装置：放大器] → [执行器：DC 电机] → [过程：转台] → 实际转速；实际转速经 [传感器：测速发电机] 返回比较环节，反馈信号为"实测转速（电压）"。

#### 1.3.3 飞轮调速器（Fly-ball Governor）

反馈控制的经典实例，也是**公认的第一个用于工业过程的自动反馈控制器**。

工作过程（对应图中标注 ①②③）：

1. 发动机转速升高 → 离心力增大 → 飞球从转轴向外张开（moves out from rotating shaft）；
2. 飞球张开经连杆带动节气门关小一点（throttle valve closes a little）；
3. 蒸汽流量减少 → 转速回落，回到设定值（returning speed to setpoint）。

![飞轮调速器工作原理](/obsidian-assets/69c3d6dfe1a4efb1.png)

> 图中的 fixed fulcrum 为固定支点，离心力（centrifugal force）是驱动飞球张开的力源。

### §1.4 复杂控制系统（Complex Control Systems）

**例一：锅炉—发电机组协调控制系统（Coordinated control system for a boiler-generator）**

被控变量涵盖 O₂ 含量、温度（T）、压力、转速、电压/电流等多个测点；控制器接收"期望工作状态"与"期望输出电功率"，同时向水阀、燃料阀、空气阀发出指令，并设有转速调节器（speed governor）。

![锅炉—发电机组协调控制系统](/obsidian-assets/bd3e9d30e186d5cb.png)

**例二：炼油厂某工段（A section of an oil refinery plant）**

多输入、多输出（MIMO）结构：Controller 与 Process (System) 之间是多路并行通道，Measurement 环节把多路输出反馈回控制器。

### §1.5 例题：水位控制系统

被控过程：水箱水位控制。

![水位控制系统原理图](/obsidian-assets/b994b9e6b9333183.png)

**（1）工作原理**

浮球（float ball）随水位 `h` 上下移动，经杠杆（lever）带动进水阀门（valve）；水位偏低时阀门开大、进水量增加，水位回升；水位偏高时阀门关小，进水量减少。

**（2）被控变量与参考量**

- 被控变量：水位 `h`（更准确地说，是浮球位置所反映的水位）。
- 参考量（期望水位）：由杠杆支点位置决定的期望水位。

**（3）功能方块图**

```
desired water-level ──▶( Σ )──▶ error ──▶ [ lever ] ──▶ [ valve ] ──▶ water-level
                         ▲  −                                              │
                         └──────── water-level ◀── [ floating ball ] ◀────┘
```

![水位控制系统的功能方块图](/obsidian-assets/623908beb89ed4b5.png)

> 注意：误差（error）= 期望水位 − 实测水位，是**杠杆**的输入、**阀门**的驱动来源。

### §1.6 控制理论的发展阶段（Historical Periods）

| 时期 | 目标（Objectives） | 理论基础/方法 | 局限 / 优势 |
| --- | --- | --- | --- |
| **工业革命**（Industrial Revolution） | 反馈控制器开始被广泛使用 | **直觉与发明**（intuition and invention），并走向严格分析——常微分方程（ODE） | 第一个工业自动反馈控制器公认是**飞轮调速器** |
| **第二次世界大战** | 使控制系统**稳定**（stabilizing control systems） | **传递函数**、图解手段（频域法）：Bode 图、Nyquist 图 | 局限：**单输入单输出**（SISO）；统称 **经典控制理论**（Classic Control Theory） |
| **冷战太空竞赛**（The Push into Space in the Cold War） | 复杂精密控制，**实现最优控制** | **状态空间法**（时域法） | 优势：**多输入多输出**（MIMO）；统称 **现代控制理论**（Modern Control Theory） |
| **经济全球化、股东价值思维** | 把**扰动与不确定性**的影响纳入考虑 | **L2 增益**与 **H∞ 范数** | 称为 **鲁棒控制理论**（Robust Control Theory） |

**扰动与不确定性（Disturbances and Uncertainty）**

所有真实系统都受到噪声与外部扰动的作用，这些因素会显著影响系统性能。简单例子：飞机会受到阵风（wind-gusts）形式的扰动；汽车巡航控制器必须应对不同的道路坡度和不同的车辆载重。

**并行发展的分支（Parallel researches）**

- 非线性控制（Nonlinear control）
- 智能控制（Intelligent control）
- 自适应控制（Adaptive control）

## 第 2 章 系统的数学模型（Mathematical Models of Systems）

### §2.1 线性定常动态系统（Linear and Stationary Dynamic Systems）

#### 2.1.1 线性的定义

系统按其**激励**（excitation）与**响应**（response）的关系定义为线性：

```
Excitation u(t) ──▶ [ Linear System ] ──▶ Response y(t)
```

![线性系统的激励与响应](/obsidian-assets/36db83c22f527893.png)

**线性系统的两个必要条件：**

- **叠加原理**（Principle of superposition）
- **齐次性**（Property of homogeneity）

#### 2.1.2 叠加原理

设

$$
y_1(t) = f[u_1(t)], \qquad y_2(t) = f[u_2(t)]
$$

则叠加原理要求

$$
y_1(t) + y_2(t) = f\big[u_1(t) + u_2(t)\big]
$$

#### 2.1.3 齐次性

设

$$
y(t) = f[u(t)]
$$

则齐次性要求对任意常数 $k$

$$
k\,y(t) = f\big[k\,u(t)\big]
$$

#### 2.1.4 两个原理是否等价？

**结论：齐次性可推出叠加原理。** 证明如下。

已知 $y_1(t) = f[u_1(t)]$，由齐次性有 $k y_1(t) = f[k u_1(t)]$。

令

$$
u_2 = u_1 + \Delta, \qquad \Delta = k' u_1
$$

于是

$$
u_2 = (1 + k') u_1
$$

由齐次性逐项展开：

$$
\begin{aligned}
f(u_1 + u_2) &= f\big[u_1 + (1+k')u_1\big] \\
&= f\big[(2+k')u_1\big] \\
&= (2+k')f(u_1) \\
&= f(u_1) + (1+k')f(u_1) \\
&= f(u_1) + f\big[(1+k')u_1\big] \\
&= f(u_1) + f(u_2)
\end{aligned}
$$

**注意证明的适用范围**：此处 $k' = \Delta / u_1$ 要求 $u_1$ 是非零**标量**。当变量是向量或矩阵时，此构造不成立（课件留下的思考题：变量为向量/矩阵时如何？以及如何由叠加原理反推齐次性？）。

#### 2.1.5 线性性判别例题

**(1) $y = u^2$**

取 $u = u_1 + u_2$，则

$$
y = u^2 = (u_1 + u_2)^2 \neq u_1^2 + u_2^2
$$

**非线性。**

**(2) $y = mu + b$**（$m$、$b$ 为常数参数）

$$
y(u_1 + u_2) = m(u_1 + u_2) + b \neq (mu_1 + b) + (mu_2 + b) = y_1 + y_2
$$

**非线性**——常数项 $b$ 破坏了齐次性。

#### 2.1.6 在工作点附近视为线性（坐标平移）

系统 (2) 在**工作点** $(u_0, y_0)$ 附近，对**微小变化** $\Delta u$、$\Delta y$ 而言可视为线性。

设

$$
y = mu + b, \qquad y_0 = mu_0 + b, \qquad u = u_0 + \Delta u, \qquad y = y_0 + \Delta y
$$

则

$$
y_0 + \Delta y = m(u_0 + \Delta u) + b = (mu_0 + b) + m\Delta u = y_0 + m\Delta u
$$

故

$$
\boxed{\Delta y = m\,\Delta u}
$$

即在**平移后的坐标系**（以工作点为原点）中，系统是线性的，且斜率仍为 $m$。

![坐标平移：以工作点为新原点](/obsidian-assets/66a84feb0a90e789.png)

### §2.2 非线性动态系统的线性化（Linearization）

**三条基本认识：**

1. 绝大多数（若非全部）物理系统都是**非线性**的；
2. 在**小信号条件**（small-signal conditions）下，非线性元件往往可以被线性化；
3. 实现手段是在**工作点**处做**泰勒级数展开**（Taylor series expansion）。

#### 线性化过程

设非线性系统为

$$
y(t) = f\big[u(t)\big]
$$

在 $u_0$ 处做泰勒展开：

$$
y(t) = f(u_0) + \frac{df}{du}\bigg|_{u_0}(u - u_0) + \frac{1}{2!}\frac{d^2f}{du^2}\bigg|_{u_0}(u - u_0)^2 + \cdots
$$

**忽略高阶项**，并记

$$
m = \frac{df}{du}\bigg|_{u_0}, \qquad y_0 = f(u_0)
$$

得到线性化模型

$$
\boxed{\;y - y_0 = m\,(u - u_0)\;}
$$

**几何意义**：在工作点附近的小范围内，**工作点处的斜率**是对曲线的一个良好近似。

![泰勒展开线性化：平衡点处的切线](/obsidian-assets/ab28a0556e1b70ed.png)

> 术语对应：图中的 Equilibrium (Operating Point) 即平衡点/工作点，坐标为 $(u_0, y_0)$。

### §2.3 物理系统的数学模型

#### 2.3.1 为什么需要数学模型

- 求解控制问题必须要有**定量的数学模型**；
- 物理系统本质上是**动态**的 → 其模型是**微分方程**；
- **线性时不变**系统的模型是**常微分方程**（ODE）。

#### 2.3.2 建模的一般步骤

1. 定义系统及其各组成部件；
2. 建立各部件的数学模型，并**列出必要的假设**；
3. 依据**物理定律**写出描述模型动态的微分方程；
4. 求解方程，得到所期望的输出变量；
5. **检验**解与假设；
6. 如有必要，重新分析系统。

#### 2.3.3 例题 1：质量—弹簧—阻尼系统

**假设：**

- 假设 1：**线性弹簧**（linear spring）；
- 假设 2：**粘性阻尼器**（viscous damper），**不是库仑阻尼**（not coulomb）。

**物理定律：牛顿第二定律。**

![质量—弹簧—阻尼系统](/obsidian-assets/6cd09abc3c0af3d2.png)

图中符号：质量 $M$、壁面摩擦系数 $b$、弹簧刚度 $k$、位移 $y(t)$、外力 $r(t)$。

**动力学方程：**

$$
r(t) - b\,\dot{y}(t) - k\,y(t) = m\,\ddot{y}(t)
$$

> 注意"粘性阻尼 vs 库仑阻尼"这一假设的作用：粘性阻尼的阻尼力正比于速度 $b\dot{y}$，因此方程是**线性**的；库仑阻尼的阻尼力与速度方向有关、幅值恒定，会引入非线性。

### §2.4 拉普拉斯变换（Laplace Transform）

#### 2.4.1 为什么要用拉普拉斯变换

拉普拉斯变换法把一个**求解常微分方程（ODE）**的问题，转化为一个**相对容易的求解代数方程**的问题。求解流程为：

1. 得到微分方程；
2. 计算拉普拉斯变换；
3. 求解所得的代数变换式；
4. 通过**拉普拉斯逆变换**得到时间响应。

#### 2.4.2 定义与存在条件

**存在条件（充分条件）：** 物理上可实现的信号总是有拉普拉斯变换，即要求

$$
\int_{0^-}^{\infty}\big|f(t)\big|e^{-\sigma t}\,dt < \infty
$$

**拉普拉斯变换：**

$$
F(s) = \int_{0^-}^{\infty} f(t)\,e^{-st}\,dt
$$

**拉普拉斯逆变换：**

$$
f(t) = \frac{1}{2\pi j}\int_{\sigma - j\infty}^{\sigma + j\infty} F(s)\,e^{st}\,ds
$$

#### 2.4.3 常用拉普拉斯变换对

| $f(t)$，$t \ge 0$ | $\mathcal{L}[f(t)]$ | 收敛域（Region of Convergence） |
| --- | --- | --- |
| $1$ | $\dfrac{1}{s}$ | $\sigma > 0$ |
| $\delta_D(t)$ | $1$ | $\lvert \sigma \rvert < \infty$ |
| $t$ | $\dfrac{1}{s^2}$ | $\sigma > 0$ |
| $t^n,\ n \in \mathbb{Z}^+$ | $\dfrac{n!}{s^{n+1}}$ | $\sigma > 0$ |
| $e^{\alpha t},\ \alpha \in \mathbb{C}$ | $\dfrac{1}{s - \alpha}$ | $\sigma > \Re\{\alpha\}$ |
| $t\,e^{\alpha t},\ \alpha \in \mathbb{C}$ | $\dfrac{1}{(s - \alpha)^2}$ | $\sigma > \Re\{\alpha\}$ |
| $\cos(\omega_o t)$ | $\dfrac{s}{s^2 + \omega_o^2}$ | $\sigma > 0$ |
| $\sin(\omega_o t)$ | $\dfrac{\omega_o}{s^2 + \omega_o^2}$ | $\sigma > 0$ |
| $e^{\alpha t}\sin(\omega_o t + \beta)$ | $\dfrac{(\sin\beta)\,s + \omega_o^2\cos\beta - \alpha\sin\beta}{(s-\alpha)^2 + \omega_o^2}$ | $\sigma > \Re\{\alpha\}$ |
| $t\sin(\omega_o t)$ | $\dfrac{2\omega_o s}{(s^2 + \omega_o^2)^2}$ | $\sigma > 0$ |
| $t\cos(\omega_o t)$ | $\dfrac{s^2 - \omega_o^2}{(s^2 + \omega_o^2)^2}$ | $\sigma > 0$ |
| $\mu(t) - \mu(t - \tau)$ | $\dfrac{1 - e^{-s\tau}}{s}$ | $\lvert \sigma \rvert < \infty$ |

#### 2.4.4 常用拉普拉斯变换性质

| $f(t)$ | $\mathcal{L}[f(t)]$ | 名称 |
| --- | --- | --- |
| $\sum_{i=1}^{l} a_i f_i(t)$ | $\sum_{i=1}^{l} a_i F_i(s)$ | 线性组合（Linear combination） |
| $\dfrac{dy(t)}{dt}$ | $sY(s) - y(0^-)$ | 微分法则（Derivative Law） |
| $\dfrac{d^k y(t)}{dt^k}$ | $s^k Y(s) - \sum_{i=1}^{k} s^{\,k-i}\dfrac{d^{\,i-1}y(t)}{dt^{\,i-1}}\Big\rvert_{t=0^-}$ | 高阶微分（High order derivative） |
| $\int_{0^-}^{t} y(\tau)\,d\tau$ | $\dfrac{1}{s}Y(s)$ | 积分法则（Integral Law） |
| $y(t-\tau)\,\mu(t-\tau)$ | $e^{-s\tau}Y(s)$ | 延迟（Delay） |
| $t\,y(t)$ | $-\dfrac{dY(s)}{ds}$ | — |
| $t^k y(t)$ | $(-1)^k\dfrac{d^k Y(s)}{ds^k}$ | — |
| $\int_{0^-}^{t} f_1(\tau) f_2(t-\tau)\,d\tau$ | $F_1(s) F_2(s)$ | 卷积（Convolution） |
| $\lim_{t \to \infty} y(t)$ | $\lim_{s \to 0} sY(s)$ | 终值定理（Final Value Theorem） |
| $\lim_{t \to 0^+} y(t)$ | $\lim_{s \to \infty} sY(s)$ | 初值定理（Initial Value Theorem） |
| $f_1(t) f_2(t)$ | $\dfrac{1}{2\pi j}\int_{\sigma - j\infty}^{\sigma + j\infty} F_1(\zeta) F_2(s-\zeta)\,d\zeta$ | 时域乘积（Time domain product） |
| $e^{at} f_1(t)$ | $F_1(s-a)$ | 频移（Frequency Shift） |

#### 2.4.5 三条重要法则及其"算子"解释

**（1）微分法则**

原函数：

$$
f^{(k)}(t) = \frac{d^k f(t)}{dt^k}
$$

拉普拉斯变换：

$$
\mathcal{L}\Big[\frac{d^k f(t)}{dt^k}\Big] = s^k F(s) - s^{k-1}f(0^-) - s^{k-2}f'(0^-) - \cdots - f^{(k-1)}(0^-)
$$

**只要**

$$
f(0^-) = f'(0^-) = \cdots = f^{(k-1)}(0^-) = 0
$$

**就可以把拉普拉斯变量 $s$ 看作微分算子：**

$$
s \equiv \frac{d}{dt}
$$

**（2）积分法则**

原函数：

$$
\int_{0^-}^{t} f(\tau)\,d\tau
$$

拉普拉斯变换：

$$
\mathcal{L}\Big[\int_{0^-}^{t} f(\tau)\,d\tau\Big] = \frac{F(s)}{s}
$$

**只要 $f(t) = 0\ (t \le 0)$**，就可以把 $1/s$ 看作积分算子：

$$
\frac{1}{s} \equiv \int_{0^-}^{t} dt
$$

**（3）实卷积（复乘）**

设 $F_1(s)$、$F_2(s)$ 分别是 $f_1(t)$、$f_2(t)$ 的拉普拉斯变换，且当 $t < 0$ 时 $f_1(t) = f_2(t) = 0$，则

$$
\mathcal{L}\big[f_1(t) * f_2(t)\big] = \mathcal{L}\Big[\int_{0}^{t} f_1(\tau) f_2(t-\tau)\,d\tau\Big] = F_1(s) F_2(s)
$$

> 即：**时域卷积 ↔ 复频域相乘**。这是后面用传递函数串联/并联化简的理论依据。

### §2.5 传递函数（The Transfer Function）

#### 2.5.1 定义

> The transfer function of a linear system is defined as the ratio of the Laplace transform of the output variable to the Laplace transform of the input variable, **with all initial conditions assumed to be zero**.

线性系统的传递函数定义为：**输出变量的拉普拉斯变换**与**输入变量的拉普拉斯变换**之比，且假定**所有初始条件为零**。

$$
\text{TF} = \frac{\mathcal{L}(\text{output})}{\mathcal{L}(\text{input})}
$$

#### 2.5.2 由 ODE 求传递函数

**原系统（Origin system）：**

$$
a_n y^{(n)}(t) + a_{n-1}y^{(n-1)}(t) + \cdots + a_1 \dot{y}(t) + a_0 y(t) = b_m u^{(m)}(t) + \cdots + b_1 \dot{u}(t) + b_0 u(t)
$$

**零初始条件：**

$$
y(0^-) = \dot{y}(0^-) = \cdots = y^{(n-1)}(0^-) = 0
$$

$$
u(0^-) = \dot{u}(0^-) = \cdots = u^{(m-1)}(0^-) = 0
$$

**取拉普拉斯变换：**

$$
\big(s^n + a_{n-1}s^{n-1} + \cdots + a_1 s + a_0\big)Y(s) = \big(b_m s^m + \cdots + b_1 s + b_0\big)U(s)
$$

**传递函数：**

$$
G(s) = \frac{Y(s)}{U(s)} = \frac{b_m s^m + b_{m-1}s^{m-1} + \cdots + b_1 s + b_0}{s^n + a_{n-1}s^{n-1} + \cdots + a_1 s + a_0}, \qquad n \ge m
$$

#### 2.5.3 关于传递函数的四点说明

1. 传递函数**只对线性时不变系统**定义；
2. 系统的**所有初始条件都置零**；
3. 传递函数**与系统的输入无关**（它只由系统本身的参数与结构决定）；
4. $n$ 与 $m$ 之差称为系统的**相对阶**（relative degree）。当 $n > m$ 时，称传递函数是**严格真**的（strictly proper）。

#### 2.5.4 传递函数的另一种定义（单位脉冲响应）

输入取**单位脉冲** $\delta(t)$，则输出 $y(t)$ 即**单位脉冲响应**。

因为 $\mathcal{L}[\delta(t)] = 1$，所以

$$
Y(s) = G(s)\cdot U(s) = G(s)
$$

于是

$$
g(t) = \mathcal{L}^{-1}\big[Y(s)\big] = \mathcal{L}^{-1}\big[G(s)\cdot U(s)\big] = \mathcal{L}^{-1}\big[G(s)\big]
$$

即

$$
\boxed{\;g(t) = y(t) \quad \text{当}\quad u(t) = \delta(t)\;}
$$

**结论：传递函数 $G(s)$ 就是单位脉冲响应 $g(t)$ 的拉普拉斯变换。**
