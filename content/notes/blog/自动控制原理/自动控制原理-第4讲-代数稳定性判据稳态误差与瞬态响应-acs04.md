# 第 4 讲：代数稳定性判据、稳态误差与瞬态响应

> **本讲对应课件**：PPT for the class on Oct. 15th（Chapter 3，共 89 页）。
>
> **学完能做到**
> 1. 列劳斯表判断稳定性，并数出右半平面根的个数；处理首列为零和整行为零两种特殊情况。
> 2. 用劳斯判据求稳定裕度和使系统稳定的参数范围。
> 3. 根据系统型别和输入类型写出稳态误差，知道终值定理什么时候不能用。
> 4. 计算扰动引起的稳态误差，说出拑制扰动的两个办法；算灵敏度。
> 5. 由阻尼比和自然频率算二阶系统的超调量和调节时间，或反过来由指标定极点。

第 3 讲说：稳定 ⟺ 特征方程的根都在左半平面。可三阶以上的多项式很难手算求根，带参数时更是如此。这一讲先给一个**不求根**的办法——劳斯判据。系统稳定之后，再问两个问题：输出最终跟得有多准（稳态误差），过程中走得有多快、多稳（瞬态指标）。

## 一、劳斯—赫尔维茨判据

### 1.1 先做一道初筛：系数同号且不缺项（课件第 5–7 页）

特征方程

$$
F(s)=a_ns^n+a_{n-1}s^{n-1}+\cdots+a_1s+a_0=0
$$

的根都不在右半平面的**必要条件**：

1. 所有系数同号；
2. 没有系数为零。

**为什么。** 由根与系数的关系（韦达定理）：

$$
\frac{a_{n-1}}{a_n}=-\sum(\text{所有根}),\quad \frac{a_{n-2}}{a_n}=+\sum(\text{根两两之积}),\quad\dots,\quad \frac{a_0}{a_n}=(-1)^n(\text{所有根之积}).
$$

若所有根的实部都为负，把 $F(s)$ 写成 $(s+\alpha)$ 和 $(s^2+\beta s+\gamma)$（$\alpha,\beta,\gamma>0$）的乘积，展开后每个系数都是正数之和，不可能为零或变号。

**但它不充分。** 例如 $s^4+5s^3+8s^2+16s+20$ 系数全正、不缺项，却有两个右半平面根（见 1.4 节例 3.5）。所以还需要充要判据。

### 1.2 赫尔维茨判据（课件第 8 页）

设 $a_n>0$。所有根都在左半平面的**充要条件**是：赫尔维茨行列式 $D_1,D_2,\dots,D_n$ 全部为正。

$$
D_1=a_{n-1},\quad
D_2=\begin{vmatrix}a_{n-1}&a_{n-3}\\a_n&a_{n-2}\end{vmatrix},\quad
D_3=\begin{vmatrix}a_{n-1}&a_{n-3}&a_{n-5}\\a_n&a_{n-2}&a_{n-4}\\0&a_{n-1}&a_{n-3}\end{vmatrix},\quad\dots
$$

排法：第一行从 $a_{n-1}$ 开始隔项取系数 $a_{n-1},a_{n-3},\dots$，第二行放 $a_n,a_{n-2},\dots$，往下每两行右移一格重复，下标超出范围的填 0。$D_k$ 是左上角 $k\times k$ 的主子式。

**例**：三阶 $a_3s^3+a_2s^2+a_1s+a_0$（$a_3>0$），$D_1=a_2>0$，$D_2=a_2a_1-a_3a_0>0$，$D_3=a_0D_2>0$。合起来就是：**系数全正，且 $a_2a_1>a_3a_0$**。这是三阶系统最常用的稳定条件，值得记住。

阶数高时行列式越来越大，劳斯表是它的简化算法。

### 1.3 劳斯表的列法（课件第 9–10 页）

以六阶 $a_6s^6+a_5s^5+\cdots+a_0=0$ 为例。

![](/obsidian-assets/6c66b331d851104a.png)

**前两行**直接抄系数，隔一个取一个：

| | | | | |
|---|---|---|---|---|
| $s^6$ | $a_6$ | $a_4$ | $a_2$ | $a_0$ |
| $s^5$ | $a_5$ | $a_3$ | $a_1$ | 0 |

**后面每一行**由上面两行算出。以 $s^4$ 行为例：

$$
A=\frac{a_5a_4-a_6a_3}{a_5},\qquad B=\frac{a_5a_2-a_6a_1}{a_5},\qquad \frac{a_5a_0-a_6\cdot0}{a_5}=a_0 .
$$

规律：新行第 $j$ 列 = （上一行首元 × 上上行第 $j+1$ 列 − 上上行首元 × 上一行第 $j+1$ 列）÷ 上一行首元。就是一个 $2\times2$ 行列式取负除以上一行首元。列到 $s^0$ 行为止，共 $n+1$ 行。

小技巧：某一行整体乘以一个正数，不影响结论，可用来消分数。

### 1.4 判据（课件第 11–12 页）

> 1. 常规劳斯表的**第一列**元素全部同号且无虚轴根 ⟺ 所有根都在开左半平面。若曾出现整行零，必须另查辅助方程的虚轴根。
> 2. 第一列**变号的次数** = 右半平面根的个数。

为什么只看第一列：第一列元素恰好是赫尔维茨行列式的比值，

$$
a_n,\quad D_1,\quad \frac{D_2}{D_1},\quad \frac{D_3}{D_2},\quad\dots,\quad \frac{D_n}{D_{n-1}},
$$

所以「第一列全正」与「$D_k$ 全正」是同一件事。

**例 3.4（课件第 13 页）**：$2s^4+2s^3+8s^2+3s+2=0$。

| | | | |
|---|---|---|---|
| $s^4$ | 2 | 8 | 2 |
| $s^3$ | 2 | 3 | 0 |
| $s^2$ | $\frac{2\cdot8-2\cdot3}{2}=5$ | $\frac{2\cdot2-2\cdot0}{2}=2$ | |
| $s^1$ | $\frac{5\cdot3-2\cdot2}{5}=\frac{11}{5}$ | 0 | |
| $s^0$ | 2 | | |

第一列 $2,2,5,\tfrac{11}{5},2$ 全正，系统稳定。

**例 3.5（课件第 14 页）**：$s^4+5s^3+8s^2+16s+20=0$。

| | | | |
|---|---|---|---|
| $s^4$ | 1 | 8 | 20 |
| $s^3$ | 5 | 16 | 0 |
| $s^2$ | $\frac{5\cdot8-1\cdot16}{5}=4.8$ | 20 | |
| $s^1$ | $\frac{4.8\cdot16-5\cdot20}{4.8}=-4.83$ | 0 | |
| $s^0$ | 20 | | |

第一列 $1,5,4.8,-4.83,20$：从 $4.8$ 到 $-4.83$ 变号一次，从 $-4.83$ 到 $20$ 又变号一次，共两次——**两个右半平面根**，系统不稳定。（数值求根可验：$0.127\pm1.822j$。）

## 二、两种特殊情况（课件第 15–19 页）

### 2.1 某行首元为零、其余不全为零：用 $\varepsilon$ 代替

下一行要除以这个零，算不下去。办法：用一个很小的正数 $\varepsilon$ 代替 0，照常列表，最后令 $\varepsilon\to0^+$ 看符号。

**例**：$s^5+2s^4+2s^3+4s^2+s+1=0$。

| | | | |
|---|---|---|---|
| $s^5$ | 1 | 2 | 1 |
| $s^4$ | 2 | 4 | 1 |
| $s^3$ | $\frac{2\cdot2-1\cdot4}{2}=0\to\varepsilon$ | $\frac{2\cdot1-1\cdot1}{2}=\frac12$ | |
| $s^2$ | $\frac{4\varepsilon-1}{\varepsilon}\approx-\frac1\varepsilon$ | 1 | |
| $s^1$ | $\approx\frac12$ | | |
| $s^0$ | 1 | | |

第一列：$1,\ 2,\ \varepsilon(+),\ -\frac1\varepsilon(-),\ \frac12(+),\ 1$。变号两次，两个右半平面根（数值验证：$0.069\pm1.274j$）。

课件提醒：方程有纯虚根时，$\varepsilon$ 法可能给出错误结论。

### 2.2 某行元素全为零：用辅助方程

**例**：$s^3+2s^2+4s+K=0$。

| | | |
|---|---|---|
| $s^3$ | 1 | 4 |
| $s^2$ | 2 | $K$ |
| $s^1$ | $\frac{8-K}{2}$ | 0 |
| $s^0$ | $K$ | |

$K=8$ 时 $s^1$ 行全为零。**步骤**：

1. 用全零行**上面一行**的系数写辅助方程（次数按该行的 $s$ 幂，隔一次取）：$A(s)=2s^2+8=0$。
2. 求导：$\dfrac{dA}{ds}=4s$。
3. 用导数的系数（4）代替全零行。
4. 继续列表：$s^1$ 行为 4，$s^0$ 行为 8。
5. 看第一列 $1,2,4,8$：没有变号，所以没有右半平面根。

**辅助方程的根也是原方程的根**：$2s^2+8=0$ 给出 $s=\pm2j$。原方程除以 $s^2+4$ 得 $s+2$，三个根是 $-2,\pm2j$。系统在 $K=8$ 时临界稳定（等幅振荡，频率 2 rad/s）。

**整行为零意味着什么**（课件第 19 页）：方程有关于原点对称的根，可能是
1. 一对等值异号的实根 $\pm a$；
2. 一对或多对纯虚根 $\pm j\omega$；
3. 关于原点对称的两对共轭复根。

所以「整行为零 ⇒ 有虚轴根」**不对**；解辅助方程才知道是哪一种。

## 三、劳斯判据的两个应用

### 3.1 稳定裕度（课件第 20 页）

「稳定」只是是或否。想知道根离虚轴有多远，可以把虚轴往左搬。

![](/obsidian-assets/e630e061fe45f28c.png)

**方法**：令 $s=s'-\sigma_0$（即新坐标 $s'$ 的虚轴位于原来的 $s=-\sigma_0$）。对关于 $s'$ 的新方程列劳斯表：若新方程仍稳定，说明所有根都在 $s=-\sigma_0$ 左边。

**例**：$s^3+7s^2+17s+11=0$。原方程劳斯表第一列 $1,7,\frac{108}{7},11$，稳定。问根是否都在 $s=-1$ 左边。

代入 $s=s'-1$ 并展开：

$$
(s'-1)^3+7(s'-1)^2+17(s'-1)+11=s'^3+4s'^2+6s'+0=0 .
$$

常数项为 0，说明 $s'=0$ 是一个根，即原方程有根恰好在 $s=-1$。其余 $s'^2+4s'+6=0$ 给 $s'=-2\pm j\sqrt2$，即 $s=-3\pm j\sqrt2$。结论：稳定裕度恰好是 1——最靠近虚轴的根在 $-1$。

### 3.2 使系统稳定的参数范围（课件第 21–22 页）

![](/obsidian-assets/048441a9045ea7f1.png)

单位负反馈，开环 $G_0(s)=\dfrac{K}{s(T_1s+1)(T_2s+1)}$，$T_1,T_2>0$。闭环特征方程 $1+G_0=0$ 两边乘分母：

$$
T_1T_2s^3+(T_1+T_2)s^2+s+K=0 .
$$

| | | |
|---|---|---|
| $s^3$ | $T_1T_2$ | 1 |
| $s^2$ | $T_1+T_2$ | $K$ |
| $s^1$ | $\dfrac{(T_1+T_2)-KT_1T_2}{T_1+T_2}$ | 0 |
| $s^0$ | $K$ | |

第一列全正：$K>0$，且 $T_1+T_2>KT_1T_2$，即

$$
\boxed{\ 0<K<\frac{1}{T_1}+\frac{1}{T_2}\ }
$$

（也可直接用三阶条件 $a_2a_1>a_3a_0$：$(T_1+T_2)\cdot1>T_1T_2K$。）取 $T_1=1$、$T_2=0.1$，得 $0<K<11$。开环增益太大会失稳，这是反馈系统最典型的矛盾。

## 四、时间响应与典型试验信号（课件第 24–31 页）

### 4.1 瞬态与稳态

$$
y(t)=y_t(t)+y_{ss}(t),\qquad \lim_{t\to\infty}y_t(t)=0 .
$$

- **瞬态响应** $y_t$：随时间趋于零的那部分。惯性、质量、电感使系统不能瞬间跟上输入的突变。
- **稳态响应** $y_{ss}$：瞬态消失后剩下的部分，反映最终精度。输出与期望不一致，就有**稳态误差**。

### 4.2 三种典型输入

实际输入事先未知，所以用几种标准信号评价。线性系统对复杂信号的响应可以由它们叠加得到。

| 信号 | $r(t)$（$t\ge0$） | $R(s)$ | 考察什么 |
|---|---|---|---|
| 阶跃 | $1$ | $\dfrac1s$ | 对突变的反应快慢 |
| 斜坡 | $t$ | $\dfrac{1}{s^2}$ | 跟踪匀速变化的能力 |
| 抛物线 | $\tfrac12t^2$ | $\dfrac{1}{s^3}$ | 跟踪匀加速变化的能力 |

从上到下变化一个比一个快。比抛物线更快的试验信号实际中很少需要。

## 五、稳态误差

### 5.1 定义（课件第 32–33 页）

![](/obsidian-assets/1079711e3cc2d351.png)

两种定义：
- **按输入端**：$e(t)=r(t)-b(t)$。$b(t)$ 是测量环节 $H$ 的输出，比较点的输出是 $e(t)$。
- **按输出端**：$e(t)=y_r(t)-y(t)$，$y_r$ 是期望输出。

令 $G$ 表示前向通道，$H$ 表示反馈测量环节。按图沿信号方向写得 $E=R-B$、$B=HY$、$Y=GE$。单位反馈 $H=1$ 且期望输出取 $y_r=r$ 时，两种误差都等于 $r-y$。稳态误差 $e_{ss}=\lim_{t\to\infty}e(t)$。实际中经过 4–5 倍时间常数就可认为到达稳态。

### 5.2 用终值定理计算（课件第 34 页）

按输入端定义，$E=R-HY$，$Y=GE$，消去 $Y$：

$$
E(s)=\frac{R(s)}{1+G(s)H(s)}=\frac{R(s)}{1+G_0(s)},\qquad G_0=GH .
$$

**终值定理**：若 $sE(s)$ 的极点都在开左半平面（没有实部 $\ge0$ 的极点），则

$$
e_{ss}=\lim_{s\to0}sE(s)=\lim_{s\to0}\frac{sR(s)}{1+G_0(s)} .
$$

**用之前必须检查条件**。课件第 35 页两个例子：

**(1)** $G=\dfrac{1}{s+1}$，$H=\dfrac{1}{s+2}$，$R=\dfrac1s$：

$$
E(s)=\frac{1/s}{1+\frac{1}{(s+1)(s+2)}}=\frac{(s+1)(s+2)}{s(s^2+3s+3)} .
$$

$sE$ 的极点是 $s^2+3s+3=0$ 的根，在左半平面，可以用：$e_{ss}=\dfrac{1\cdot2}{3}=\dfrac23$。

**(2)** $G=\dfrac{\omega^2}{s^2}$，$H=1$，$R=\dfrac1s$：$E=\dfrac{1/s}{1+\omega^2/s^2}=\dfrac{s}{s^2+\omega^2}$。$sE$ 的极点在 $\pm j\omega$（虚轴上），**终值定理不适用**。实际上 $e(t)=\cos\omega t$ 永远在振，没有终值。若硬套公式会得到错误的「0」。

### 5.3 系统的型别（课件第 36–37 页）

从公式看，$e_{ss}$ 取决于 $G_0(s)$ 在 $s\to0$ 时的行为，也就是 $G_0$ 在原点有几个极点。把开环传函写成时间常数形式：

$$
G_0(s)=\frac{K\prod_{i=1}^m(T_is+1)}{s^{r}\prod_{j=1}^{v}(\tau_js+1)} .
$$

- $K$：**开环增益**，$K=\lim_{s\to0}s^rG_0(s)$；
- $r$：开环在原点的极点数（积分环节个数），称为系统的**型别**。$r=0,1,2$ 分别叫 0 型、1 型、2 型。

型别和阶数是两回事：阶数是分母总次数，型别只数原点极点。

### 5.4 阶跃输入：位置误差系数 $K_p$（课件第 38–42 页）

$R=\dfrac1s$：

$$
e_{ss}=\lim_{s\to0}\frac{s\cdot\frac1s}{1+G_0(s)}=\frac{1}{1+K_p},\qquad K_p=\lim_{s\to0}G_0(s).
$$

- 0 型：$K_p=K$，$e_{ss}=\dfrac{1}{1+K}$；
- 1 型及以上：$K_p=\infty$，$e_{ss}=0$。

**例**：$G_0=\dfrac{20}{(2s+1)(0.1s+1)}$（0 型，$K=20$），$e_{ss}=\dfrac{1}{21}=0.0476$，输出停在 $0.9524$。
$G_0=\dfrac{100}{s(s+10)}$（1 型），$e_{ss}=0$。

**注意**（课件第 42 页）：稳态误差为零不等于过程中没有误差。给 $\frac{100}{s(s+10)}$ 的闭环输入方波，每次跳变后都有超调和过渡过程：

![](/obsidian-assets/4d85cdb15bdb8f1e.png)

### 5.5 斜坡输入：速度误差系数 $K_v$（课件第 43–46 页）

$R=\dfrac{1}{s^2}$：

$$
e_{ss}=\lim_{s\to0}\frac{s\cdot\frac{1}{s^2}}{1+G_0}=\lim_{s\to0}\frac{1}{s+sG_0(s)}=\frac{1}{K_v},\qquad K_v=\lim_{s\to0}sG_0(s).
$$

- 0 型：$K_v=0$，$e_{ss}=\infty$（误差越拉越大）；
- 1 型：$K_v=K$，$e_{ss}=\dfrac1K$；
- 2 型及以上：$K_v=\infty$，$e_{ss}=0$。

**例**：$G_0=\dfrac{20}{s(s+10)}$，$K_v=\lim s\cdot\frac{20}{s(s+10)}=2$，$e_{ss}=0.5$——输出与斜坡平行，落后 0.5。
$G_0=\dfrac{2(s+1)}{s^2(0.1s+1)}$（2 型），$e_{ss}=0$。

### 5.6 抛物线输入：加速度误差系数 $K_a$

同理，$R=\dfrac{1}{s^3}$ 时 $e_{ss}=\dfrac{1}{K_a}$，$K_a=\lim_{s\to0}s^2G_0(s)$。0、1 型 $e_{ss}=\infty$，2 型 $e_{ss}=1/K$，3 型及以上为 0。

### 5.7 汇总表（单位反馈、系统稳定为前提）

| 型别 | 阶跃 $1(t)$ | 斜坡 $t$ | 抛物线 $\frac12t^2$ |
|---|---|---|---|
| 0 | $\dfrac{1}{1+K}$ | $\infty$ | $\infty$ |
| 1 | 0 | $\dfrac1K$ | $\infty$ |
| 2 | 0 | 0 | $\dfrac1K$ |

记法：每多一个积分器，就能多消掉一阶输入的误差。输入是幅值 $A$ 的阶跃、斜坡等，误差也乘 $A$。

### 5.8 例：终值定理用不上时（课件第 47–49 页）

单位反馈，$G_0=\dfrac Ks$。先查稳定：闭环 $\dfrac{K}{s+K}$，$K>0$ 时稳定。误差传函

$$
\frac{E}{R}=\frac{1}{1+G_0}=\frac{s}{s+K}.
$$

**(1)** $r=\tfrac12t^2$，$R=\dfrac{1}{s^3}$：$sE=\dfrac{1}{s(s+K)}$ 在原点有极点，终值定理不适用。直接看：$E=\dfrac{1}{s^2(s+K)}$，反变换含 $\dfrac tK$ 项，误差随时间线性增长到无穷。（1 型系统跟不上抛物线，与 5.7 节表一致。）

**(2)** $r=\sin\omega t$：$sE$ 在 $\pm j\omega$ 有极点，终值定理不适用。用**相量法**：稳定系统对正弦输入的稳态响应是同频正弦，幅值乘 $|\Phi(j\omega)|$，相位加 $\angle\Phi(j\omega)$。这里

$$
\Phi_e(j\omega)=\frac{j\omega}{j\omega+K},\quad |\Phi_e|=\frac{\omega}{\sqrt{\omega^2+K^2}},\quad \angle\Phi_e=90^\circ-\arctan\frac{\omega}{K},
$$

$$
e_{ss}(t)=\frac{\omega}{\sqrt{\omega^2+K^2}}\sin\Big(\omega t+90^\circ-\arctan\frac{\omega}{K}\Big).
$$

稳态误差不是常数，而是一个正弦。$K$ 越大幅值越小。（相量法就是第 6 讲「频率响应」的出发点。）

## 六、扰动与参数变化对稳态误差的影响

### 6.1 扰动引起的误差（课件第 50–52 页）

扰动有两类来源：内部（非线性、参数变化）和外部（环境）。先按课件图的负号，把外扰 $D$ 接在控制器 $G_c$ 和对象 $G_p$ 之间。令 $R=0$，有 $Y=G_p(G_cE-D)$、$E=-HY$。代入第一式并将 $E$ 项移到同侧：

$$
\frac{E(s)}{D(s)}=\frac{G_p(s)H(s)}{1+G_c(s)G_p(s)H(s)}=\frac{G_pH}{1+G_0}.
$$

阶跃扰动 $d(t)=d\cdot1(t)$，$D=d/s$，由终值定理

$$
e_{ss}=\lim_{s\to0}\frac{G_p(s)H(s)}{1+G_0(s)}\,d=\lim_{s\to0}\frac{G_0(s)}{1+G_0(s)}\frac{d}{G_c(s)} .
$$

当开环增益很大（或开环含积分）时 $\frac{G_0(s)}{1+G_0(s)}$ 在 $s\to0$ 时趋近 $1$，于是

$$
|e_{ss}|\approx\lim_{s\to0}\left|\frac{d}{G_c(s)}\right| .
$$

**结论**：抑制扰动靠的是**扰动作用点之前**的环节。
1. 增大扰动点之前控制器的增益；
2. 在扰动点之前的控制器里加积分（$G_c(0)=\infty$，阶跃扰动误差为零）。

积分放在扰动之后（对象里）不管用。

### 6.2 复合控制：用前馈抵消扰动（课件第 53 页）

![](/obsidian-assets/289e4f4c439aa263.png)

扰动 $D$ 以负号进入 $G_p$ 的输入端；若 $D$ 可测，再把它经 $G_d$ 以正号送到 $G_c$ 之前的比较点。令 $R=0$，跟着信号走：

$$
Y=G_p\big[G_c(G_dD-HY)-D\big]\ \Longrightarrow\ \frac{Y}{D}=\frac{G_dG_cG_p-G_p}{1+G_cG_pH}.
$$

取 $G_d=\dfrac{1}{G_c}$，分子为零，扰动对输出**完全没有影响**。前馈在扰动影响输出之前就修正，反馈负责清除残差。实际中 $1/G_c$ 可能不可实现，只能近似抵消。

### 6.3 例 3.11：输入和扰动同时作用（课件第 54–55 页）

![](/obsidian-assets/0f2885de3652efa6.png)

**题设。** 前向通道 $\dfrac{50}{0.5s+1}$，之后扰动 $d(t)$ 以**负号**进入，再经 $\dfrac1s$ 得到 $y$；单位负反馈。$r(t)=t$，$d(t)=0.5\cdot1(t)$，误差 $e=r-y$。求 $e_{ss}$。

**第一步：分别求两个传函**（叠加原理）。开环 $G_0=\dfrac{50}{s(0.5s+1)}$，闭环分母 $0.5s^2+s+50$（系数全正的二阶，稳定）。

$$
G_1=\frac{Y}{R}=\frac{50}{0.5s^2+s+50},\qquad
G_2=\frac{Y}{D}=\frac{-1/s}{1+\frac{50}{s(0.5s+1)}}=-\frac{0.5s+1}{0.5s^2+s+50}.
$$

**第二步：写误差。**

$$
E=R-Y=(1-G_1)R-G_2D=\frac{0.5s^2+s}{0.5s^2+s+50}\cdot\frac{1}{s^2}+\frac{0.5s+1}{0.5s^2+s+50}\cdot\frac{0.5}{s}.
$$

**第三步：检查 $sE$ 的极点**：只有 $0.5s^2+s+50=0$ 的根，在左半平面。可用终值定理：

$$
e_{ss}=\lim_{s\to0}\Big[\frac{0.5s+1}{0.5s^2+s+50}+\frac{0.5s+1}{0.5s^2+s+50}\times0.5\Big]=\frac{1}{50}+\frac{0.5}{50}=0.03 .
$$

两部分的含义：$\frac{1}{50}=\frac{1}{K_v}$ 是 1 型系统跟斜坡的误差；$\frac{0.5}{50}=\frac{d}{G_c(0)}$ 是扰动误差——积分器在扰动之后，消不掉它，正好印证 6.1 节的结论。

### 6.4 参数变化：灵敏度（课件第 57–60 页）

闭环 $T=\dfrac{G}{1+GH}$。**灵敏度**定义为闭环的相对变化与参数相对变化之比。

**前向通道 $G$ 变化**：

$$
S_G=\frac{\partial T/T}{\partial G/G}=\frac{\partial T}{\partial G}\cdot\frac GT=\frac{(1+GH)-GH}{(1+GH)^2}\cdot\frac{G(1+GH)}{G}=\frac{1}{1+GH}.
$$

**反馈通道 $H$ 变化**：

$$
S_H=\frac{\partial T}{\partial H}\cdot\frac HT=\frac{-G^2}{(1+GH)^2}\cdot\frac{H(1+GH)}{G}=-\frac{GH}{1+GH}.
$$

稳态下（$s\to0$）若开环含积分，$GH\to\infty$，则 $S_G\to0$，$|S_H|\to1$。

**结论**：负反馈能有效削弱**前向通道**参数变化的影响（第 1 讲转台的 $1/(1+L)$），对**反馈通道**的参数变化却无能为力——传感器读数偏了，系统会忠实地跟着偏。所以反馈通道的元件必须精密。

## 七、瞬态响应

### 7.1 性能指标（课件第 63–65 页）

用**单位阶跃响应**定义：

![](/obsidian-assets/57d858a1e9749e22.png)

| 指标 | 定义 | 衡量 |
|---|---|---|
| 最大超调量 $\sigma\%$ | $\dfrac{y_{\max}-y(\infty)}{y(\infty)}\times100\%$ | 相对稳定性 |
| 上升时间 $t_r$ | 从 0 第一次升到终值（或 10% → 90%）所需时间 | 快速性 |
| 峰值时间 $t_p$ | 到达最大值的时间 | 快速性 |
| 调节时间 $t_s$ | 进入并保持在终值 ±2%（或 ±5%）范围内的时间 | 快速性 |

![](/obsidian-assets/d113f041dafa1714.png)

高阶系统的指标一般靠仿真，或者参照一阶、二阶系统来估计（第 5 讲）。

### 7.2 一阶系统（课件第 66 页）

积分环节 $\dfrac{1}{Ts}$ 加单位负反馈：

$$
G(s)=\frac{Y}{R}=\frac{1}{Ts+1},\qquad \text{极点 } s=-\frac1T .
$$

单位阶跃响应 $Y=\dfrac{1}{s(Ts+1)}=\dfrac1s-\dfrac{1}{s+1/T}$：

$$
y(t)=1-e^{-t/T}.
$$

![](/obsidian-assets/66029ce17b998260.png)

特征点：$t=T$ 时 $y=0.632$；$t=4T$ 时 $y=1-e^{-4}=0.982$，进入 2% 误差带，所以 $t_s\approx4T$（取 5% 则 $3T$）。没有超调。**极点离虚轴越远（$T$ 越小），响应越快。**

### 7.3 二阶系统的标准形式（课件第 67–69 页）

开环 $\dfrac{\omega_n^2}{s(s+2\zeta\omega_n)}$ 加单位负反馈：

$$
G(s)=\frac{\omega_n^2}{s^2+2\zeta\omega_ns+\omega_n^2}=\frac{1}{T^2s^2+2\zeta Ts+1},\qquad T=\frac{1}{\omega_n}.
$$

- $\omega_n$：**无阻尼自然频率**（rad/s）；
- $\zeta$：**阻尼比**（无量纲）。

这就是第 1 讲质量—弹簧—阻尼 $\ddot y+2\dot y+5y=r$ 归一化后的形式（那里 $\omega_n=\sqrt5$，$\zeta=0.447$）。

**极点**（0<ζ<1 时）：

$$
s_{1,2}=-\zeta\omega_n\pm j\omega_n\sqrt{1-\zeta^2}=-\sigma\pm j\omega_d,\qquad \sigma=\zeta\omega_n,\quad \omega_d=\omega_n\sqrt{1-\zeta^2}.
$$

![](/obsidian-assets/3b2dae1a1c278d2d.png)

**几何意义**（课件第 69 页）：极点到原点的距离是 $\omega_n$；实部 $-\sigma=-\zeta\omega_n$（衰减速度）；虚部 $\omega_d$（**阻尼振荡频率**）；极点与负实轴的夹角 $\theta$ 满足 $\cos\theta=\zeta$。

### 7.4 四种阻尼情况（课件第 70–74 页）

| $\zeta$ | 极点 | 单位阶跃响应 | 名称 |
|---|---|---|---|
| $0$ | $\pm j\omega_n$ | $1-\cos\omega_nt$，等幅振荡 | 无阻尼 |
| $0<\zeta<1$ | $-\zeta\omega_n\pm j\omega_d$ | $1-\dfrac{e^{-\zeta\omega_nt}}{\sqrt{1-\zeta^2}}\sin(\omega_dt+\theta)$，$\theta=\arccos\zeta$ | 欠阻尼 |
| $1$ | $-\omega_n$（二重） | $1-(1+\omega_nt)e^{-\omega_nt}$ | 临界阻尼 |
| $>1$ | $-\zeta\omega_n\pm\omega_n\sqrt{\zeta^2-1}$（两实根） | $1+k_1e^{s_1t}+k_2e^{s_2t}$ | 过阻尼 |

![](/obsidian-assets/c2787cf2b625cce1.png)

从图上读：$\zeta$ 越小振荡越厉害；$\zeta\ge1$ 没有超调但上升慢。工程上常取 $\zeta=0.4\sim0.8$，$\zeta=0.707$ 常称「最佳阻尼」。

**欠阻尼阶跃响应的来历**：$Y(s)=\dfrac{\omega_n^2}{s[(s+\sigma)^2+\omega_d^2]}$，部分分式（与第 1 讲 8.5 节同样的办法）得

$$
Y(s)=\frac1s-\frac{s+2\sigma}{(s+\sigma)^2+\omega_d^2}=\frac1s-\frac{s+\sigma}{(s+\sigma)^2+\omega_d^2}-\frac{\sigma}{\omega_d}\cdot\frac{\omega_d}{(s+\sigma)^2+\omega_d^2},
$$

$y(t)=1-e^{-\sigma t}\big(\cos\omega_dt+\frac{\sigma}{\omega_d}\sin\omega_dt\big)$，合并成一个正弦即表中形式。

### 7.5 超调量和调节时间（课件第 75–79 页）

欠阻尼时：

$$
\boxed{\ \sigma\%=e^{-\pi\zeta/\sqrt{1-\zeta^2}}\times100\%,\qquad t_s\approx\frac{4}{\zeta\omega_n}\ (2\%\ \text{误差带})\ }
$$

补充（从 7.4 节的表达式求导可得）：$t_p=\dfrac{\pi}{\omega_d}$，$t_r=\dfrac{\pi-\theta}{\omega_d}$。

**怎么读这两个公式**：
- $\sigma\%$ **只由 $\zeta$ 决定**，即只由极点的**角度** $\theta$ 决定。$\zeta\uparrow\Rightarrow\sigma\%\downarrow$。
- $t_s$ 由 $\zeta\omega_n=\sigma$ 决定，即由极点到虚轴的**横向距离**决定。
- $\zeta$ 不变时增大 $\omega_n$，波形形状不变，只是时间轴压缩（课件第 79 页）。

![](/obsidian-assets/13d3f65e53225eaa.png)

![](/obsidian-assets/6561a9eebe73c8a0.png)

$t_s\approx4/(\zeta\omega_n)$ 是用包络线 $e^{-\zeta\omega_nt}$ 估算的，在 $\zeta$ 较小时较准，$\zeta$ 接近或大于 1 时偏差变大（见上图实际曲线与估算曲线的差别）。

**例（课件第 76 页）**：$\omega_n=1$，$\zeta=0.3$。

$$
\sigma\%=e^{-0.3\pi/\sqrt{1-0.09}}=e^{-0.988}=37.2\%,\qquad t_s=\frac{4}{0.3\times1}=13.3\ \text{s}.
$$

**例：由指标定极点（课件第 80 页）**。设计二阶系统，$\zeta=0.707$，$t_s=0.5$ s。

1. $\cos\theta=\zeta=0.707\Rightarrow\theta=45^\circ$：极点在与负实轴成 45° 的射线上，实部的绝对值等于虚部。
2. $t_s=\dfrac{4}{\zeta\omega_n}=0.5\Rightarrow\zeta\omega_n=8$。
3. 极点 $s_{1,2}=-8\pm j8$，$\omega_n=\sqrt{8^2+8^2}=8\sqrt2\approx11.3$ rad/s。

对应传函 $G(s)=\dfrac{128}{s^2+16s+128}$。

## 八、课件复习题与讨论

**1. 劳斯判据能用于 $s^4+7s^3+4s^2+17s+11e^{-2s}=0$ 吗？** 不能。含 $e^{-2s}$（纯延迟），不是多项式，有无穷多个根。

**2. 劳斯表中途出现全零行，说明方程有虚轴根？** 不对。也可能是 $\pm a$ 实根或对称的复根对（2.2 节）。

**3. 单位反馈的 2 型系统，阶跃和斜坡的稳态误差一定为零？** 不一定。前提是闭环稳定，而 2 型系统很容易不稳定（例如 $\frac{K}{s^2}$ 闭环是等幅振荡）。

**4. 稳态误差无穷大，系统就不稳定？** 不对。0 型稳定系统跟斜坡，误差也趋于无穷。这是「跟不上」，不是「不稳定」。

**5. 不稳定系统的稳态误差一定无穷大？** 不稳定系统谈不上稳态，误差一般发散或持续振荡。所以算稳态误差的第一步永远是判稳。

**6. 稳态误差不是常数，系统就不稳定？** 不对。稳定系统对正弦输入的稳态误差就是正弦（5.8 节）。

## 自测

1. 用劳斯表判断 $s^3+3s^2+3s+9=0$ 的根的分布。
2. 单位负反馈，$G_0=\dfrac{K}{s(s+1)(s+5)}$，求使闭环稳定的 $K$ 的范围。
3. 上题取 $K=10$，求斜坡输入 $r=2t$ 时的稳态误差。
4. 二阶系统要求超调不大于 4.3%，阻尼比至少多少？若再要求 $t_s\le2$ s，极点实部至少多大？
5. 为什么说「反馈通道的传感器必须精密」？用灵敏度回答。

**答案**
1. 表：$s^3$: 1, 3；$s^2$: 3, 9；$s^1$: $\frac{9-9}{3}=0$，整行为零。辅助方程 $3s^2+9=0$，$s=\pm j\sqrt3$；求导 $6s$，$s^1$ 行改为 6，$s^0$ 行 9，首列无变号。所以一对虚根 $\pm j\sqrt3$，另一个根 $-3$，临界稳定。
2. 特征方程 $s^3+6s^2+5s+K=0$，三阶条件 $6\times5>K$ 且 $K>0$：$0<K<30$。
3. 1 型，$K_v=\lim s\cdot\frac{10}{s(s+1)(s+5)}=2$；单位斜坡误差 $\frac12$，输入幅值 2，$e_{ss}=1$。
4. $e^{-\pi\zeta/\sqrt{1-\zeta^2}}\le0.043$ → $\zeta\ge0.707$。$\frac{4}{\zeta\omega_n}\le2$ → $\zeta\omega_n\ge2$，极点实部 $\le-2$。
5. $|S_H|=\frac{|GH|}{|1+GH|}\approx1$：反馈通道 1% 的误差几乎原样变成输出 1% 的误差，反馈本身没法纠正。

下一讲问：如果开环增益 $K$ 从 0 连续变到无穷，闭环极点在 $s$ 平面上怎么走？不解方程就能画出它们的轨迹——根轨迹法。还会讨论高阶系统怎样用主导极点近似成二阶。
