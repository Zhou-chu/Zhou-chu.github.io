# 计算机系统概论（三）：浮点数

> 本篇对应课件第三讲《浮点数》。上一篇的整数是"精确但会溢出"的，浮点数则正相反：它能覆盖极大极小的范围，代价是**大多数数都只能近似表示**。这一讲要弄清楚近似的规则是什么，以及它会在哪些地方让程序"悄悄出错"。

## 1. 引子：加 1000 次 0.1，得到的不是 100

课件开头是一段很短的 C 代码：

```c
float position = 0.0f;
float velocity = 0.1f;
for (int i = 0; i < 1000; i++) {
    position += velocity;
}
printf("position = %.15f\n", position);
printf("position == 100.0f ? %s\n", position == 100.0f ? "true" : "false");
printf("error = %.15f\n", position - 100.0f);
```

在 x86-64 上用 gcc 实测，输出是：

```text
position = 99.999046325683594
position == 100.0f ? false
error = -0.000953674316406
```

从数学上看应当恰好是 100，程序却差了近千分之一。原因有两层：第一，`0.1f` 本身就不是 0.1，它实际存的是 `0.10000000149011612`；第二，每次相加的结果还要再舍入一次，误差在 1000 次累加中不断积累。本篇后面的内容就是把这两层原因拆开讲清楚。

## 2. 二进制小数：能精确表示什么

小数点后的位权依次是 $\frac12,\frac14,\frac18,\ldots$，所以一个二进制小数 $b_i b_{i-1}\cdots b_1 b_0 . b_{-1}b_{-2}\cdots b_{-j}$ 的值是

$$\sum_{k=-j}^{i} b_k\cdot 2^k$$

一些例子：$5\frac34=101.11_2$，$2\frac78=10.111_2$，$\frac{63}{64}=0.111111_2$。

这里有一个根本的限制：**只有形如 $X/2^k$ 的数才能用有限位二进制小数精确表示。** 十进制里的 0.1、0.2 这类"整齐"的数，在二进制里却是无限循环小数：

| 值 | 二进制表示 |
|---|---|
| $1/3$ | $0.0101010101\cdots_2$ |
| $1/5$ | $0.001100110011\cdots_2$ |
| $1/10$ | $0.0001100110011\cdots_2$ |

所以 `0.1f` 只能取最接近的那个可以表示的数。上面引子里的问题，从这里就开始了。

## 3. IEEE 754：一个浮点数怎么编码

IEEE 754 标准建立于 1985 年，它把一个浮点数写成

$$V=(-1)^s\times M\times 2^E$$

三个部分：**符号** $s$；**有效数**（尾数）$M$，规格化时是 $[1.0,2.0)$ 内的小数；**指数**（阶码）$E$。编码时把一个字拆成三个域：

```text
| s |    exp    |    frac    |
```

`exp` 域负责编码 $E$，`frac` 域负责编码 $M$。各种精度的区别只是两个域的宽度不同：

![](/obsidian-assets/504b9d76b3c65d24.png)

| 格式 | exp 位数 | frac 位数 | 总位数 |
|---|---|---|---|
| 半精度（FP16） | 5 | 10 | 16 |
| 单精度（`float`） | 8 | 23 | 32 |
| 双精度（`double`） | 11 | 52 | 64 |
| 扩展精度 | 15 | 63 | 80（其中 1 位无用） |
| BF16（深度学习常用） | 8 | 7 | 16 |

根据 `exp` 域取值的不同，浮点数分成三类：规格化数、非规格化数、特殊值。

![](/obsidian-assets/e61371f77db4cfe2.png)

### 3.1 规格化数（Normalized）

**条件**：`exp` 既不全是 0，也不全是 1。

- **阶码**：真实指数 $E=Exp-Bias$，其中 $Exp$ 是 `exp` 域当作无符号数的值，偏置 $Bias=2^{e-1}-1$（$e$ 是 `exp` 域的位数）。单精度 $Bias=127$，此时 $Exp\in[1,254]$，$E\in[-126,127]$；双精度 $Bias=1023$，$Exp\in[1,2046]$，$E\in[-1022,1023]$。
- **尾数**：$M=1.xxx\cdots x_2$，小数点前的 1 是**隐含**的，不占存储位。这等于白赚一位精度。

于是 `frac` 全 0 时 $M=1.0$ 最小，全 1 时 $M=2.0-\varepsilon$ 最大，其中 $\varepsilon=2^{-23}$（单精度）或 $2^{-52}$（双精度）。

**为什么指数用"偏置"而不是补码？** 偏置让指数域当作无符号数比较时，大小顺序与真实指数一致，这一点后面讲浮点数比较时会用到。

#### 例：`float F = 15213.0`

$$15213_{10}=11101101101101_2=1.1101101101101_2\times 2^{13}$$

- 尾数 $M=1.1101101101101_2$，`frac` 就是小数点后的 `1101101101101`，后面补 10 个 0 凑满 23 位；
- 阶码 $E=13$，$Exp=E+Bias=13+127=140=10001100_2$；
- 符号为正，$s=0$。

![](/obsidian-assets/9b294d72706d2f30.png)

拼起来就是 `0 10001100 11011011011010000000000`，十六进制 `0x466DB400`。可以自己写个 `show_bytes` 验证。

### 3.2 非规格化数（Denormalized）

**条件**：`exp` 全为 0。这时

- $E=1-Bias$（注意**不是** $0-Bias$）；
- $M=0.xxx\cdots x_2$，**没有隐含的 1**。

它有两个用途：

- `frac` 也全 0：表示 **0**。由于有符号位，存在 $+0$ 和 $-0$ 两个零。
- `frac` 不全 0：表示**非常接近 0 的数**，这些数的有效位数会逐步减少，称为**逐步下溢（gradual underflow）**。

**为什么 $E$ 取 $1-Bias$ 而不是 $-Bias$？** 看单精度：最大的非规格化数是 $(1.0-\varepsilon)\times2^{-126}$，最小的规格化数是 $1.0\times2^{-126}$，两者恰好首尾相接，中间没有空隙。如果非规格化数取 $E=-127$，就会漏掉一段、也会和规格化数的间隔不一致。取 $1-Bias$ 使得"从非规格化过渡到规格化"是平滑的。

### 3.3 特殊值

**条件**：`exp` 全为 1。

- `frac` 全 0：**无穷**，有 $+\infty$ 和 $-\infty$，用来表示溢出，例如 `1.0/0.0` 得 $+\infty$，`-1.0/0.0` 得 $-\infty$；
- `frac` 不全 0：**NaN**（Not-a-Number），表示无法得到实数的运算结果，例如 $\sqrt{-1}$、$\infty-\infty$、$\infty\times0$。

## 4. 用一个 8 位小浮点数看清全貌

直接看单精度的 32 位太长，课件用了一个 8 位的玩具格式 E4M3：1 位符号、**4 位指数**、**3 位小数**，其余规则都遵循 IEEE 754。偏置 $Bias=2^{4-1}-1=7$。

| Exp | exp | $E$ | $2^E$ | | Exp | exp | $E$ | $2^E$ |
|---|---|---|---|---|---|---|---|---|
| 0 | 0000 | −6 | 1/64（非规格化） | | 8 | 1000 | +1 | 2 |
| 1 | 0001 | −6 | 1/64 | | 9 | 1001 | +2 | 4 |
| 2 | 0010 | −5 | 1/32 | | 10 | 1010 | +3 | 8 |
| 3 | 0011 | −4 | 1/16 | | 11 | 1011 | +4 | 16 |
| 4 | 0100 | −3 | 1/8 | | 12 | 1100 | +5 | 32 |
| 5 | 0101 | −2 | 1/4 | | 13 | 1101 | +6 | 64 |
| 6 | 0110 | −1 | 1/2 | | 14 | 1110 | +7 | 128 |
| 7 | 0111 | 0 | 1 | | 15 | 1111 | — | inf / NaN |

注意 $Exp=0$（非规格化）和 $Exp=1$（最小的规格化）的 $E$ 都是 −6，这就是上面说的"平滑过渡"。把所有取值排开：

| s exp frac | $E$ | 数值 | 备注 |
|---|---|---|---|
| 0 0000 000 | −6 | 0 | |
| 0 0000 001 | −6 | $\frac18\times\frac1{64}=\frac1{512}$ | 最接近 0 |
| 0 0000 010 | −6 | $2/512$ | |
| … | | | |
| 0 0000 111 | −6 | $7/512$ | 最大的非规格化数 |
| 0 0001 000 | −6 | $\frac88\times\frac1{64}=8/512$ | 最小的规格化数 |
| 0 0001 001 | −6 | $9/512$ | |
| … | | | |
| 0 0110 111 | −1 | $\frac{15}8\times\frac12=\frac{15}{16}$ | 最接近 1（小于） |
| 0 0111 000 | 0 | 1 | |
| 0 0111 001 | 0 | $\frac98$ | 最接近 1（大于） |
| … | | | |
| 0 1110 111 | 7 | $\frac{15}8\times128=240$ | 最大的规格化数 |
| 0 1111 000 | — | $\infty$ | |

从中可以直接读出几条规律：

- 非规格化数的间隔是 $\frac1{512}$，**与最小的几个规格化数的间隔相同**，所以可以无缝衔接；
- 规格化数每跨过一个 $E$，间隔就翻一倍：$E=-6$ 时间隔是 $\frac1{512}$，$E=0$ 时是 $\frac18$，$E=7$ 时是 16。**离 0 越远，浮点数越稀疏，相对精度却保持不变。**

菱形是非规格化数，品红三角是规格化数，黄点是无穷。可以看到 0 附近很密，两端很稀。

### 单精度与双精度的特殊数值

| 描述 | exp | frac | 数值 |
|---|---|---|---|
| 零 | 00…00 | 00…00 | 0.0 |
| 最小正非规格化数 | 00…00 | 00…01 | $2^{-\{23,52\}}\times2^{-\{126,1022\}}$；单精度 $\approx1.4\times10^{-45}$，双精度 $\approx4.9\times10^{-324}$ |
| 最大非规格化数 | 00…00 | 11…11 | $(1.0-\varepsilon)\times2^{-\{126,1022\}}$；单精度 $\approx1.18\times10^{-38}$，双精度 $\approx2.2\times10^{-308}$ |
| 最小正规格化数 | 00…01 | 00…00 | $1.0\times2^{-\{126,1022\}}$，恰好比最大非规格化数大一点 |
| 1 | 01…11 | 00…00 | 1.0 |
| 最大规格化数 | 11…10 | 11…11 | $(2.0-\varepsilon)\times2^{\{127,1023\}}$；单精度 $\approx3.4\times10^{38}$，双精度 $\approx1.8\times10^{308}$ |

这些数的来源都可以自己推出来：比如单精度最小正非规格化数，是 $frac=0\cdots01$，所以 $M=2^{-23}$，$E=1-127=-126$，乘起来是 $2^{-149}\approx1.4\times10^{-45}$。

## 5. 浮点数的大小比较

IEEE 754 的编码有一个很实用的性质：**除了少数例外，浮点数可以直接按无符号整数的方式比较大小。** 原因是：指数用偏置编码，指数域越大数越大；指数相同时看 `frac`，`frac` 越大数越大；而规格化数与非规格化数、规格化数与无穷之间，位串的顺序同样与数值顺序一致。

例外有三类：

1. **必须先比较符号位**：负数的符号位是 1，按无符号整数看反而大；
2. **$+0$ 与 $-0$**：位串不同，但 IEEE 要求它们相等；
3. **NaN**：不考虑符号位的话，NaN 的位串比其他任何值（包括 $\infty$）都大，但在 IEEE 的比较规则里，任何与 NaN 的比较（`==`、`<`、`>`）结果都是假，只有 `!=` 为真，连 `NaN == NaN` 都不成立。

## 6. 舍入

### 6.1 四种舍入模式

给定一个实数，转成浮点数的流程是：先算出精确值，再转成所需精度；其中可能**溢出**（指数太大），也可能需要**舍入**。IEEE 规定了四种舍入模式，课件用美元金额做了对比：

| 模式 | \$1.40 | \$1.60 | \$1.50 | \$2.50 | −\$1.50 |
|---|---|---|---|---|---|
| 向 0 舍入 | \$1 | \$1 | \$1 | \$2 | −\$1 |
| 向下舍入 | \$1 | \$1 | \$1 | \$2 | −\$2 |
| 向上舍入 | \$2 | \$2 | \$2 | \$3 | −\$1 |
| 向偶数舍入 | \$1 | \$2 | \$2 | \$2 | −\$2 |

### 6.2 向偶数舍入（Round-To-Even）

这是**默认**的舍入模式，也叫"向最接近值的舍入"。其他三种都会引入**统计上的偏差**（比如总是向上舍入，大量数据累加后误差会朝一个方向累积）。

关键的设计决策是：**恰好处在两个可能结果正中间时怎么办？** 规则是：选择使**舍入后最低有效位为偶数**的那一个。以十进制保留百分位为例：

| 原值 | 舍入结果 | 说明 |
|---|---|---|
| 1.2349999 | 1.23 | 不到一半 |
| 1.2350001 | 1.24 | 超过一半 |
| 1.2350000 | 1.24 | 恰好一半，为了让末位是偶数（4），向上 |
| 1.2450000 | 1.24 | 恰好一半，为了让末位是偶数（4），向下 |

二进制中，"偶数"意味着最低有效位是 0，而"恰好一半"意味着最低有效位右侧的位串是 `100…0`。舍入到小数点后 2 位的例子：

| 数值 | 二进制 | 舍入到 2 位 | 判断 | 结果 |
|---|---|---|---|---|
| $2\frac3{32}$ | $10.00011_2$ | $10.00_2$ | 不到一半，向下 | 2 |
| $2\frac3{16}$ | $10.00110_2$ | $10.01_2$ | 超过一半，向上 | $2\frac14$ |
| $2\frac78$ | $10.11100_2$ | $11.00_2$ | 恰好一半，向上凑偶 | 3 |
| $2\frac58$ | $10.10100_2$ | $10.10_2$ | 恰好一半，向下保持偶 | $2\frac12$ |

### 6.3 转换步骤：规格化、舍入、后调整

把一个数转成浮点格式，具体分三步：

1. **规格化**：把数写成 $1.xxx\times2^E$ 的形式；
2. **舍入**：按向偶数舍入把 `frac` 截到所需位数；
3. **后调整（postnormalize）**：舍入可能进位产生 $10.000\cdots$，此时要再规格化一次，指数加 1。

用课件的例子，把 8 位无符号整数转成 E4M3 格式（$Bias=7$，`frac` 3 位）：

| 原值 | 二进制 | 规格化 | 舍入后 | 后调整 | 编码 `s exp frac` | 最终值 |
|---|---|---|---|---|---|---|
| 128 | `10000000` | $1.0000000\times2^7$ | 1.000（无进位） | — | `0 1110 000` | 128 |
| 15 | `00001111` | $1.1110000\times2^3$ | 1.111（无进位） | — | `0 1010 111` | 15 |
| 17 | `00010001` | $1.0001000\times2^4$ | 1.000（恰好一半，向偶） | — | `0 1011 000` | 16 |
| 19 | `00010011` | $1.0011000\times2^4$ | 1.010（恰好一半，向偶需进位） | — | `0 1011 010` | 20 |
| 138 | `10001010` | $1.0001010\times2^7$ | 1.001（超过一半，进位） | — | `0 1110 001` | 144 |
| 63 | `00111111` | $1.1111100\times2^5$ | 10.000（进位溢出） | $1.000\times2^6$ | `0 1101 000` | 64 |

其中 17 和 19 是"恰好一半"的两个对照：17 的 `frac` 保留位末位已经是 0（偶数），所以向下；19 保留后末位是 1（奇数），所以向上进位，变成 1.010。最后一行 63 是后调整的典型情况：舍入使得有效数变成 `10.000`，这就必须把指数加 1、有效数变回 `1.000`。

## 7. C 语言中的浮点数

C 里 `float` 是单精度，`double` 是双精度。`int`（32 位）、`float`、`double` 之间的转换遵循几条基本规则：

- **`int` → `double`**：**精确转换**。`double` 有 52 位小数域（53 位有效位），足以容纳 32 位整数；
- **`int` → `float`**：**不会溢出，但可能被舍入**。`float` 只有 23 位小数域（24 位有效位），绝对值超过 $2^{24}$ 的整数可能无法精确表示；
- **`double` / `float` → `int`**：**小数部分直接截断**（向 0 舍入）。如果结果溢出，或者原值是 NaN，**转换结果没有定义**，在 x86 上通常会得到 $T_{min}$。

### 判断题：浮点数的陷阱

课件第 33 页的 10 个判断，假设 `d` 和 `f` 都不是 NaN：

| 命题 | 结论 | 理由或反例 |
|---|---|---|
| `x == (int)(float) x` | 假 | `x = 16777217`（$2^{24}+1$），转成 `float` 后舍入为 `16777216.0`，转回来不相等 |
| `x == (int)(double) x` | 真 | `int` 转 `double` 精确，转回也精确 |
| `f == (float)(double) f` | 真 | `float` 转 `double` 精确，转回无损 |
| `d == (float) d` | 假 | `double` 转 `float` 要丢精度，如 `d = 0.1` |
| `f == -(-f)` | 真 | 取负只改符号位 |
| `2/3 == 2/3.0` | 假 | 左边是整数除法，等于 0；右边是浮点除法，约 0.667 |
| `d < 0.0` ⇒ `(d*2) < 0.0` | 真 | 乘 2 只会让绝对值变大，溢出也是 $-\infty$，仍然小于 0 |
| `d > f` ⇒ `-f > -d` | 真 | 取负对称，顺序反转 |
| `d * d >= 0.0` | 真 | 平方非负；溢出时是 $+\infty$，仍然大于等于 0 |
| `(d+f)-d == f` | 假 | `d = 1e30`、`f = 1.0` 时，`d+f` 舍入回 `d`，结果是 0 |

这些命题与整数那一讲的区别很值得体会：整数运算的"反例"主要来自**溢出**，浮点运算的"反例"主要来自**舍入**和**精度丢失**。

### 浮点加法不满足结合律

课件最后给了一个更直接的例子（`1e10f`、`1.0f`、`-1e10f` 三个数相加）：

```c
float s1 = 1.0f + (-1e10f) + 1e10f;      // 实测：0.0
float s2 = (-1e10f) + 1e10f + 1.0f;      // 实测：1.0
```

数学上两者都等于 1，实际结果却不同。原因是 $10^{10}$ 位于 $2^{33}$ 与 $2^{34}$ 之间，`float` 只有 23 位小数域，此处相邻两个浮点数的间隔是 $2^{33-23}=1024$。`1.0f` 加到 `-1e10f` 上，远小于间隔的一半，结果被舍入回 `-1e10f`，这个 1 就被"吞掉"了；而先把两个 $10^{10}$ 抵消，再加 1，就不会丢。所以**浮点加法的结果依赖于运算顺序**，对一长串数求和时，顺序、分组方式都会改变结果。这也是并行求和与顺序求和的结果可能不一致的原因。

## 8. 对照 AI 里的浮点格式

课件最后把这一讲和大模型联系起来：训练和推理的算力开销，很大一部分取决于用几位浮点数。几种常见格式的取舍如下：

| 格式 | 指数位 | 小数位 | 总位 | 使用场景 |
|---|---|---|---|---|
| FP32 | 8 | 23 | 32 | 训练默认，精度高 |
| FP16 | 5 | 10 | 16 | 推理加速，范围小 |
| BF16 | 8 | 7 | 16 | 训练替代 FP32，范围与 FP32 相同 |
| FP8 (E4M3) | 4 | 3 | 8 | 推理，精度优先 |
| FP8 (E5M2) | 5 | 2 | 8 | 训练，范围优先 |

读这张表只需要抓住一条规律：**指数位决定数值范围，小数位决定精度。** BF16 保留了与 FP32 同样的 8 位指数，所以动态范围一样，只是把精度砍到 7 位小数，训练时不容易溢出；FP16 的指数只有 5 位，范围小得多；FP8 的两种变体则分别把预算更多给了精度或范围。

> 补充：上一节的 E4M3 完全按 IEEE 规则（$Exp=15$ 为无穷与 NaN），最大值是 240。业界实际使用的 FP8 E4M3 在特殊值的处理上做了调整，数值范围与此不同，这里只借它来说明编码规律。

## 小结

1. 浮点数是 $(-1)^s\times M\times2^E$，三个域 `s / exp / frac` 分别编码符号、指数和尾数。
2. 三类取值：**规格化**（$E=Exp-Bias$，$M=1.frac$）、**非规格化**（$E=1-Bias$，$M=0.frac$，用于表示 0 与逐步下溢）、**特殊值**（`exp` 全 1：无穷与 NaN）。
3. 浮点数在数轴上**不均匀**：离 0 越近越密，越远越稀；相对精度基本不变。
4. 默认舍入是**向偶数舍入**，恰好一半时让末位为偶数，以避免统计偏差。
5. 整数与浮点的转换：`int→double` 精确，`int→float` 可能舍入，浮点→`int` 向 0 截断且溢出未定义。
6. 浮点运算会**舍入、丢精度**，不满足结合律；比较两个浮点数是否"相等"时要特别小心。
