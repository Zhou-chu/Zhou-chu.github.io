## 半音与全音

音与音之间的距离用两个单位衡量：

> **半音**：键盘上相邻两个琴键之间的距离（不论黑白）。
> **全音**：由两个半音组成，即中间隔一个琴键的两个键之间的距离。

![半音与全音](/obsidian-assets/db1466953de75b04.png)

看键盘就能数出来：C 与 C♯ 相邻，是半音；C 与 D 之间隔着 C♯，是全音。白键里有两处例外，**E–F 与 B–C 之间没有黑键**，它们本身就是半音；其余相邻白键（C–D、D–E、F–G、G–A、A–B）之间都有黑键，是全音。这就是为什么黑键是"两个一组、三个一组"的——黑键只出现在全音的缺口里。

一个八度正好包含 12 个半音。现代钢琴采用十二平均律，把一个八度（频率比 2 : 1）等比地分成 12 份，相邻两个半音的频率比都是 2^(1/12) ≈ 1.0595。连续升 12 个半音，频率翻 12 次，倍数为 (2^(1/12))^12 = 2，恰好回到高八度。

## 大调音阶

把一组音按音高由低到高、依次排列，叫做**音阶**。其中最常用的是**大调音阶**，共 8 个音（最后一个是第一个音的高八度）。它的构造规则是：

> 相邻两音之间依次为：**全、全、半、全、全、全、半**。

以 C 为起点，在键盘上白键依次弹出：

![C 大调音阶](/obsidian-assets/da5f7b192734b395.png)

C → D（全），D → E（全），E → F（半），F → G（全），G → A（全），A → B（全），B → C（半）。这正好符合上面的规律，所以 C 大调音阶全部用白键，没有升降号。这是 C 大调特殊的地方：别的音开始，同样遵守"全全半全全全半"，就必须借助黑键了（见下一篇）。

课上练习的**五指音阶**取音阶的前五个音，间隔是全、全、半、全：C D E F G。它刚好用五根手指各弹一个键，不用换位，是练习的基础。

## 音级

音阶中的每个音，按照从低到高的位置给出序号，称为**音级**，用罗马数字表示，同时有各自的名称：

| 音级 | 名称 | 在 C 大调中 |
| --- | --- | --- |
| Ⅰ | 主音 | C |
| Ⅱ | 上主音 | D |
| Ⅲ | 中音 | E |
| Ⅳ | 下属音 | F |
| Ⅴ | 属音 | G |
| Ⅵ | 下中音 | A |
| Ⅶ | 导音 | B |

主音是音阶的起点，也是最稳定、最有"归宿感"的音。导音与主音只隔半音，听起来有强烈地想上行到主音的倾向，因此叫"导音"。属音（第Ⅴ级）和下属音（第Ⅳ级）分别位于主音上方和下方的五度、四度处，后面讲和弦时会很有用。

## 升号、降号与还原号

要弹黑键，或者在别的音上起始同样规律的音阶，就需要改变音的高低，用三种记号：

![升降号与还原号](/obsidian-assets/f618c6a7cf84188a.png)

**升号（♯）**：使音**升高一个半音**。**降号（♭）**：使音**降低一个半音**。**还原号（♮）**：取消前面升降号的作用，使音回到原来的高度。

书写时，升降还原号写在音符的**左侧**，位置与音符所在的线或间对齐（升号的两条竖线夹住那条线或在那个间内，降号的圆圈对着那条线）。

## 升降号的作用范围

一个写在音符前的升降号叫**临时记号**。它的作用范围有明确的规定：

![临时记号的作用范围](/obsidian-assets/ebce6a136493114e.png)

> 在同一个小节内，临时记号对其**后面所有相同位置（同一音高）的音**有效，遇到小节线时失效。

注意"相同位置"：临时记号只影响同一条线或间的音，不影响高八度或低八度的同名音。若想在小节内取消，用还原号。

有一种特殊情况：带升降号的音用**延音线**连到下一个小节时，升降号对被连住的那个音继续有效（它本来就是同一个音的延长）；而小节线之后新出现的同名音，则恢复为没有记号时的音高，如果还要升高，必须重新写升号。

## 等音

同一个琴键可以有不同的名字，这样的音叫**等音**。黑键最典型：C♯ = D♭，D♯ = E♭，F♯ = G♭，G♯ = A♭，A♯ = B♭。

![等音](/obsidian-assets/8bfe03136f0564c9.png)

白键也有等音：E♯ = F（E 升高一个半音，因为 E–F 本来就是半音），B♯ = C，F♭ = E，C♭ = B。这些写法在课件中被作为易错点单独强调（如 B♯、F♭）：看到它们不要以为是黑键，要用"升高半音"这一定义去推。

起个不同的名字不只是为了好看，不同的名字会出现在不同的调里，决定了音阶的音名按字母顺序不重复出现。下一篇会说明这一点。

## 小结

半音是键盘上相邻的两个键，全音是两个半音；大调音阶的间隔模式是全全半全全全半；升号升半音、降号降半音、还原号恢复本位；临时记号在同一小节内对同一音高有效；同音异名叫等音。
