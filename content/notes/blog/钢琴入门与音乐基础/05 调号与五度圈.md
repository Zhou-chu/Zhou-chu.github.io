## 调与调号

**调**由主音和音阶的类型决定：以 C 为主音的大调叫 C 大调，以 G 为主音的大调叫 G 大调，依此类推。同一首曲子可以放在不同的调上弹，旋律的"形状"相同，只是整体升高或降低。

每个大调的音阶都遵守同一条规律：**全全半全全全半**。C 大调恰好全是白键，但从别的音出发，规律会要求某些音升高或降低。为了避免每次都在音符前写升降号，把整首曲子要用到的升降号集中写在谱号的右边，这就是**调号**。

![大调音阶的模式](/obsidian-assets/f793a384f71f7f77.png)

## 推导：G 大调为什么要 F♯

以 G 为主音，先照白键写出：G A B C D E F G。检查每一对相邻音之间的距离：

| 相邻音 | 实际距离 | 规律要求 |
| --- | --- | --- |
| G → A | 全 | 全 |
| A → B | 全 | 全 |
| B → C | 半 | 半 |
| C → D | 全 | 全 |
| D → E | 全 | 全 |
| E → F | **半** | 全 |
| F → G | **全** | 半 |

前五对都吻合；第六、七对不吻合。第六级 E 到第七级之间需要全音，而 E–F 本来是半音，因此第七级必须升高半音，F 变成 F♯。这样 E → F♯ 是全音，F♯ → G 是半音，规律成立。

> 因此 **G 大调的调号是一个升号（F♯）**。

## 推导：D 大调与 F 大调

D 大调：先按白键写出 D E F G A B C D，逐对检查。D → E 是全音，吻合；E → F 是半音，但规律要求这里是全音，所以 F 要升为 F♯（此后 F♯ → G 是半音，正是规律要求的第三、四级之间的半音）；G → A、A → B 都是全音，吻合；B → C 是半音，但规律要求这里是全音，所以 C 要升为 C♯（此后 C♯ → D 是半音，正是第七、八级之间的半音）。D 大调有两个升号：F♯、C♯。

F 大调向另一个方向走：F G A B C D E F。F → G、G → A 都是全音，吻合；A → B 是全音，但规律要求第三、四级之间是半音，所以 B 要降低半音变成 B♭（A → B♭ 为半音，B♭ → C 为全音）；C → D、D → E 是全音，E → F 是半音，都吻合。F 大调有一个降号：B♭。

![常见调的调号](/obsidian-assets/fc7b414a970c147e.png)

课程重点掌握四个调：**C 大调（无升降号）、G 大调（F♯）、D 大调（F♯、C♯）、F 大调（B♭）**。

## 五度圈

观察 C → G → D 这个顺序：每次把主音向上移一个纯五度（C 上方的纯五度是 G，G 上方的纯五度是 D），调号就**多一个升号**，而且新增的升号总是落在新主音的下方一个半音，也就是新调的**导音**上（G 大调的导音是 F♯，D 大调的导音是 C♯）。

反方向，每次向下移一个纯五度（C → F → B♭），调号就多一个降号。把这种关系画成圆形，叫**五度圈**：

![五度圈](/obsidian-assets/f991919944a5c32b.png)

顺时针方向每步增加一个升号，依次是 C、G、D、A、E、B……；逆时针方向每步增加一个降号，依次是 C、F、B♭、E♭、A♭、D♭……

升号出现的顺序固定为：**F♯ C♯ G♯ D♯ A♯ E♯ B♯**。降号出现的顺序固定为：**B♭ E♭ A♭ D♭ G♭ C♭ F♭**。两个顺序恰好相反，且每个后一个升号比前一个高一个纯五度（降号则低五度）。写在谱号后面时，升降号要放在固定的线或间上，不能乱挪。

## 由调号反推调

看到一个调号，要判断是哪个大调，利用上面的规律：

![由调号找调](/obsidian-assets/828ec7c16afee164.png)

**升号调**：最后一个升号是该调的**导音**，因此主音是它**上方的半音**。例如两个升号 F♯、C♯，最后一个升号是 C♯，C♯ 上方半音是 D，所以是 D 大调。

**降号调**：**倒数第二个降号**就是该调的主音。例如两个降号 B♭、E♭，倒数第二个是 B♭，所以是 B♭ 大调；三个降号 B♭、E♭、A♭，倒数第二个是 E♭，所以是 E♭ 大调。只有一个降号时没有"倒数第二个"，这是例外，记住它是 F 大调。

这条规则可以验证：降号调的最后一个降号是该调的第四级（如 F 大调的 B♭），而第四级比主音高一个纯四度；降号的顺序是每次下行一个纯五度，所以倒数第二个降号比最后一个降号高一个纯五度，也就是比它低一个纯四度，恰好就是主音。

没有任何升降号的就是 C 大调。

## 五指音阶在不同调中的位置

五指音阶（全全半全）在各个调上的位置如下：

![五指音阶的位置](/obsidian-assets/9ef22e44f63c411b.png)

图中给出 C、G、F 三个位置。C：C D E F G；G：G A B C D；F：F G A B♭ C（第 4 指弹黑键 B♭）。D 位置同样可以推出，即 D E F♯ G A，验证如下：D → E（全），E → F♯（全），F♯ → G（半），G → A（全），与"全全半全"一致。弹的时候要把调号里的升降号记在手上：遇到 D 位置要记得 F 弹成 F♯，遇到 F 位置要记得 B 弹成 B♭。

## 小结

调号是大调"全全半全全全半"的必然结果：从白键出发时，不满足规律的位置通过升降号调整。一个升号对应 G 大调，两个升号对应 D 大调，一个降号对应 F 大调；五度圈揭示了调号增减的规律；由最后一个升号（导音）或倒数第二个降号（主音）可以反推调。
